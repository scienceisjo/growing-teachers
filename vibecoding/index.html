슬라이드는 닫히면 끝이지만, 페이지는 매뉴얼로 남습니다. 못 따라온 부분은 집에서 링크를 다시 열면 됩니다.

💡 한 단계 더 — 나만의 '페이지 제작 도우미' 에이전트 만들기

SenGPT의 에이전트(챗봇 만들기) 기능에 아래 지시문을 붙여 넣으면, 매번 조건을 설명할 필요 없이 "○○ 연수 페이지 만들어 줘" 한마디로 통하는 전용 도우미가 됩니다. 오늘 실습은 에이전트 없이도 충분하니, 익숙해진 뒤에 만들어 보세요.

에이전트 지시문 (전체 복사) 
너는 '연수 페이지 제작 도우미'다. 교사가 말로 요청하면 웹페이지를 만들어 준다.

규칙:
1. 항상 HTML 한 파일로 완성해서 준다. CSS와 자바스크립트도 그 파일 안에 넣는다. 외부 파일·라이브러리·이미지 링크는 쓰지 않는다.
2. 코드는 하나의 코드 블록으로, 처음(<!DOCTYPE html>)부터 끝(</html>)까지 빠짐없이 준다.
3. 휴대폰에서도 잘 보이게 만든다(viewport 설정, 넉넉한 글자 크기와 여백).
4. 글꼴은 시스템 기본을 쓰고, 색은 요청이 없으면 흰 바탕에 파란 포인트로 깔끔하게.
5. 내용을 지어내지 않는다. 사용자가 주지 않은 정보(날짜·이름·장소)는 ○○로 표시하고, 무엇을 채워야 하는지 알려 준다.
6. 수정 요청을 받으면 파일 전체를 처음부터 끝까지 다시 준다. 바뀐 부분만 주지 않는다.
7. 답이 길어서 중간에 끊기면, 사용자가 "이어서"라고 할 때 끊긴 지점부터 이어서 출력한다.

1바이브코딩이 뭔가요

코드를 '쓰는' 게 아니라, AI에게 말로 시키고 결과물을 받아 쓰는 방식입니다. 우리는 기획자가 되고, 타자는 AI가 칩니다.

💬
① 말로 시킨다"연수 안내 페이지 만들어 줘"
→
📋
② 코드를 받는다코드 블록 전체 복사
→
👁️
③ 파일로 연다🧰 도우미에 붙여넣기
→
🔁
④ 다시 말로 고친다"제목 더 크게" → ②로

이 ①→④ 루프를 도는 것이 전부입니다. 한 바퀴에 1~2분, 서너 바퀴면 쓸 만한 페이지가 나옵니다.

2실패하지 않는 규칙 셋

1️⃣ "한 파일로 완성본"

항상 "HTML 한 파일로, 처음부터 끝까지"를 요구하세요. 파일이 여러 개로 쪼개지는 순간 초보자는 길을 잃습니다.

2️⃣ 한 번에 하나만

"색도 바꾸고 표도 넣고 퀴즈도…"를 한꺼번에 시키면 뒤죽박죽이 됩니다. 한 바퀴에 한 가지만 고치세요.

3️⃣ 항상 전체를 다시 받기

"이 부분만 바꾸세요"라며 조각 코드를 주면 어디에 끼울지 몰라 막힙니다. "파일 전체를 다시 줘"가 안전합니다.

오류가 나면? 당황할 것 없습니다. 화면이 하얗거나 버튼이 안 눌리면, 증상(또는 오류 메시지)을 그대로 복사해서 AI에게 붙여넣고 "고쳐서 전체 다시 줘"라고 하면 됩니다. 오류 해결도 말로 합니다.
넣지 말아야 할 것 — 학생 실명·사진·연락처 등 개인정보. 오늘 만드는 페이지는 공개 인터넷에 올라간다는 것을 전제로 내용을 고르세요.

2

3

미리보기는 새 탭에 즉시 열립니다. 마음에 들면 파일 이름을 정하고 저장하세요. 저장된 파일은 더블클릭하면 언제든 다시 열립니다.

4
한 가지만 고쳐 보기

SenGPT로 돌아가 "제목을 더 크게 하고, 전체 여백을 시원하게. 파일 전체를 다시 줘" — 새 코드를 받아 2~3번을 반복합니다. 이 루프가 몸에 붙으면 끝난 겁니다.

여기까지 되면 오늘의 절반이 끝났습니다. 옆 사람과 서로 미리보기 화면을 보여 주세요 — 같은 프롬프트인데 다른 페이지가 나온 것도 재미있는 관찰거리입니다.
🗒 도우미 없이 저장하고 싶다면 (메모장 방법)

수정 요청은 아래 카드를 복사해 그대로 쓰거나 살짝 바꿔 쓰세요. 모든 카드 끝에 "전체를 다시 줘"가 붙어 있는 이유는 「🪄 원리」의 규칙 3번입니다.

맨 아래에 만든 사람과 날짜가 들어간 작은 안내 줄을 추가하고, 인쇄했을 때도 깔끔하게 나오도록 정리해 줘. 파일 전체를 다시 줘.

  







  
1파일을 '주소'로 바꾸기 — GitHub Pages

  
GitHub는 전 세계에서 가장 널리 쓰이는 무료 코드 저장소입니다. 여기 올린 HTML은 공짜로, 기한 없이, 인터넷 주소가 됩니다.

  

    
1
github.com 가입
이메일 하나면 됩니다(영어 화면이지만 가입 → 이메일 인증까지 3분). 아이디는 주소에 들어가니 깔끔한 영문으로. 연수 전에 미리 가입해 오면 가장 좋습니다.

    
2
저장소 만들기: 오른쪽 위 ＋ → New repository
Repository name에 my-training 처럼 영문 이름 → Public 선택 → Create repository.

    
3
파일 올리기: uploading an existing file 클릭
만든 .html 파일을 끌어다 놓습니다. 이때 파일 이름을 index.html로 바꿔 올리면 주소가 짧고 깔끔해집니다. 아래 Commit changes 클릭.

    
4
Pages 켜기: Settings → 왼쪽 Pages
Branch를 main, 폴더 / (root)로 놓고 Save.

    
5
1~2분 뒤 주소 확인
https://아이디.github.io/my-training/ — 이 주소가 여러분의 연수 자료입니다. 휴대폰으로 직접 열어 확인하세요.

    
6
QR 만들기
네이버에서 "QR코드 만들기" 검색 → 주소 붙여넣기 → 이미지 저장. 다음 연수 첫 화면에 이 QR 하나면 배포가 끝납니다.

  

  
수정하고 싶어지면? 파일을 고쳐서 같은 이름으로 다시 올리면(Add file → Upload) 1~2분 안에 같은 주소에 새 내용이 반영됩니다. 주소는 그대로라서 이미 나눠 준 QR도 계속 살아 있습니다.

  
오늘 여기서 막히는 분은 — 괜찮습니다. 완성한 .html 파일을 강사에게 보내 주시면 모아서 올려 드리고 주소를 돌려드립니다(대행 배포). 가입은 집에서 천천히 하셔도 됩니다.

50–70실습② 내 자료로스타터 템플릿 + 개조 프롬프트 · 각자 실제로 쓸 연수 주제로 · 고치기 사전 활용

85–90링크 갤러리 + 마무리완성 링크를 모아 전자칠판에서 함께 열람 · "오늘 만든 주소는 평생 무료로 살아 있습니다"
