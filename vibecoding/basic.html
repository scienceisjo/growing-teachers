도구를 열고, 바탕화면에 폴더 하나 만들기

5분

쓰시는 도구를 열고, 오늘 만든 파일이 모일 폴더를 하나 만들어보겠습니다!

폴더부터 만드는 까닭

만든 파일을 나중에 끌어다 올려야 해서, 처음부터 한곳에 모아 둡니다.

저는 새 앱을 만들 때마다 폴더부터 하나 만듭니다. Claude 앱과 ChatGPT 앱의 코딩 도우미는 그 폴더 안에서 파일을 만들고 고치기 때문에, 폴더가 곧 작업대가 됩니다. 폴더 없이 시작하면 파일이 어디에 생겼는지 찾느라 시간을 씁니다.

SenGPT는 파일을 직접 만들지 못해서, 받은 코드를 폴더에 저장하는 일은 선생님이 합니다. 그래서 SenGPT로 하시는 분도 폴더는 똑같이 만들어 둡니다.

도구별 순서

  1. 바탕화면에 과학실험실 폴더 만들기바탕화면 빈 곳 오른쪽 클릭 → [새로 만들기] → [폴더] → 이름 과학실험실
  2. ChatGPTChatGPT 앱을 열고 Codex로 바꾸기왼쪽 위 [ChatGPT ▾] → [Codex]
  3. ChatGPT과학실험실 폴더를 작업 폴더로 연결하기[새 작업] → 프로젝트를 묻으면 [폴더 추가] → 바탕화면 → 과학실험실
  4. ClaudeClaude 앱을 열고 Code 탭으로 가기위쪽 가운데 [Code] 탭
  5. Claude과학실험실 폴더 고르기[Local] → [Select folder](폴더 선택) → 바탕화면 → 과학실험실
  6. Claude모델을 Sonnet으로 두기보내기 버튼 옆 모델 이름을 눌러 Sonnet. 사용량을 아낍니다
  7. SenGPTSenGPT 열기senedu.kr 로그인 → [도구모음] → [SenGPT]. 새 창이 안 뜨면 주소창 오른쪽에서 팝업 허용
  8. 입력칸이 보이면 준비 끝앱이 업데이트되면 버튼 이름이 조금 다를 수 있습니다
막혔을 때

학교 노트북에 앱이 설치되지 않습니다. 관리자 권한이 막혀 있는 노트북입니다. 오늘은 SenGPT나 ChatGPT 웹으로 하시고, 만든 코드는 3단계의 코드 도우미로 저장하면 같은 결과가 나옵니다.

Code 탭을 누르니 요금제를 올리라고 나옵니다. Claude 무료 계정은 Code 탭이 잠겨 있습니다. 오늘은 SenGPT 갈래로 오셔도 같은 결과물을 만드실 수 있습니다.

SenGPT 새 창이 뜨지 않습니다. 팝업이 막힌 상태입니다. 주소창 오른쪽 끝의 팝업 차단 표시를 눌러 senedu.kr을 허용하고 다시 누릅니다.

부탁문은 AI와 같이 씁니다

10분

보여주고 싶은 장면을 한 줄로 적고, 빈칸을 채워 부탁문을 완성해보겠습니다!

예전엔 주문 잘 쓰는 법을 배웠습니다

요즘은 하고 싶은 것을 말하고, 모르는 것은 AI가 먼저 묻게 합니다.

몇 해 전만 해도 AI에게 원하는 결과를 얻으려면 역할을 정해 주고 형식을 못 박는 요령, 이른바 프롬프트 엔지니어링을 따로 배웠습니다. 지금 모델들은 사람 말을 훨씬 잘 알아들어서, 저는 요령보다 수업 장면을 정확히 말하는 데 시간을 씁니다. 그리고 부탁문 끝에 "만들기 전에 궁금한 것을 먼저 물어봐 줘"를 꼭 붙입니다.

그래도 과학 시뮬레이션에는 AI가 잘 놓치는 것이 있습니다. 숫자에 단위를 안 붙이거나, 식으로 계산하지 않고 그럴듯하게 그리거나, 슬라이더 끝에서 화면이 깨지는 것들입니다. 그래서 아래 빌더는 선생님이 적은 장면에 이런 것을 막는 공통 규칙을 저절로 붙입니다.

빌더칸을 채우면 부탁문이 완성됩니다

완성된 부탁문을 복사해 도구에 붙여넣습니다.

학생이 하는 일 (여러 개 골라도 됩니다)
쓰는 화면
완성된 부탁문

공통 규칙은 제가 시뮬레이션을 만들면서 자주 고쳤던 것들을 모은 것입니다. 이 규칙을 붙여도 빠지는 것이 생기기 때문에 4단계의 30초 점검을 따로 둡니다.

AI가 되물으면 짧게 답합니다

잘 모르겠는 질문에는 "네가 정해 줘"라고 답해도 괜찮습니다.

되묻는 질문은 대개 입자를 몇 개 그릴지, 어떤 값을 슬라이더로 바꿀지, 그래프를 넣을지 같은 것들입니다. 저는 수업에서 꼭 필요한 것만 답하고 나머지는 AI에게 맡깁니다.

막혔을 때

부탁문이 너무 길어 보입니다. 길어도 괜찮습니다. 짧고 막연한 부탁이 오히려 엉뚱한 결과를 만듭니다.

AI가 묻지 않고 바로 만들기 시작했습니다. 그대로 두셔도 괜찮습니다. 결과를 보고 4단계와 5단계에서 고칩니다.

무슨 장면을 만들지 정하지 못하겠습니다. 이번 주 수업에서 칠판에 그림으로 설명하기 가장 답답했던 장면 하나를 적습니다. 입자처럼 눈에 안 보이는 것이 움직이는 장면일수록 시뮬레이션이 잘 맞습니다.

보내고, 기다리고, 열어 보기

15분

부탁문을 보내 index.html을 받고, 브라우저에서 움직이는지 확인해보겠습니다!

도구별 순서

  1. ChatGPT · Claude입력칸에 부탁문을 붙여넣고 보내기Ctrl+V → 보내기(↑) 버튼
  2. ChatGPT · Claude되묻는 질문에 답하기짧게. 모르겠으면 "네가 정해 줘"
  3. ChatGPT · Claude파일을 만들어도 되냐고 물으면 위치를 보고 허용하기과학실험실 폴더 안이면 [허용]. 다른 곳이면 멈추고 손 들기
  4. ChatGPT · Claude다 됐다고 하면 index.html 열기과학실험실 폴더에서 index.html 더블클릭
  5. SenGPT부탁문을 붙여넣고 보내기Ctrl+V → 보내기
  6. SenGPT질문에 답하고 코드가 끝까지 나올 때까지 기다리기마지막 줄이 </html> 이면 끝까지 나온 것
  7. SenGPT답을 통째로 복사해 아래 코드 도우미에 붙여넣기답 아래 복사 버튼 → 코드 도우미 칸 클릭 → Ctrl+V → [미리보기]
  8. SenGPT과학실험실 폴더에 index.html로 저장하고 열기[index.html로 저장] → 과학실험실 폴더 → 저장한 파일 더블클릭

SenGPT코드 도우미

설명이 섞인 답을 통째로 붙여넣어도 코드만 골라 미리 보여 주고, 파일로 저장합니다.

채팅 답을 메모장에 붙여 저장하면 파일이 .txt로 저장되거나 설명 문장이 섞여 들어가 열리지 않는 일이 자주 생깁니다. 그래서 코드 부분만 골라 바로 .html로 저장하는 도우미를 이 페이지에 넣었습니다. 붙여넣은 내용은 선생님 컴퓨터 안에서만 처리되고 어디로도 보내지 않습니다.

처음 결과는 70%면 충분합니다

어설퍼도 움직이기만 하면 다음 단계로 넘어갑니다.

저는 한 번에 완성본이 나온 적이 거의 없습니다. 초안은 금방 나오지만 시간은 대부분 고치는 데 들어갑니다. 그래서 첫 화면이 조금 어설퍼도 움직이기만 하면 4단계로 넘어갑니다. 처음부터 완벽하게 만들려고 붙잡고 있으면 60분 안에 보관함까지 가지 못합니다.

막혔을 때

한참 기다려도 반응이 없습니다. 화면 아래에 허용을 묻는 창이 떠 있는지 봅니다. 멈춘 것처럼 보이면 대개 선생님 대답을 기다리는 중입니다.

SenGPT 코드가 중간에 끊겼습니다. "처음부터 끝까지 다시, 설명은 빼고 코드만 써 줘"라고 보냅니다. 그래도 끊기면 기능을 하나 줄여 달라고 합니다.

index.html이 어디 있는지 모르겠습니다. 도구에게 "방금 만든 파일 위치를 알려 줘"라고 물으면 경로를 알려 줍니다.

파일을 열었더니 하얀 화면만 나옵니다. 도구에게 "하얀 화면만 나와. 원인을 찾아서 고쳐 줘"라고 보냅니다. SenGPT 갈래라면 코드 도우미의 미리보기에서 먼저 확인합니다.

학생에게 주기 전 30초 점검

5분

슬라이더를 양 끝까지 밀어 보고, 단위와 축을 보고, AI에게 틀린 곳을 물어보겠습니다!

눈으로 네 가지

  1. 슬라이더를 양 끝까지 밀고 0도 넣어 보기화면이 깨지거나 음수·NaN이 뜨면 적어 두기
  2. 숫자마다 단위가 붙었는지 보기압력 kPa·atm, 온도 ℃·K, 부피 mL처럼
  3. 그래프의 축 이름·단위·눈금 보기보일 법칙이면 직선이 아니라 반비례 곡선인지
  4. 학생이 이 화면만 보고 잘못 배울 곳 찾기예: 온도를 올렸더니 입자 크기가 커진다

AI에게 한 번 더 묻기

코드는 아직 바꾸지 말고 목록만 받습니다. 고치는 것은 5단계에서 하나씩 합니다.

점검 부탁
이 시뮬레이션에서 과학적으로 틀리거나 학생이 오해할 수 있는 부분만 목록으로 알려 줘. 코드는 아직 바꾸지 마.

AI가 만든 시뮬레이션은 그럴듯하게 움직이지만, 식으로 계산하지 않고 모양만 흉내 낸 경우가 있습니다. 기본값 근처에서는 맞아 보이다가 슬라이더를 끝까지 밀면 드러납니다.

저는 이 점검을 수업에도 씁니다. 기체 단원에서 일부러 틀리게 만든 시뮬레이션 세 개를 학생들에게 주고 틀린 곳을 찾게 했는데, 숨겨 둔 결함이 모두 열한 개였습니다. 학생들은 찾은 결함을 AI에게 말로 고치게 하는 데까지 해 봤습니다.

토큰과 긴 대화

AI가 읽고 쓰는 양만큼 요금제 한도가 줄어듭니다. 대화가 길어지면 AI가 앞부분을 스스로 요약해서 이어 갑니다.

토큰은 AI가 글을 읽고 쓰는 단위입니다. 요금제의 사용 한도는 메시지 개수보다 이 토큰을 얼마나 썼는지에 따라 줄어듭니다. "파일 전체를 다시 써 줘"는 파일 한 장을 통째로 다시 쓰는 일이라 가장 많이 씁니다. Claude 앱과 Codex는 고칠 부분만 바꾸니 훨씬 덜 쓰고, SenGPT처럼 고칠 때마다 코드 전체를 다시 받는 방식은 한 번에 파일 한 장만큼 씁니다.

대화가 길어지면 AI가 앞부분을 스스로 요약해서 이어 갑니다. 다만 요약하면서 자잘한 약속이 빠질 수 있어서, 저는 꼭 지킬 규칙을 파일에 적어 두고 "이 규칙을 읽고 시작해 줘"라고 합니다. Claude 앱이나 Codex처럼 폴더에서 일하는 도구는 만든 파일이 그대로 남아 있어서, 새 대화를 열어도 "이 폴더의 index.html을 이어서 고쳐 줘" 한 줄이면 이어집니다. 처음부터 다시 올려야 하는 것은 코드가 채팅창 안에만 있는 웹 채팅 쪽입니다.

막혔을 때

고쳐 달라고 했더니 다른 부분까지 바뀌었습니다. "방금 고치기 전으로 되돌려 줘"라고 한 뒤, 고칠 곳 하나만 다시 부탁합니다.

새로고침해도 바뀐 것이 보이지 않습니다. SenGPT 갈래라면 새 코드를 코드 도우미로 다시 저장했는지 봅니다. 앱 갈래라면 AI가 다른 파일을 고쳤을 수 있으니 "어느 파일을 고쳤는지 알려 줘"라고 묻습니다.

사용량이 다 떨어졌다고 나옵니다. 몇 시간 단위로 다시 채워집니다. 같은 부탁을 여러 번 되풀이하는 것이 가장 많이 쓰니, 부탁을 하나로 모아 짧게 보냅니다.

GiteacherHub에 올려 서로 열어 보기

10분

만든 index.html을 보관함에 올리고, 다른 분임 선생님의 앱도 열어보겠습니다!

올리는 순서

PIN은 앞 화면에 있습니다. GitHub 계정이 없어도 올라갑니다.

GiteacherHub · 올리기선생님들이 바이브코딩으로 만든 교실 앱을 모아 두는 보관함입니다.
올리기 열기 ↗
  1. 회차를 고르고 앞 화면의 PIN 넣기[올리기 열기] → 회차 → PIN → [확인]
  2. index.html을 끌어다 놓고 미리보기로 한 번 더 확인하기과학실험실 폴더의 index.html → 점선 칸으로 끌기
  3. 제목·학교급·과목·목적 고르기제목은 파일 안의 제목이 먼저 채워집니다
  4. 대표 화면 붙여넣기 (선택)앱 화면에서 Win+Shift+S로 캡처 → 대표 화면 칸 클릭 → Ctrl+V
  5. 고치기 비밀번호를 정하고 개인정보 없음에 체크한 뒤 올리기비밀번호는 나중에 파일을 바꾸거나 내릴 때 씁니다

보관함은 배포를 하지 않아도 서로 만든 것을 바로 열어 볼 수 있게 만든 곳입니다. 올린 앱은 제가 학생 이름이 들어 있지 않은지 확인한 뒤 공개하고, 연수 중에는 나눔 시간에 한 번에 공개합니다. 공개된 앱마다 의견을 남길 수 있어서, 다른 선생님이 어떻게 고쳐 쓰셨는지도 모입니다.

막혔을 때

PIN이 맞지 않다고 나옵니다. 앞 화면의 숫자를 다시 봅니다. 회차가 닫혀 있으면 저에게 말씀해 주세요.

파일이 2MB보다 크다고 나옵니다. 사진을 파일 안에 넣은 경우입니다. 도구에게 "넣은 이미지를 작게 줄여 줘"라고 부탁하고 다시 올립니다.
