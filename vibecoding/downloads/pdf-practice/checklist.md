# PDF 검수표

![HNR TECH](assets/hnr-tech-mark.webp)

생성 코드가 실행됐다는 것과 자료가 맞게 만들어졌다는 것은 다르다. 해당하는 항목을 최종 PDF에서 확인한다.

## 자료와 내용

- [ ] 과목·대상·수업 범위가 교사의 요청과 같다.
- [ ] 확인되지 않은 성취기준·인용문·출처를 넣지 않았다.
- [ ] 원자료의 조건·예외·수치·단위·용어를 빠뜨리거나 바꾸지 않았다.
- [ ] 문항·지문·사진·글꼴의 이용 및 배포 권한을 확인했다.
- [ ] 학생 이름·학번·성적·얼굴·계정 정보와 개인 경로를 제외했다.
- [ ] 설명용 도식의 방향·연결·비례·축·라벨을 검토했다.

## 파일 확인

- [ ] 최종 PDF를 다시 열 수 있다.
- [ ] 용지 크기·방향·쪽수·페이지 번호가 맞다.
- [ ] 한글·영문·숫자·수학 기호·첨자·단위가 정상 표시된다.
- [ ] 문항 번호·그림 번호·쪽 참조·해설 번호가 맞는다.
- [ ] 수정 가능한 원본 또는 생성 코드가 함께 있다.
- [ ] ZIP을 만들었다면 다시 열어 파일 목록과 압축 오류를 확인했다.

## 모든 쪽을 이미지로 확인

- [ ] 마지막으로 저장한 PDF의 모든 쪽을 새로 렌더링했다.
- [ ] 모든 쪽에서 글자·그림·표의 잘림과 겹침을 직접 확인했다.
- [ ] 빈 페이지, 뒤바뀐 순서, 오래된 내용이 남아 있지 않다.
- [ ] 사진 비율이 맞고 작은 조작 부분도 읽힌다.
- [ ] 실제 인쇄 크기에서 본문·각주·라벨이 읽힌다.
- [ ] 흑백 인쇄가 필요하면 색 없이도 구분된다.
- [ ] 손으로 쓰는 빈칸·체크칸·풀이 공간이 충분하다.

## 문제지

- [ ] 발문과 선지가 같은 대상을 묻는다.
- [ ] 자료 해석 문항을 제시된 자료만으로 판단할 수 있다.
- [ ] 정답의 유일성과 각 오답의 근거를 확인했다.
- [ ] 계산·단위·부호·그래프를 다시 검산했다.
- [ ] 정답지가 최종 문제지 순서와 일치한다.
- [ ] 학생용 자료에 정답이 잘못 노출되지 않는다.
- [ ] 배점이 있다면 합계와 부분점수 기준을 확인했다.

## 정리본·단권화

- [ ] 교사가 강조한 개념과 표현을 반영했다.
- [ ] 줄이는 과정에서 조건·예외·인과관계가 달라지지 않았다.
- [ ] 도식·표·화살표와 본문이 일치한다.
- [ ] 장식이나 모눈이 본문을 방해하지 않는다.
- [ ] 빈칸으로 요청한 부분은 비어 있다.

## 실험·실습 매뉴얼

- [ ] 장비 모델과 실제 사진·화면을 대조했다.
- [ ] 절차·안전 조건은 교사가 확인한 자료에 근거한다.
- [ ] 확인되지 않은 설정값·시약량·전원 조건을 추측하지 않았다.
- [ ] 사진 번호와 설명이 실제 버튼·단자·연결 지점을 가리킨다.
- [ ] 가짜 장비 사진·프로그램 화면·측정값이 없다.
- [ ] 안전 경고가 필요한 행동 앞이나 옆에 있다.
- [ ] 저장·종료·재실험·기존 결과 삭제를 구분했다.
- [ ] 수정된 절차와 모순되는 문장이 다른 쪽에 남아 있지 않다.

## 교사 최종 확인

- [ ] 실제로 사용할 문항·개념·절차를 교사가 확인했다.
- [ ] 검수하지 못한 부분과 추가로 필요한 자료를 별도로 적었다.
- [ ] 안전 조건이나 핵심 내용이 미확인인 자료를 학생용 완료본으로 배포하지 않는다.
