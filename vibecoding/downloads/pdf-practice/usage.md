# PDF 제작 실습

![HNR TECH](assets/hnr-tech-mark.webp)

내 수업 자료를 첨부하고, 자료 종류와 디자인을 골라 PDF를 만든다. 여기 있는 SKILL.md는 AI가 따라 읽는 제작 지침이다. 실행 프로그램이나 글꼴 설치 파일이 아니다.

## 스킬(SKILL.md)이 뭔가요?

AI가 작업할 때 따라야 할 순서와 기준을 정리해 둔 지침입니다. 기본 파일이 SKILL.md이고, 필요하면 예시·참고자료·제작 코드가 함께 들어갑니다. MD는 제목·목록 등을 표시할 수 있는 마크다운 문서 파일입니다. [스킬의 구성 · 공식 설명](https://developers.openai.com/plugins/concepts/skills)

예를 들어 실험 매뉴얼 스킬에는 ‘실제 장비 사진 사용’, ‘한 쪽에 주요 조작 하나’, ‘완성한 모든 쪽의 잘림·겹침 확인’ 같은 기준이 적혀 있습니다. 다른 실험 매뉴얼을 만들 때도 같은 지침을 다시 쓸 수 있습니다.

이번에 만들 내용은 요청문에, 반복해서 지킬 제작 방식은 스킬에 적어 둔다고 생각하시면 됩니다.

이번 실습에서는 별도 설치하지 않습니다. 선택한 SKILL.md와 본인 자료를 AI에 첨부하고, “첨부한 지침을 먼저 읽고, 이 방식으로 만들어 줘.”라고 요청하면 됩니다. 파일을 채팅에 첨부하는 것과 앱에 스킬을 설치하는 것은 다릅니다. 파일을 붙인다고 PDF 생성 기능이 새로 생기는 것도 아닙니다.

## 1. 자료 종류 고르기

| 만들 자료 | 첨부할 스킬 | 준비할 자료 |
| --- | --- | --- |
| 인쇄용 문제지 | `exam-sheet/SKILL.md` | 직접 쓴 문항 또는 수업 자료, 문항 수·유형, 정답지 필요 여부 |
| 손글씨 정리본·단권화 | `handwritten-notes/SKILL.md` | 학습지·수업 메모, 강조할 내용, 제외할 내용 |
| 실험·실습 매뉴얼 | `lab-manual/SKILL.md` | 교사가 확인한 절차·안전 조건, 실제 장비 사진·프로그램 화면 |

과학 이외의 교과에도 사용할 수 있다. 문항·개념·실습 절차는 각 교과에 맞는 자료를 제공한다.

## 2. 디자인 고르기

- 흑백 시험지: `mono-exam`
- 파란 학습지: `blue-worksheet`
- 모눈 손글씨: `grid-notes`
- 코넬 노트: `cornell`
- 사진형 가로 매뉴얼: `photo-manual`
- 관찰 기록지: `checklist`

디자인의 상세 기준은 [styles.md](styles.md)에 있다. 선택한 SKILL.md와 함께 첨부하면 된다. 디자인은 시작점이며 용지·색·쪽수는 바꿀 수 있다.

## 3. AI에 첨부하기

파일 첨부와 코드 실행·PDF 파일 생성을 지원하는 AI 환경을 사용한다. 지금 쓰는 환경에서 파일을 만들 수 있는지 먼저 확인한다. 지원하지 않으면 생성 코드나 편집 원본을 받아 실행 가능한 환경에서 이어서 작업한다. 지침을 붙였다고 파일 생성 기능이 생기는 것은 아니다.

첨부할 파일:

1. 선택한 자료의 SKILL.md 한 개
2. 내 수업 자료
3. styles.md
4. checklist.md

SKILL.md만 첨부해도 기본 제작 지침은 전달된다. 여러 SKILL.md를 한 번에 첨부하면 이름이 같으므로 파일 내용을 확인해 어떤 지침을 적용할지 명시한다. 이 실습에서는 필요한 한 개부터 쓰면 된다.

## 4. 요청하기

아래 내용을 수업에 맞게 채워 함께 보낸다.

```text
첨부한 SKILL.md를 따라 PDF를 만들어 줘.

과목·대상:
단원 또는 주제:
만들 자료:
디자인 키:
용지·방향:
분량:
첨부 자료에서 사용할 부분:
꼭 넣을 내용:
빼야 할 내용:
학생이 직접 쓰는 칸:
정답지 또는 교사용 설명 필요 여부:

원자료에 없는 핵심 조건을 추측하지 말고 먼저 물어봐 줘.
여러 쪽이면 대표 1~2쪽을 먼저 보여 줘.
최종 PDF의 모든 쪽을 이미지로 렌더링해 잘림·겹침·한글 깨짐을 확인해 줘.
PDF와 수정 가능한 원본을 함께 줘.
검수하지 못한 부분은 따로 적어 줘.
```

문제지 예시:

> 첨부한 내가 쓴 문항 8개를 흑백 시험지로 편집해 줘. 디자인은 mono-exam, A4 세로 2쪽이야. 발문과 선지는 바꾸지 말고 서술형에는 풀이 공간을 넉넉히 줘. 정답과 해설은 별도 PDF로 만들어 줘. 2쪽에 읽기 어렵게 들어가면 먼저 알려 줘.

정리본 예시:

> 첨부한 학습지와 수업 메모로 단권화를 만들어 줘. 디자인은 grid-notes, A4 세로야. 메모에 표시한 개념을 우선하고 수업에서 다루지 않은 내용은 추가하지 마. 용어 비교는 표로, 관계 설명은 벡터 도식으로 넣어 줘. 손글씨 글꼴은 읽기 쉬운 것으로 확인해 줘.

실험 매뉴얼 예시:

> 첨부한 실험 절차와 실제 장비 사진으로 학생용 매뉴얼을 만들어 줘. 디자인은 photo-manual, A4 가로야. 사진 위에 번호를 붙이고 한 쪽에 주요 행동 하나씩 배치해 줘. 내가 적지 않은 설정값이나 안전 조건은 추측하지 마. 사진이 부족한 단계는 필요한 촬영 목록을 먼저 알려 줘. 관찰 결과 칸은 비워 둬.

## 5. 고치기

수정할 쪽과 내용을 구체적으로 적는다.

> 2쪽의 표가 너무 작아. 문항은 그대로 두고 표를 넓혀 줘. 필요하면 그 문항만 다음 쪽으로 옮겨도 돼. 바뀐 쪽과 앞뒤 쪽을 다시 렌더링해서 확인해 줘.

> 3쪽의 사진 번호 2가 다른 단자를 가리키고 있어. 내가 표시한 사진 기준으로 고쳐 줘. 연결 설명과 뒤쪽 확인 항목도 같이 대조해 줘.

## 6. 사용 전 확인

- [checklist.md](checklist.md)로 확인하고 실제 출력 크기로 한 번 본다.
- 문항 정답·개념 설명·실험 절차는 교사가 최종 확인한다. AI가 검수했다고 해서 수업 적합성과 안전이 보장되는 것은 아니다.
- 학생 이름·학번·얼굴·성적·계정 정보는 올리지 않는다. 필요한 경우 익명화한 자료를 준비한다.
- 책이나 문제집 자료를 가지고 있다는 것이 재배포 허락을 뜻하지 않는다. 문항·사진·지문·글꼴의 권리를 확인한다.
- 이 묶음에는 글꼴 파일, 학생 자료, 개인용 연락처, 실행 프로그램이 들어 있지 않다. HNR TECH 표시는 이 연수 지침의 제작자 표식이며 선생님의 PDF에 넣을 필요는 없다.
