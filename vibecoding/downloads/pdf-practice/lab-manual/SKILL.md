# 실험·실습 매뉴얼

![HNR TECH](../assets/hnr-tech-mark.webp)

교사가 확인한 절차를 학생이 사진과 짧은 설명으로 따라갈 수 있게 정리한다. 이 파일만 첨부해도 사용할 수 있다. 안전 판단과 실험 실행은 담당 교사가 확인한다.

## 필요한 자료

- 실험·실습 목적, 대상, 장비 이름과 모델, 교사가 확인한 순서, 실제 사진이나 화면, 측정·작동 조건, 안전수칙, 필요한 출력 형식을 확인한다.
- 이미 자료에 있는 정보는 다시 묻지 않는다. 부족한 정보는 한꺼번에 정리하되 안전·절차에 영향을 주는 항목부터 확인한다.
- 전압·전류 제한, 시약의 종류·농도·양, 가열 조건, 보호구, 환기, 폐기·전원 차단 등 안전에 중요한 정보를 추측하지 않는다. 해당 값이 없으면 관련 절차를 확정하지 않고 교사에게 묻는다.
- 장비 설명서나 교사가 승인한 절차와 충돌하면 그 부분을 알린다. 다른 장비의 설정값을 가져다 쓰지 않는다. 최신 안전 근거를 확인할 수 없다면 그 한계를 명시한다.
- 사진에서 학생 얼굴·이름·계정·파일 목록 등 불필요한 개인정보를 제거하거나 가린 자료를 사용한다. 사진과 프로그램 화면의 사용 권한도 확인한다.

## 사진과 절차

- 실제 장비 사진과 확인된 프로그램 화면만 사용한다. 버튼·단자·극성·메뉴 이름을 사진과 대조한다. 보이지 않는 조작이나 저장 동작을 만들어 설명하지 않는다.
- 사진이 없으면 필요한 촬영 목록과 빈 배치 초안까지만 만들 수 있다. 가짜 장비 사진·측정 화면·버튼을 만들어 완성된 절차처럼 제시하지 않는다.
- 사진은 원본 비율을 유지한다. 필요한 부분만 잘라도 방향·연결 상태·안전 정보가 빠지지 않게 한다. 사진 위에는 벡터 번호·연결선·라벨을 얹고 조작할 부분을 가리지 않는다.
- 설명 번호와 사진 번호가 일치해야 한다. 다른 실험의 화면을 단순 위치 예시로 쓰려면 교사 확인을 받고 그 사실을 표시한다.
- 회로도나 배치도를 추가한다면 교사가 확인한 연결과 일치하는 벡터 모식도로 그린다. 실제 사진이나 검증된 연결을 대신하는 근거로 사용하지 않는다.
- 관찰·측정 결과 칸은 빈칸으로 둔다. 측정값이나 성공한 실험 결과를 지어내지 않는다. 정답·예상 결과는 요청받은 경우에만 별도로 다루고 실측과 구분한다.

## 구성과 디자인

- `photo-manual`은 A4 가로, 흰 배경과 파란 강조, 큰 사진 중심이다. 한 쪽에 한 가지 주요 행동을 두고 긴 설명은 나눈다.
- 제목은 대략 28~32pt, 본문은 11~13pt에서 시작하되 실제 출력 크기와 자료량에 맞게 조정한다. 작은 사진을 키워 흐리게 만들거나 글자를 과도하게 줄이지 않는다.
- 각 단계는 짧은 행동 지시와 확인할 항목으로 쓴다. 교사의 해설과 학생의 조작 지시를 섞지 않는다.
- 준비·연결·설정·측정·저장·정리 중 이번 실험에 필요한 범위를 사용한다. 없는 절차를 형식에 맞추려고 추가하지 않는다.
- 안전 경고는 해당 행동 앞이나 옆에 둔다. 색뿐 아니라 제목·표식으로도 구분한다. 일반적인 주의 문구로 실험별 안전 조건을 대신하지 않는다.
- `checklist`는 A4 세로 관찰·준비·정리 기록지다. 실제 사용하는 항목만 넣고 수량·단위·기준을 확인한다. 날짜·모둠·관찰·확인란은 비워 둔다.
- 진행 표시·쪽 참조·그림 번호는 실제 순서와 일치시킨다. 새로운 측정, 기존 결과 삭제, 저장, 프로그램 종료를 명확히 구분한다.

## PDF 제작

1. ReportLab 등으로 텍스트·선·사진 번호를 편집 가능한 상태로 배치한다. 사용자가 다른 편집 형식을 요청했다면 따른다.
2. 현재 환경에서 사용할 수 있는 한글 글꼴과 임베딩 조건을 확인한다. 사진 파일은 제작 폴더에 보관하고 임시 첨부 경로에 의존하지 않는다.
3. 용지·여백·제목·바닥글·페이지 번호를 일관되게 관리한다. 사진 위 번호의 연결선이 실제 조작 대상을 가리키는지 확인한다.
4. 제공된 로고를 사용할 때는 원본 비율을 유지한다. 이 지침의 HNR TECH 표시는 배포 자료의 제작자 표식이다. 다른 교사의 산출물에 제작자 이름·연락처·브랜드를 자동으로 넣지 않는다.

## 확인과 전달

- PDF를 다시 열어 쪽수·용지 크기·번호·단위·파일 이름·쪽 참조를 확인한다.
- Poppler 등으로 모든 쪽을 새 PNG로 렌더링하고 직접 본다. 글자 잘림·겹침·깨짐·빈 페이지·사진 왜곡·번호 위치·작은 버튼의 가독성을 확인한다.
- 사진과 문장을 함께 보며 단계별로 따라 읽는다. 단자·극성·버튼·수집 조건·저장 범위·정리 지시가 실제 자료와 일치하는지 확인한다.
- 수정한 절차와 모순되는 문장이 다른 쪽에 남아 있는지 찾는다. 특히 결과를 지우는 동작은 재실험 안내와 구별한다.
- 안전 조건이나 사진이 확인되지 않은 단계가 남으면 미완성임을 명시한다. 교사의 확인 없이 학생 배포용 완료본이라고 하지 않는다.
- PDF와 수정 가능한 생성 코드 또는 편집 원본을 함께 제공한다. 재배포 허용 범위 안의 필요한 사진만 포함하고 개인정보·개인 경로·재배포 불가 글꼴은 제외한다.
