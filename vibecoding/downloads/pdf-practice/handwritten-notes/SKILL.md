# 손글씨 정리본·단권화

![HNR TECH](../assets/hnr-tech-mark.webp)

손글씨 느낌은 한글 글꼴과 선·도형의 배치로 만든다. 본문을 그림으로 생성하지 않으므로 글자와 내용을 계속 수정할 수 있다. 이 파일만 첨부해도 사용할 수 있다.

## 자료와 정리 범위

- 과목·대상·단원, 교사가 강조한 부분, 사용할 원자료, 제외할 내용, 용지·쪽수를 확인한다. 자료에 있는 정보는 다시 묻지 않는다.
- 수업에서 사용하는 용어와 설명 순서를 우선한다. 서로 다른 자료에서 같은 개념을 다르게 설명하면 임의로 합치지 말고 차이를 알린다.
- 요약 때문에 조건·예외·인과관계가 빠지지 않게 한다. 정의·원리·예·비교를 구별한다. 외우기 쉬운 표현이 정확한 설명을 대신하지 않게 한다.
- 확인되지 않은 성취기준이나 출처를 만들지 않는다. 외부 내용을 보충하면 원자료와 구별하고 교사의 범위 확인을 받는다.
- 학생 개인정보는 제외한다. 교과서·문제집·사진·지문의 복제 및 배포 권한을 확인하고 허가되지 않은 자료를 통째로 재현하지 않는다.

## 구성

- 핵심어, 정의, 비교할 항목, 필요한 도식, 교사가 강조한 표현을 먼저 묶는다. 내용에 맞춰 소제목과 쪽 구성을 정한다.
- `grid-notes`는 연한 모눈 위에 손글씨 본문과 도식을 배치한다. `cornell`은 왼쪽 핵심어·질문, 오른쪽 정리, 아래 요약 칸으로 나눈다.
- 학생이 직접 쓰는 칸과 이미 채워진 설명을 구분한다. 코넬 노트의 모든 칸을 AI가 채울지, 일부를 비울지는 요청을 따른다.
- 단권화는 자료를 많이 넣는 것이 아니라 중복 설명을 합치고 필요한 관계를 보이게 하는 작업이다. 읽기 어려울 정도로 작은 글씨로 압축하지 않는다.
- 1단·2단과 쪽수는 내용에 맞게 정한다. 이전 예시의 쪽수나 특정 단원 색을 다른 과목에 강제하지 않는다.

## 글꼴과 시각 요소

- 현재 환경에 있는 한글 손글씨 TTF와 PDF 임베딩 조건을 확인한다. 적합한 글꼴이 없으면 읽기 좋은 한글 글꼴로 초안을 만들고 차이를 알리거나, 사용자가 합법적으로 제공한 글꼴을 받는다.
- 손글씨 글꼴에서도 숫자·영문·괄호·수학 기호·첨자·단위가 표시되는지 확인한다. 다른 글꼴로 보완하면 해당 글꼴의 실제 폭으로 다시 배치한다.
- 본문·제목·강조의 차이를 유지한다. 형광펜, 밑줄, 색은 필요한 부분에만 쓴다. 모눈과 장식은 본문보다 옅게 하고 흑백 인쇄에서도 핵심 내용이 읽히게 한다.
- 도표·그래프·회로·기하 도형은 SVG나 PDF 벡터로 작성한다. 화살표의 방향, 연결 관계, 축·단위, 라벨 위치를 내용과 대조한다. 정확한 설명이 필요한 그림을 생성형 삽화로 대신하지 않는다.
- 실제 사진이 필요하면 출처와 사용 권한을 확인한다. 사진의 의미를 바꾸는 변형을 하지 않는다.

## PDF 제작

1. Python ReportLab 등으로 한글 텍스트와 벡터를 배치한다. 사용자가 기존 편집 형식을 지정했다면 그 형식을 유지한다.
2. 용지·여백·글꼴·색을 한 곳에서 관리한다. 모든 단위와 좌표계는 일관되게 사용한다.
3. 실제 글꼴로 문장 폭을 계산하고 줄 수에 따른 높이를 확보한다. 그림·텍스트·표·바닥글이 겹치지 않게 배치한다.
4. 여러 쪽이라면 대표 1~2쪽을 먼저 확인하고 같은 배치 원칙을 이어 간다. 내용에 맞지 않는 칸을 억지로 반복하지 않는다.
5. 로고를 요청받았다면 원본 비율을 유지한다. 이 지침의 HNR TECH 표시는 배포 자료의 제작자 표식이며, 다른 교사의 산출물에는 자동으로 넣지 않는다.

## 확인과 전달

- 최종 PDF를 다시 열어 쪽수·용지 크기·텍스트·필수 기호·페이지 번호를 확인한다.
- Poppler 등으로 모든 쪽을 새 PNG로 렌더링하고 직접 본다. 한글 깨짐·잘림·겹침·희미한 본문·사진 왜곡·읽기 어려운 손글씨가 없는지 확인한다.
- 실제 인쇄 크기에서 작은 라벨·첨자·각주가 읽히는지, 쓰기 칸이 충분한지 확인한다. 글자를 줄이는 대신 내용을 덜거나 쪽을 나누는 방법을 우선한다.
- 원자료와 비교해 조건·예외·단위·부호·화살표·표의 대응이 정확한지 다시 확인한다. 예쁘게 보인다는 이유로 내용 검증을 생략하지 않는다.
- 수정 후에는 PDF와 렌더 이미지를 다시 만든다. 검수하지 못한 부분은 분명히 알린다.
- 최종 PDF와 수정 가능한 코드 또는 편집 원본을 제공한다. 필요하면 쪽별 PNG를 추가한다. 재배포 권한 없는 글꼴·원자료·개인 경로는 포함하지 않는다.
