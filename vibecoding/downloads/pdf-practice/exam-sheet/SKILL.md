# 인쇄용 문제지

![HNR TECH](../assets/hnr-tech-mark.webp)

이 지침은 교사의 자료를 문제지 PDF로 만드는 연수용 제작 지침이다. 문항의 타당성과 실제 수업 범위는 교사가 최종 확인한다. 이 파일만 첨부해도 사용할 수 있다.

## 먼저 확인할 것

- 과목·대상·단원, 다룰 내용과 제외할 내용, 문항 수·유형, 풀이 공간, 용지·쪽수, 정답지 필요 여부를 확인한다. 이미 주어진 내용은 다시 묻지 않는다.
- 기존 문항의 편집인지 새 문항의 작성인지 구분한다. 편집만 요청했다면 발문·선지·정답을 임의로 바꾸지 않는다. 오류가 의심되면 표시하고 확인받는다.
- 성취기준은 제공된 자료나 확인한 공식 출처를 사용한다. 코드·인용문·출처를 만들어 넣지 않는다.
- 학생 이름·학번·성적은 받지 않는다. 이름 칸이 필요하면 빈칸으로 둔다. 첨부 자료에 불필요한 개인정보가 있으면 제거를 요청한다.

## 문항 구성

- 새 문항은 교사가 허용한 학습 범위 안에서 작성한다. 문제집의 표현이나 수치만 바꿔 새 문항이라고 하지 않는다. 자료·사진·지문·문항의 사용 및 배포 권한을 확인한다.
- 한 문항의 발문과 선지가 같은 대상을 묻도록 한다. 자료 해석 문항은 제시된 자료로 판단할 수 있어야 한다.
- 객관식은 정답의 유일성과 오답의 근거를 각각 확인한다. 선지는 표현·길이·문법을 맞추고, 답을 불필요하게 드러내는 상보적 선지나 조합은 피한다. 오답에는 해당 수업에서 다룬 개념상의 혼동을 사용한다.
- 5지 선다형을 억지로 만들지 않는다. 문항에 맞는 선지 수 또는 다른 문항 유형을 교사와 정한다. 정답 번호를 검토하되 분포를 맞추려고 문항을 훼손하지 않는다.
- 서술형은 답할 범위·조건을 명시한다. 정답지를 요청했다면 모범답안, 허용 가능한 답, 부분점수 기준을 함께 검토한다. 학생의 답을 AI가 자동 채점하는 기능은 이 작업에 포함하지 않는다.
- 계산 문항은 직접 다시 풀어 정답·단위·유효숫자를 점검한다. 그래프의 축·눈금·단위·범례와 본문 수치가 일치해야 한다.
- 교사가 제공한 실측값과 교육용 예시 데이터를 구별한다. 새로 만든 데이터는 예시라고 명시하고 실제 실험 결과나 학생 자료로 제시하지 않는다.

## 배치와 디자인

- 기본은 A4 세로 흰 바탕이다. `mono-exam`은 흑백 시험지, `blue-worksheet`는 파란색 학습지다. 사용자가 다른 형식을 골랐다면 그 요청을 우선한다.
- 1단·2단은 문항과 풀이 공간에 맞게 정한다. 긴 지문·표·그래프는 무리하게 좁은 단에 넣지 않는다.
- 인쇄 여백은 약 12~15mm부터 시작하고 제본·양면 인쇄 여부를 반영한다. 글자 크기는 실제 인쇄 크기에서 읽히게 조정한다. 쪽수를 맞추려고 글자를 계속 줄이지 않는다.
- 문항 번호·발문·그림·선지는 가능한 한 같은 쪽에 둔다. 나눠야 한다면 연속임을 표시한다. 풀이 칸은 실제 답안 분량을 고려한다.
- 학생용 문제지에는 답을 노출하지 않는다. 정답지 파일을 따로 만들거나 문서 뒤에 분리하되 교사의 선택을 따른다.
- 색만으로 정답·분류·곡선을 구분하지 않는다. 흑백 출력에서도 선 모양·번호·문자 표식으로 읽혀야 한다.

## PDF 제작

1. 편집 가능한 코드나 원본에서 PDF를 생성한다. 정밀 배치에는 Python ReportLab을 사용할 수 있다. 기존의 다른 제작 형식을 지정했다면 유지한다.
2. 사용 가능한 한글 글꼴과 PDF 임베딩 허용 범위를 확인한다. 글꼴의 실제 문자 폭으로 줄바꿈과 높이를 계산한다. 한글·수식·첨자·특수기호의 누락을 확인한다.
3. 도형·수학 그래프·회로도는 검증 가능한 SVG 또는 PDF 벡터로 만든다. 생성형 이미지 속의 글자나 부정확한 설명 그림으로 대체하지 않는다.
4. 제목·표·문항·풀이 칸·바닥글의 영역을 구분한다. 내용이 넘치면 배치나 쪽수를 조정한다.
5. 로고를 요청받았다면 제공된 파일의 비율을 유지한다. 이 지침의 HNR TECH 표시는 배포 자료의 제작자 표식이며, 다른 교사의 산출물에 자동으로 넣지 않는다.

## 확인과 전달

- 저장한 최종 PDF를 다시 열어 실제 쪽수·용지 크기·페이지 번호·문항 번호·배점을 확인한다. 배점이 있다면 합계도 다시 계산한다.
- Poppler 등 사용 가능한 도구로 모든 쪽을 새 PNG로 렌더링하고 직접 본다. 텍스트 추출이나 생성 성공만으로 검수가 끝난 것으로 판단하지 않는다.
- 한글 깨짐·잘림·겹침·표 분할·빈 페이지·흑백 대비·풀이 공간을 확인한다. 수정했다면 최종 PDF를 다시 렌더링한다.
- 정답지는 최종 문제지와 대조한다. 문항 순서를 바꾼 뒤 번호와 해설이 어긋나지 않았는지 확인한다.
- 렌더링·글꼴·문항 검증을 완료하지 못했다면 그 항목을 명시한다. 미검수본은 완성본이라고 말하지 않는다.
- PDF와 수정 가능한 생성 코드 또는 편집 원본을 함께 전달한다. 사용한 이미지·글꼴은 재배포가 허용된 것만 포함한다. 원자료·개인정보·개인 컴퓨터 경로는 묶지 않는다.
