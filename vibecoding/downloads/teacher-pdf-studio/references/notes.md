# 손글씨 정리본·단권화·학습지

## 원자료 정리

원자료의 제목과 쪽 번호를 기록하고, 정리본에 포함할 내용이 어느 자료에서 왔는지 작업 중 추적할 수 있게 한다. 교사가 강조한 표현과 교육과정에서 요구한 범위를 구분한다. PDF 글자를 추출했어도 원본 그림·표·각주를 함께 확인한다.

단권화는 자료를 줄여 붙이는 작업이 아니다. 개념의 연결, 자주 틀리는 비교, 수업에서 사용한 그림을 제한된 분량 안에 재구성한다. 원자료에 없는 내용을 추가했다면 교사에게 구분해 알린다.

## 배치

- A4 인쇄가 목적이면 210×297mm를 사용한다. PDF 좌표는 1인치=72pt이며 A4는 약 595.28×841.89pt이다.
- 2단 배치는 실제 사례에서 사용했지만 필수는 아니다. 그림 크기와 내용 흐름에 맞춰 1단·2단을 고른다.
- 제목·본문·그림·설명·페이지 번호의 영역과 최소 여백을 정한다.
- 본문 11~14pt, 제목 20~28pt 정도에서 시작하되 글꼴의 실제 크기와 인쇄 결과로 조정한다. 이 범위에 맞추려고 읽기 어려운 글자를 억지로 유지하지 않는다.
- 문장을 나눌 때는 실제 글꼴의 폭을 계산한다. 줄 수가 늘어나면 다음 블록의 시작 좌표도 바꾼다.
- 넘치는 내용을 감추거나 페이지 밖으로 보내지 않는다. 글을 줄이거나 블록을 옮기고 필요하면 쪽수를 조정한다.

## 손글씨 스타일

실제 사례는 한글 손글씨 TTF, 연한 모눈, 형광펜 모양의 강조, 선·원·화살표 등을 ReportLab canvas에 배치했다. 사용 글꼴은 나눔손글씨 바른히피였으며, 표시되지 않는 기호에는 보조 글꼴을 사용했다. 같은 글꼴을 반드시 쓸 필요는 없다.

- 모눈과 강조색보다 본문이 먼저 읽혀야 한다.
- 강조는 핵심 개념에만 사용한다. 문장 전체를 반복해서 칠하지 않는다.
- 손글씨의 불규칙함을 흉내 내느라 글자·기호를 기울이거나 알아보기 어렵게 만들지 않는다.
- 배경과 과학 도식을 생성형 이미지 한 장으로 대체하지 않는다.
- 종이에 인쇄할 자료는 화면 확대본뿐 아니라 실제 크기로도 확인한다.

## 학습지

빈칸판과 정답판이 필요하면 동일한 내용 원본에서 생성한다. 빈칸으로 가린 개념과 정답이 일치하는지, 빈칸에 쓸 공간이 충분한지 확인한다. 학생용에는 교사용 해설이나 정답이 실수로 남지 않게 한다.

페이지 번호와 총 쪽수는 최종 문서에서 계산한다. 과거 코드의 고정 쪽수 값을 복사하지 않는다.

## 전달할 것

최종 PDF, 수정 가능한 원본, 필요한 경우 학생용·정답판을 구분해 전달한다. 생성 코드는 글꼴·입력·출력 경로를 사용자 환경에 맞게 바꿀 수 있게 한다.
