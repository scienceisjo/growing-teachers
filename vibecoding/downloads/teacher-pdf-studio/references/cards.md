# 개념 카드

## 내용

정리본 한 쪽을 작게 축소해 카드로 쓰지 않는다. 개념 하나를 중심으로 제목·필수 설명·그림·짧은 확인 질문을 다시 배치한다. 카드 수를 늘리기 위한 중복 설명이나 무의미한 표지는 넣지 않는다. 표지 유무와 전체 장수는 사용자 요청을 따른다.

## 크기와 제작

실제 가로형 카드 사례는 가로 5:세로 4 비율의 PDF를 먼저 만들고 1350×1080px PNG로 출력했다. PDF 내부 크기는 약 744.095×595.276pt였다. 이는 해당 사례의 규격이지 모든 플랫폼의 권장 규격이라는 뜻은 아니다.

- 인쇄, 휴대전화 열람, 게시 등 용도에 맞게 비율과 출력 크기를 정한다.
- 한글 TTF와 벡터 도형을 사용하고, 카드 크기에 맞춰 본문 글자를 다시 정한다.
- 제목, 본문, 그림, 출처·페이지 번호 영역을 나눈다.
- 글자가 많아지면 줄이거나 카드를 나눈다. 휴대전화에서 확대해야 겨우 읽히는 상태로 마무리하지 않는다.
- 표지를 이미지로 만들어도 본문은 별도로 편집할 수 있게 유지한다.

## PDF → PNG

최종 PDF의 비율과 목표 이미지 비율이 같을 때 Poppler 예시는 다음과 같다.

    pdftoppm -png -scale-to-x 1350 -scale-to-y 1080 cards.pdf card

이 명령은 5:4 PDF 예시다. 다른 비율의 PDF에 그대로 사용하면 그림이 늘어나거나 눌릴 수 있으므로 목표 치수를 먼저 계산한다. 실행 파일 위치와 파일명은 현재 환경에서 확인한다.

## 확인과 묶음

1. PDF 실제 쪽수와 PNG 수가 같은지 확인한다.
2. 모든 PNG의 크기와 비율을 확인한다.
3. 파일명은 01, 02처럼 순서가 유지되게 한다. 파일 정렬을 문자 순서에만 맡겨 1, 10, 2가 되지 않도록 한다.
4. 작은 모아보기 이미지는 빠진 카드와 전체 통일성을 확인하는 용도로 사용한다. 작은 미리보기만 보고 본문 검수를 끝내지 않는다.
5. 모든 카드를 원래 크기로 열어 글자·그림·하단 여백을 확인한다.
6. ZIP을 다시 열어 파일 순서·장수·무결성을 확인한다.

수정이 생기면 PDF와 PNG를 함께 다시 출력한다. 이전 PNG와 최신 PDF를 섞어 배포하지 않는다.
