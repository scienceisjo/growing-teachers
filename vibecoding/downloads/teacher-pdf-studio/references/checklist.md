# 최종 확인

자동 검사와 눈으로 하는 검사를 구분한다. 검사 도구가 통과했다는 이유만으로 과학 내용과 배치까지 맞는 것은 아니다.

## 내용

- [ ] 교사가 제공한 자료와 핵심 개념이 대응한다.
- [ ] 빠뜨린 개념과 새로 추가한 설명을 구분했다.
- [ ] 수식, 단위, 부호, 화살표, 그림의 연결을 확인했다.
- [ ] 원자료에 없는 성취기준 번호·출처·사실을 만들지 않았다.
- [ ] 문항을 추가했다면 정답·해설·학생용 표시를 확인했다.
- [ ] 학생 개인정보나 공개 권한이 없는 자료가 들어 있지 않다.

## PDF 자동 확인

- [ ] 저장한 PDF를 다시 열 수 있다.
- [ ] 실제 쪽수, 용지 크기, 페이지 번호가 일치한다.
- [ ] 의도한 본문 텍스트를 추출할 수 있다.
- [ ] 한글, 수학 기호, 첨자, 단위에 빈 글자나 대체 문자가 없다.
- [ ] 좌표 검사로 페이지 경계 밖 요소를 찾았다. 이 검사로 모든 겹침을 찾았다고 주장하지 않는다.

## 모든 쪽의 화면 확인

- [ ] 제목·본문·그림·각주가 겹치거나 잘리지 않는다.
- [ ] 글꼴·선 두께·강조색·여백이 일정하다.
- [ ] 화면을 확대하지 않아도 읽을 수 있다.
- [ ] 그림과 설명이 멀리 떨어져 있지 않다.
- [ ] 쪽 경계에서 문장·표·그림이 부자연스럽게 끊기지 않는다.
- [ ] 수정 후 다시 렌더링한 최신 화면으로 확인했다.
- [ ] 인쇄 자료는 실제 용지 크기와 인쇄 여백도 확인했다.

## 카드와 배포

- [ ] PDF와 PNG의 장수·비율·순서가 일치한다.
- [ ] 번호가 01, 02 순서로 정렬된다.
- [ ] ZIP을 다시 열어 파일 누락·손상 여부를 확인했다.
- [ ] 글꼴 파일을 포함했다면 재배포 조건을 확인했다.
- [ ] 수정 가능한 원본과 필요한 파일만 포함했다.
- [ ] 남아 있는 오류·미검증 항목을 숨기지 않았다.
