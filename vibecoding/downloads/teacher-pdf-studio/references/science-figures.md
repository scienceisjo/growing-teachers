# SVG와 PDF 벡터 그림

## 어떤 경우에 사용하는가

회로, 입자 모형, 화살표, 축, 기하 도형, 개념 관계처럼 선과 글자가 중요하고 반복해서 수정해야 하는 그림에 사용한다. SVG는 그림의 정확성을 자동으로 보장하지 않는다.

PDF를 만들기 위해 모든 그림을 SVG로 저장해야 하는 것은 아니다. 실제 정리본 제작에서는 ReportLab으로 선·원·기호를 직접 그린 경우도 많다.

## 먼저 정할 것

- 그림이 설명할 개념과 생략할 요소
- 실제 비율인지, 과장한 모형인지
- 보존할 개수·방향·연결 관계
- 선·기호·색의 의미
- 라벨과 설명이 놓일 위치

보기 좋게 배치하기 전에 이 조건을 확인한다.

## SVG

- viewBox와 출력 크기를 명시한다.
- 획 두께, 화살표 끝, 긴 라벨까지 포함하는 여백을 둔다.
- 관련된 선·기호·라벨은 같은 그룹으로 구성해 수정할 때 함께 이동한다.
- PDF로 변환할 때 한글 글꼴·마커·투명도·필터가 동일하게 출력되는지 확인한다. 지원되지 않는 효과는 단순한 도형으로 바꾼다.
- SVG는 편집 원본으로 유지한다. 인쇄용 PNG만 전달해 수정 가능성을 없애지 않는다.
- 벡터이므로 선명하게 확대되더라도 설명 내용이 맞는지는 별도 검토한다.

## 과학 그림 확인 예시

- 회로: 끊긴 선, 의도하지 않은 교차 연결, 전류계의 직렬 연결, 전압계의 병렬 연결, 전지 극성, 단위.
- 입자 모형: 입자 수와 종류, 크기, 경계 밖 입자, 조건 변화에 따른 화살표의 의미.
- 그래프: 축 이름과 단위, 눈금, 표시 범위, 선과 데이터의 대응.
- 천체 모형: 관찰자와 시선, 각도의 기준, 크기·거리의 과장 여부.

회로 기호의 모양은 교사가 제공한 교재·수업 자료의 표기 관례에 맞춘다. 다만 틀린 연결 관계를 그대로 복제하지 않는다.
