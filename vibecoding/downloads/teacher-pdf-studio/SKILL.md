# 교사용 PDF 제작

이 지침은 조승재 교사의 실제 손글씨 정리본·개념 카드 제작 과정을 연수용으로 정리한 것이다. 과거 작업에 이 이름의 스킬이 설치되어 있었다는 뜻은 아니다.

## 자료와 범위

- 교사의 학습지, 수업 메모, 정리 노트, 교육과정 자료를 먼저 확인한다. 학생 개인정보나 불필요한 문서는 요청하지 않는다.
- 과목·대상·사용 목적·필요한 형식·쪽수·강조할 내용 중 빠진 것만 확인한다. 주어진 자료로 판단할 수 있으면 다시 묻지 않는다.
- 원자료의 개념과 수업 순서를 우선한다. 빠진 내용, 서로 충돌하는 설명, 과학적으로 의심되는 부분을 구분해 알린다. 확인되지 않은 성취기준 번호를 만들지 않는다.
- 내용이 많으면 문장을 줄이거나 쪽수를 늘린다. 읽기 어려울 정도로 글자를 줄여 정해진 쪽수에 넣지 않는다.
- 기존 자료 수정에서는 요청하지 않은 내용·디자인을 보존한다. 공개하지 않은 자료를 임의로 외부에 업로드하거나 배포하지 않는다.

## 제작 방식

1. 원자료에서 제목·핵심 개념·필수 그림·교사가 강조한 표현을 정리하고, 페이지 또는 카드별 배치를 만든다.
2. 기본 방식은 Python ReportLab으로 PDF를 직접 생성하는 것이다. 사용자가 다른 형식이나 기존 제작 방식을 지정했다면 따른다.
3. 손글씨 효과는 사용 가능한 한글 TTF 글꼴, 모눈, 강조선, 도형 배치로 구현한다. 페이지 전체를 생성형 이미지로 만들어 글자를 굳히지 않는다.
4. 회로·입자·화살표·그래프는 ReportLab 도형이나 SVG로 만든다. 그림이 보기 좋다는 이유만으로 과학적으로 맞다고 판단하지 않는다.
5. 페이지 크기·여백·글꼴·색을 한 곳에서 관리한다. 문장 폭은 실제 글꼴로 계산하고, 줄 수에 따른 높이를 반영한다. 표·그림·설명·각주 영역이 겹치지 않게 한다.
6. 여러 쪽을 처음 만들 때는 대표 1~2쪽을 먼저 확인한다. 동일한 형식의 반복 작업은 검증한 배치를 재사용한다.

쪽수와 카드 장수는 사용자가 정한다. 과거 예시의 6쪽·15장·가로 5:4를 모든 자료에 강제하지 않는다.

## 글꼴과 그림

- 현재 환경에서 글꼴 파일과 사용 조건을 확인한다. 다른 컴퓨터의 절대경로를 그대로 쓰지 않는다.
- 한글·수학 기호·첨자·단위가 표시되는지 확인한다. 보조 글꼴을 쓴 경우 그 글꼴로 폭을 다시 계산한다. 깨진 문자를 숨기거나 임의의 기호로 바꾸지 않는다.
- 글꼴 파일은 재배포 허용 범위를 확인한 경우에만 묶는다. 이 배포 자료에는 글꼴 파일이 들어 있지 않다.
- SVG에는 viewBox와 출력 크기를 지정한다. 선 끝·화살표·라벨이 영역 밖으로 잘리지 않도록 여백을 둔다.
- 로고가 제공되면 원본 비율을 유지한다. 이 묶음의 HNR TECH 표시는 배포 자료의 제작자 표식이며, 참여 교사의 결과물에 강제로 넣지 않는다.

## PDF 확인

- 저장 후 다시 열어 실제 쪽수·용지 크기·텍스트 추출·필수 기호를 확인한다. 페이지 번호의 분모는 실제 쪽수와 일치시킨다.
- Poppler 등 사용 가능한 렌더러로 모든 쪽을 PNG로 만든다. 자동 검사만으로 검수가 끝났다고 하지 않는다.
- 모든 쪽에서 잘림·겹침·한글 깨짐·여백·그림과 설명의 연결을 눈으로 확인한다. 문제가 있으면 원본 코드를 수정하고 다시 PDF와 PNG를 만든다.
- 수식·단위·부호·화살표·도식의 연결과 원자료 반영 여부를 별도로 검토한다. 수정 뒤에는 관련된 다른 쪽도 확인한다.
- 렌더링 도구나 필요한 글꼴이 없으면 무엇을 검증하지 못했는지 밝힌다. 확인하지 못한 결과를 검수 완료로 표시하지 않는다.

## 출력

- 최종 PDF와 수정 가능한 생성 코드 또는 원본을 함께 남긴다.
- 카드 이미지를 요청하면 최종 PDF를 순서대로 PNG로 변환한다. 원래 비율을 유지하며, 장수·치수·순서·파일명을 확인한다.
- ZIP을 요청하면 최종 파일만 포함하고 압축을 다시 열어 목록과 무결성을 확인한다. 임시 파일·개인 경로·원자료·학생 정보는 넣지 않는다.
- 완료 시 만든 파일, 확인한 항목, 남은 확인 사항을 짧게 알린다.
