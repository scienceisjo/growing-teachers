# PDF 제작 자료 사용법

## 이 파일은 무엇인가요?

SKILL.md는 AI가 작업할 때 참고하는 지침서입니다. PDF를 자동으로 만드는 프로그램이나 글꼴 설치 파일은 아닙니다.

실제 손글씨 단권화와 개념 카드를 만들 때 썼던 방식을 정리했습니다. 원본 제작 코드에 들어 있던 개인 컴퓨터 경로, 단원별 고정 내용, 배포 관련 파일은 포함하지 않았습니다.

## 사용하는 순서

1. ZIP을 풀고 SKILL.md를 확인합니다.
2. 파일을 만들거나 코드를 실행할 수 있는 AI 작업 환경에 SKILL.md와 본인의 수업 자료를 첨부합니다.
3. 정리본이면 references/notes.md, 카드면 references/cards.md를 함께 첨부합니다. references/checklist.md도 첨부하면 상세 검수 항목을 전달할 수 있습니다.
4. 대상, 필요한 형식, 분량, 수업에서 강조한 내용을 알려 줍니다. examples/요청예시.md에 예시가 있습니다.
5. 대표 한두 쪽을 먼저 확인하고, 내용과 디자인을 고친 뒤 전체를 제작합니다.
6. 완성된 PDF의 모든 쪽을 직접 확인합니다. PDF뿐 아니라 수정 가능한 원본도 받습니다.

사용하는 AI가 파일을 만들 수 없다면 코드나 내용 초안까지만 받을 수 있습니다. 이 지침 파일을 올렸다고 PDF 생성 기능이 새로 생기지는 않습니다. 앱마다 스킬 설치 방식도 다르므로, 이 묶음에서는 특정 앱의 설치를 전제로 하지 않습니다.

## 실제로 만든 방식

- 손글씨 정리본: 수업 자료 정리 → 한글 글꼴·도형을 ReportLab으로 배치 → PDF → 쪽별 이미지 확인 → 수정
- 개념 카드: 같은 개념을 카드 크기에 맞게 다시 편집 → 카드 PDF → PNG → 순서대로 ZIP
- 과학 그림: SVG 또는 PDF 안의 선·도형으로 제작 → 좌표·연결·부호·내용 확인

손글씨처럼 보이는 본문도 글꼴로 쓴 것입니다. PDF 모든 쪽을 AI 그림으로 생성한 것이 아닙니다.

## 준비할 자료

- 본인 학습지 또는 정리할 수업 자료
- 수업에서 강조한 내용과 학생들이 자주 헷갈린 내용
- 대상 학년·과목, 원하는 쪽수 또는 카드 수
- 사용 가능한 글꼴이나 참고 디자인이 있다면 해당 자료

학생 이름·성적·연락처는 지우고 첨부합니다. 출판사 교재를 그대로 재현해 공개 배포하지 않습니다. 글꼴은 해당 배포처의 사용 조건을 확인하고 준비합니다. 이 묶음에는 글꼴 파일이 없습니다.

## 묶음 안의 파일

- SKILL.md: AI에게 전달하는 기본 지침
- references/notes.md: 정리본·학습지 제작
- references/cards.md: 개념 카드 제작과 이미지 출력
- references/science-figures.md: SVG·벡터 그림
- references/checklist.md: 내용·화면·출력 검수
- examples/요청예시.md: 자료를 첨부할 때 사용할 요청 예시
- assets/hnr-tech-mark.webp: 이 안내 자료의 제작자 표식

이 자료는 제작 절차를 공유하기 위한 것입니다. 원본 수업 자료의 재배포 권한이나 글꼴 라이선스를 대신하지 않습니다.
