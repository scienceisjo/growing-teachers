# 수업 페이지 규격서

AI가 수업 페이지(표지 + 학습 5단계 탭)를 만들 때 지키는 규칙입니다. 네 가지 수업 페이지 스킬이 같은 규격서를 씁니다.

## 1. 한눈에

- 페이지는 파일 네 개로 이뤄집니다: `index.html`(내용) · `theme.css`(색·글꼴·모서리) · `lesson.css`(부품 모양) · `lesson.js`(동작).
- **AI가 쓰는 파일은 `index.html` 하나입니다.** `lesson.css`와 `lesson.js`는 고치지 않습니다. 디자인을 바꿀 때는 `theme.css` 값만 바꿉니다.
- 진행도·빈칸·확인 문제·기록표·저장·교사 모드는 `lesson.js`가 처리합니다. 내용 쪽에서는 정해진 클래스와 `data-` 속성만 맞춰 쓰면 됩니다.
- 완성된 `index.html`에는 `【` 가 하나도 남지 않아야 합니다.

## 2. 짜임

| 구역 | 하는 일 | 자주 쓰는 부품 |
|---|---|---|
| 표지 | 오늘 무엇을 하는지 먼저 보여 주고 시작 단추를 누르게 합니다 | 단원 이름, 차시 제목, 부제, 단계 안내 5줄 |
| 1 생각 열기 | 질문을 던지고 학생이 먼저 생각하게 합니다. 정답을 알려 주지 않습니다 | `.card`, `.poe`(예측), `.note.myth` |
| 2 탐구하기 | 직접 해 보는 활동 하나, 해 본 결과를 적습니다 | `.embed`(시뮬 링크), `table.obs`(기록표), `textarea.reflect` |
| 3 개념 잡기 | 핵심 개념을 빈칸으로 꺼내 보게 합니다. 글만 나열하지 않습니다 | `.cloze-set`, `.term` |
| 4 적용하기 | 새 상황이나 생활 속에서 배운 것을 씁니다 | `.use`, `textarea.reflect` |
| 5 확인하기 | 오늘 목표를 확인하는 문제 3~5개와 한 줄 정리 | `.quiz`, `textarea.reflect` |
| + 더 알아보기 | 시험에 나오지 않는 이야기. 쓰지 않으면 구역과 탭 단추(`data-tab="t6"`)를 함께 지웁니다 | `.card` |

- 필수 탭은 5개를 넘기지 않습니다. 시뮬레이션이 여러 개여도 탭을 늘리지 않고 `.seg` 단추로 한 탭 안에서 바꿔 봅니다.
- 이 5단계는 탐구형 수업의 기본 틀입니다. 수업 성격이 다르면(분류, 논증, 절차 익히기) 단계 이름과 부품을 바꿔도 되지만, 바꾼 이유를 보고에 한 줄 적습니다.

## 3. 부품표

| 클래스 | 용도 | 지킬 것 |
|---|---|---|
| `.card` | 기본 상자 | 안에 다시 `.card`를 넣지 않습니다 |
| `.poe` + `.choice` + `.reveal` | 예측 질문. 고르면 설명이 열립니다 | 보기는 3개이고, 보기마다 학생이 그렇게 생각할 만한 까닭을 붙이면 좋습니다. **예측은 정답을 알려 주는 곳이 아닙니다.** `.reveal`에는 고른 까닭을 인정하는 말과 「2단계에서 직접 확인해요」를 쓰고 정답은 쓰지 않습니다. 정답 보기를 초록으로 칠하는 `data-hit`도 붙이지 않습니다. 정답은 2단계에서 관찰하고 3단계에서 정리합니다 |
| `.note.myth` | 흔한 오개념 | 반드시 「→ 실제로는」까지 씁니다 |
| `.note.class` | 교사용 메모 | 🧑‍🏫 모드를 켰을 때만 보입니다. 발문, 예상 답변, 되물을 말 |
| `.fig` | 그림 자리 | 그림이 없으면 학생 화면에서는 숨고 교사 모드에서만 자리 표시가 보입니다. 그림은 `<img>`나 `<svg>`로 |
| `.embed[data-src]` | 외부 시뮬레이션·영상 | `https://` 주소만. 화면이 안 뜰 때를 위해 「새 창에서 열기」가 자동으로 붙습니다 |
| `table.obs` | 기록표 | 머리글 칸 수가 곧 열 수. 학생이 칸을 눌러 적고, 표 복사 단추가 있습니다 |
| `table.cmp` | 정리용 비교표 | 학생이 적는 표가 아니라 보여 주는 표입니다. 칸 안에 `.cloze`를 넣어 빈칸으로 쓸 수 있습니다. 가로로 넘칠 수 있으니 `<div class="obs-wrap">`으로 감쌉니다. 학생이 적는 표는 `table.obs`이고 둘을 섞어 쓰지 않습니다 |
| `textarea.reflect` | 내 생각 쓰기 | `data-min`이 완료 기준 글자 수 |
| `.cloze-set` + `.cloze` | 빈칸 | 한 문장에 2개까지, 한 묶음에 4~10개(학습지형은 학습지 상자 하나를 그대로 한 묶음으로 쓰므로 이 개수를 벗어나도 됩니다). 핵심어 자리에만 뚫습니다. `data-ans` 정답, `data-c` 개념색(c1~c5), `data-no` 학습지 빈칸 번호 |
| `.term` | 용어 카드 | `style="--c:var(--c1)"`로 개념색을 지정합니다 |
| `.use` | 생활 사례 | 2~4개 |
| `.quiz[data-ans]` + `.opt` | 확인 문제 | `data-ans`는 정답 번호(1부터). 보기 앞의 ①②③④는 자동으로 붙습니다. 해설은 `.explain` |
| `.seg` + `.seg-pane` | 같은 단계 안의 갈래 | 단추의 `data-seg`와 칸의 `data-seg`를 맞춥니다. 둘은 같은 부모 안에 둡니다 |
| `.sim3d` | 3D 실험판 자리 | 3D 스킬에서만 씁니다 |

- 개념색: 용어 하나에 색 하나(`c1`~`c5`)를 정해 본문 `<b class="t1">`, 용어 카드, 빈칸 `data-c`에서 끝까지 같게 씁니다. 개념이 5개를 넘으면 색을 늘리지 말고 개념을 묶습니다.
- 진행도는 활동 하나(빈칸 묶음, 예측, 확인 문제, 생각 쓰기, 기록표)가 한 칸입니다. 활동이 하나도 없는 단계는 열어 보기만 해도 완료로 칩니다.

## 4. 글쓰기

- **말투**: 학생에게 하는 말은 해요체(「이상한 말 같죠?」). 개념 설명은 짧은 평서형(「매질은 제자리에서 진동만 한다.」). 교사 메모는 짧게.
- **문단**: 한 문단 3~4문장, 화면에서 5줄을 넘기지 않습니다. 중학생이 모르는 한자어는 처음 나올 때 괄호로 풀어 줍니다.
- **제목**: 구역 이름은 담백한 명사구로 씁니다(「자기장의 세기」). 별명은 탭 이름이 아니라 그 탭의 `h2`에만 씁니다.
- **지어낸 내용 금지**: 교과서나 선생님이 준 자료에 없는 수치, 실험 결과, 인용, 사례를 만들지 않습니다. 모르면 자리를 비우고 보고에 적습니다.
- **과학 정확성**: 개념이 틀리거나 오개념을 굳히는 문장이 없는지 확인합니다. 단순화한 부분은 「이 모형에서는 ~로 단순하게 나타냈어요」라고 밝힙니다.
- **AI 말투**: 아래 꼴은 쓰지 않습니다.
  - 표어형 제목(「선생님 학교에서도 그대로」), 끝을 자른 제목(「어디까지 되나」)
  - 단정 펀치라인(「이게 다입니다」, 「핵심은 결국 이것입니다」)
  - 「~할 때입니다」, 「X에서 Y로」 변환 공식, 「의미 있는 변화」 같은 추상어
  - 「이 단계가 끝나면 ~을 알게 됩니다」 같은 학습목표 문장
  - 질문을 던지고 화살표(→)로 바로 답하는 이야기체, 대시(—)로 이어 붙인 토막 문장
- 이모지는 표지와 단추 정도만 씁니다. 설명 문단 안에는 넣지 않습니다.

## 5. 디자인 바꾸기

- 기본 모양은 `theme.css`에 있습니다. DESIGN.md를 받았으면 `theme.css`의 변수 값만 그 문서의 색·글꼴·모서리로 바꿉니다.
- 변수와 맞추는 곳: `--bg`(바탕) · `--surface`(상자 바탕) · `--surface2`(옅은 면) · `--ink`(글자) · `--accent`(단추·강조) · `--accent-ink`(강조색 위 글자) · `--accent-soft`(강조색 옅은 면) · `--accent-text`(흰 상자 위 글자에 쓰는 강조색. 강조색이 노랑·주황처럼 밝으면 진한 색으로 따로 정합니다) · `--line`(경계선) · `--font`(본문 글꼴) · `--font-head`(제목 글꼴) · `--head-w`(제목 굵기) · `--r`·`--r-sm`(모서리) · `--bw`(상자 테두리 굵기) · `--shadow`(상자 그림자, 없으면 `none`) · `--shadow-btn`(단추 그림자).
- 한글 글꼴은 `theme.css` 맨 위에서 불러옵니다(`@import url(...)`). 설계서가 영문 전용 글꼴을 쓰면 한글은 Pretendard로 대신합니다.
- 주소 끝에 `#t3`처럼 붙이면 표지를 건너뛰고 그 탭(t1~t6)을 바로 엽니다. 디자인을 비교해 볼 때 씁니다.
- 변수만으로 안 맞는 부분이 있으면 `design.css`를 새로 만들어 **`lesson.css` 다음 줄에** 연결하고(`theme.css` → `lesson.css` → `design.css` 순서여야 덮어쓰기가 됩니다), 30줄 안쪽으로 씁니다. `lesson.css`는 고치지 않습니다.
- 지킬 것: 본문 글자 크기 16px 이상, 글자와 바탕의 대비, 한글 글꼴(Pretendard 등)은 유지, 개념색 다섯 개는 서로 구별되게. DESIGN.md에 있는 로고나 브랜드 이름은 쓰지 않습니다.
- 디자인을 바꿔도 기능이 그대로인지 한 번 눌러 봅니다(빈칸, 예측, 확인 문제, 기록표).

## 6. 마치기 전 점검

1. `grep -c '【' index.html` 이 0입니다.
2. `window.LESSON.save` 값을 이 페이지만의 영문 이름으로 바꿨습니다(같은 사이트의 다른 페이지와 겹치면 기록이 섞입니다).
3. 브라우저로 열어 표지 → 시작 → 5개 탭을 모두 눌러 보고, 콘솔에 빨간 오류가 없습니다.
4. 빈칸은 눌러서 정답이 나오고, 확인 문제는 오답 후 정답을 고를 수 있고, 새로고침해도 기록이 남습니다.
5. 휴대폰 폭(375px)에서 가로로 넘치는 곳이 없습니다.
6. 쓰지 않은 부품(`.embed`, `table.obs`, `.sim3d`, 더 알아보기)은 지웠습니다.
7. 교과서나 자료에 없는 내용을 지어내지 않았고, 확인하지 못한 것은 보고에 「확인 필요」로 적었습니다.

## 7. 올리기

폴더째 GitHub Pages 같은 곳에 올립니다. 파일 네 개의 이름과 위치를 바꾸지 않습니다. 한 파일로 합치고 싶으면 `theme.css`, `lesson.css`, `lesson.js`의 내용을 `index.html`의 `<style>`과 `<script>` 안에 그대로 옮깁니다.
