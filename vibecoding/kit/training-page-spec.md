# 연수 자료 페이지 설계서 (training-page-spec.md)

> 연수·워크숍·수업 나눔 자료를 **HTML 한 장**으로 만드는 설계서입니다. 조승재(해누리중 과학)가 연수 페이지를 만들 때 쓰는 짜임(단계 칩, 상세/발표 두 모드, 블록, 탭 전환)을 그대로 적었습니다.
> 이 파일을 AI에게 첨부하고 연수 내용만 알려 주시면, 매번 프롬프트를 길게 쓰지 않아도 같은 틀의 페이지가 나옵니다.
> 예시: https://scienceisjo.github.io/growing-teachers/vibecoding/ · https://scienceisjo.github.io/growing-teachers/opening/
> 고쳐 쓰고 나누셔도 됩니다. 나누실 때 출처만 남겨 주세요.

---

## 첫째 부분 — 선생님이 읽을 곳

### 이런 페이지가 나옵니다
- **링크 하나로 끝나는 연수 자료**: PPT 대신 이 페이지 하나를 앞 화면에 띄우고, 같은 주소를 선생님들께 QR로 나눠 드립니다.
- **📖 상세 / 🎤 발표 두 모드**: 같은 페이지가 단추 하나로 바뀝니다. 발표 모드는 앞 화면용으로 키워드와 한 줄만 크게, 상세 모드는 못 오신 분이나 나중에 다시 보시는 분을 위해 설명까지 전부 보입니다.
- **단계 칩과 타이머**: 위쪽 띠에 「1 보여주기 · 2 실습 · 3 나눔 · 4 마무리」 같은 단계가 보이고, 지금 단계와 지난 시간이 표시됩니다.
- **두 가지 짜임 중 하나**
  - 스크롤형: 단계가 위에서 아래로 이어지고, 칩을 누르면 그 단계로 내려갑니다. 연수 본체에 맞습니다.
  - 탭형: 칩이 탭이 되어 한 번에 한 단계만 보입니다. 오프닝(인사·아이스브레이킹·설문처럼 짧은 화면 여러 개)에 맞습니다.

### 쓰는 법
1. 이 파일을 AI에게 첨부하고 아래 「연수 정보」를 채워 함께 보냅니다.
2. AI가 먼저 **진행표**(단계 · 분 · 들어갈 블록)를 보여 줍니다. 시간 배분과 빠진 내용을 여기서 고치세요.
3. "좋아, 만들어 줘" 하면 `index.html` 한 파일이 나옵니다. 더블클릭하면 열립니다.
4. 고칠 때는 "2단계 실습 체크리스트에 한 줄 더 넣어 줘. 나머지는 그대로 둬"처럼 한 가지씩 말씀하세요.

### 연수 정보 (복사해서 채워 보내기)
```
[연수 이름]
[대상] 예: 중등 과학 교사 20명, 각자 노트북
[시간] 예: 100분
[오늘 선생님들이 가져가실 것 3개 이내] (링크·파일·만든 결과물)
[보여 드릴 사례] (내 수업·도구, 링크가 있으면 같이)
[실습] 각자 무엇을 만들거나 해 보는지, 결과물이 무엇인지
[나눔] 질문 한 문장, 또는 결과물을 올리는 곳(패들렛·구글 설문·OneDrive 파일 요청 링크)
[강사] 이름 · 학교 · 과목 (사진은 넣지 않아도 됩니다)
[짜임] 스크롤형 / 탭형
```

## 둘째 부분 — AI가 읽을 곳

(여기부터는 AI에게 하는 말입니다.)

### 0. 맡을 일
사용자가 준 연수 정보로 **연수 자료 페이지(HTML 파일 하나)**를 만듭니다. 글은 **강사가 선생님들께 직접 하는 말**입니다.

### 일하는 차례
1. 연수 정보가 비어 있으면 짧게 묻습니다.
2. **진행표를 먼저** 보여 줍니다: 단계 번호 · 단계 이름 · 분 · 들어갈 블록 · 가져가실 것. 단계는 4~6개, 분의 합 = 연수 시간. 사용자가 "바로 만들어 줘"라고 했으면 건너뜁니다.
3. 확인을 받으면 만들고, 넘기기 전에 맨 아래 「건네기 전에 확인할 열 가지」를 하나씩 봅니다.

### 어기면 안 되는 규칙
1. 사용자가 주지 않은 사례·숫자·경험담·인용을 지어내지 않습니다. 필요하면 진행표에 「추가 제안」으로 따로 적어 확인을 받습니다.
2. 그림은 이미지 생성 기능으로 만들지 않습니다. 필요한 그림은 SVG로 그리거나, 사용자가 준 화면 캡처 자리를 비워 둡니다.
3. 색은 아래 색 표만 씁니다. 그림자·그라데이션 없음. 한글에 고정폭 글꼴을 쓰지 않습니다.
4. 생략하지 않습니다. `<!DOCTYPE html>`부터 `</html>`까지 전부 쓰고, 끊기면 "이어서"라는 말에 끊긴 곳부터 이어 씁니다.
5. 외부 파일은 글꼴(Pretendard)과 QR 라이브러리만 CDN으로 불러옵니다. 나머지는 한 파일 안에.

### 1. 목소리 (글 쓰는 법)
- 강사 1인칭, 합쇼체. 단계 첫 문장은 "~해 보겠습니다!"처럼 같이 하자는 말로.
- 보이는 본문에 **강사에게 하는 말을 쓰지 않습니다**: "~하십시오", "참가자에게 ~하게 하세요" 같은 진행 지시는 금지. 강사 메모는 `.cue`(발표 모드에서 c 키로만 보임)에.
- 금지: 표어 같은 제목, 「~의 본질」「역량」「혁신」 같은 추상어, 학습목표 문장("끝나면 ~이 남습니다"), 앞 절을 극적으로 되받는 문장, 화살표·대시로 이은 토막 메모, "연수가 끝나면 해 보세요" 같은 숙제.
- 그 자리에 숫자, 화면·단추 이름, 강사 학교의 실제 사례를 씁니다.

### 2. 페이지 짜임
```
상단 띠(고정): 페이지 이름 · 단계 칩 · 타이머(경과/계획 분, ▶ ↺) · [🎤 발표로] 단추
표지: 강사 이름표(이름·학교) · 작은 눈썹 글(공문 연수명) · 큰 제목(가져가실 것이 보이는 문장) · 소개 한두 문장 · 흐름 줄(단계 이름을 → 로 이은 알약들) · 큰 단추 2~3개
단계 1 … 단계 N (스크롤형: 차례로 / 탭형: 하나만 보임)
마무리: 가져가실 것 상자 2~3칸 + 링크
바닥글: © 연도 강사 이름 · 학교 · 최종 업데이트 날짜
```

### 3. 단계와 블록
단계:
```html
<section class="step" id="s1" data-title="보여주기" data-min="20">
  <div class="wrap">
    <div class="step-h"><span class="num">1</span><h2>단계 제목</h2><span class="min"><b>20</b>분</span></div>
    <p class="goal">이 단계에서 같이 할 일 한 문장 (~해 보겠습니다!)</p>
    …블록…
  </div>
</section>
```
- `data-title`·`data-min`으로 상단 칩, 표지 흐름 줄, 타이머 계획 분을 스크립트가 만듭니다.

블록(모든 내용의 단위, 세 겹):
```html
<div class="blk">
  <p class="kw">키워드 줄 — 말할 때의 제목</p>
  <p class="brief">발표 모드에도 남는 한 줄</p>
  …부품…
  <div class="detail"><p>상세 설명 2~3문단(강사 1인칭·이유·사례)</p></div>
  <div class="cue">강사 메모(발표 모드에서 c 키를 눌렀을 때만)</div>
</div>
```
- 발표 모드에서 `.kw`+`.brief`만 떠도 강사가 말로 이어 갈 수 있고, 상세 모드에서 `.detail`만 읽어도 처음 보는 사람이 따라올 수 있게 둘 다 채웁니다.

부품(필요한 것만 쓰고, 안 쓰는 것은 넣지 않습니다):
| 부품 | 쓰는 곳 | 모양 |
|---|---|---|
| 액자 `.frame` | 사례 보여 주기 | 16:9 iframe 또는 이미지, 아래 한 줄 설명 |
| 비교 상자 `.grid2 > .box` | 비교·가져갈 것 | 2~3칸, 굵은 제목 + 두 줄 |
| 체크 실습 `ol.steps` | 실습 | 체크칸 + 할 일(`.what`, 동사로 끝) + 방법(`.how`, 단추·메뉴 이름 그대로). 체크 상태는 localStorage에 남고, 끝낸 줄은 회색 취소선 |
| 막혔을 때 `details.stuck` | 실습 | 접는 칸. 실제로 자주 막히는 것만 |
| 프롬프트 카드 `.pr` | AI 실습 | 회색 칸 + 오른쪽 위 [복사] 단추 |
| 제출 `.submit` | 결과물 모으기 | 설명 + 큰 단추(패들렛·구글 설문·OneDrive 파일 요청 링크) + QR |
| QR `.qr[data-url]` | 어디든 | 주소가 비면 이 페이지 주소. 찍으면 상세 모드로 열림 |
| 표 `table` | 상세 안 | 머리 칸 검정 면, 줄은 헤어라인 |
| 알림 `.note` / `.note.warn` | 상세 안 | 왼쪽 선 + 한 줄, warn은 「주의 ·」 |

### 4. 두 모드
| | 📖 상세 (`html[data-mode="detail"]`) | 🎤 발표 (`present`) |
|---|---|---|
| 보임 | 전부 | `.kw` `.brief` `.steps .what` `.frame` `.grid2` `.submit` `.qr` |
| 숨김 | `.cue`, `.only-present` | `.detail` `.only-detail` `.steps .how` 입력 폼 |
| 글자 | 17px, 본문 폭 860px | 22px, 폭 1180px, `.kw` 1.75rem |
- 켜는 법: 단추 · `p` 키 · 주소 `?mode=present`. 고른 모드는 localStorage에 남고 주소가 우선합니다.
- 발표 모드 키: `→` `←` 다음/앞 단계, `t` 타이머 시작·멈춤(계획 분을 넘기면 빨간색), `c` 강사 메모.
- 상세 모드에서는 스크롤하면 지금 보이는 단계의 칩이 파랗게 따라옵니다.

### 5. 탭형으로 만들 때
- 단계 칩이 탭 단추가 됩니다. 누르면 그 단계만 보이고 나머지는 숨깁니다(`hidden`).
- 주소 끝 `#s2`로 열면 그 탭이 열리고, 탭을 바꾸면 주소의 `#`도 바뀝니다.
- `←` `→`로 탭을 옮깁니다. 탭 번호는 보이는 탭만 1부터 매깁니다.

### 6. 디자인
| 갈래 | 값 |
|---|---|
| 바탕 | 흰색 `#ffffff`, 보조 면 `#f5f5f7` |
| 강조 | 파랑 `#0066cc` 하나 — 누르는 것(단추·현재 칩·체크)에만. 옅은 면 `#eaf2fb` |
| 뜻 있는 색 | 맞음 `#1d8a4e` · 주의 `#9a6b00` · 틀림 `#b3261e` — 이 셋만 예외 |
| 글자 | 본문 `#1d1d1f`, 보조 `#6e6e73`, 잔글씨 `#86868b` |
| 선 | 헤어라인 `#e0e0e0` 1px. 구역은 선과 여백으로만 나눔 |
| 모서리 | 8px · 11px · 18px · 알약(9999px) |
| 글꼴 | Pretendard: `https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css` |
| 제목 | 굵기 600, 자간 -0.022em, 한글은 `word-break:keep-all` |
| 단계 번호 | 검정 동그라미 안 흰 숫자 |
- 휴대폰 폭(375px)에서 상단 띠의 칩은 가로로 밀어 보게 하고, 여러 칸은 한 칸으로 쌓습니다.

### 7. 건네기 전에 확인할 열 가지
1. 단계가 4~6개이고 `data-min` 합계가 연수 시간과 같은가?
2. 상단 칩이 단계 수만큼 생기고, 타이머가 돌고, 계획 분을 넘기면 빨개지는가?
3. 📖 ↔ 🎤 전환에서 `.detail`이 사라지고 글자가 커지는가? `p` 키와 `?mode=present`도 되는가?
4. 블록마다 `.kw`·`.brief`·`.detail`이 채워져 있는가?
5. 실습 체크칸이 새로고침해도 남는가?
6. QR이 그려지고, 찍으면 상세 모드로 열리는가?
7. 본문에 강사에게 하는 진행 지시, 추상어, 학습목표 문장, 지어낸 사례가 없는가?
8. 색 표 밖의 색, 그림자, 그라데이션을 쓰지 않았는가?
9. 폭 375px에서 가로로 넘치지 않는가?
10. 생략 없이 파일 전체가 있고, 바닥글 날짜가 오늘인가?
