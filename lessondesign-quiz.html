03 · ASSESSMENT

평가의 눈으로 — 그래서 온라인 퀴즈

평가가 무엇을 위한 것인지 → 그 위에서 온라인 퀴즈의 장점·한계

평가의 3요소 — 무엇을 위한 평가인가
ASSESSMENT FOR
학습을 위한 평가
이해도 확인 + 즉각 피드백으로 교수·학습 개선
ASSESSMENT AS
학습으로서의 평가
학생 자기주도 성찰·점검·조정 · 과정 중심
ASSESSMENT OF
학습 결과 확인
총괄·성취도 종합 판단·성적 · 결과 중심

젭·퀴즈앤은 실시간 형성평가(FOR)와 학생 자기점검(AS)에 특히 강해요. 결과 확인(OF·총괄)도 가능하지만, 고유한 강점은 FOR·AS예요.

왜 효과적일까?
🔁 꺼내야 남아요

이해한 걸 '꺼내기' = 핵심 학습 과정 · 약을 간식에 섞듯 거부감↓ → 학습 장벽↓

🎁 보상이 만드는 몰입

잘 풀면 보상 → 그러려면 수업 집중 → 열심히 참여 (교실 경험)

🙋 모두가 나와서 풀어요

"나와서 풀 사람?" 한 명 ✕ → 모두가 동시에 풀고 서로 그 모습을 봄

🎬 '꺼내야 남아요' — 영상으로 보기
◆ 그래서 — 온라인 퀴즈 플랫폼의 장점

그래서 교실에선 이런 장점으로 이어져요.

⚡ 즉시성

응답이 실시간으로 모여 바로 보고 바로 조정 (→ FOR). 시간의 연속성과 맞닿아요.

📊 데이터·기록

학생별 결과가 누적되어 과정중심평가·피드백의 근거. 종합성·연속성 실현.

🪞 자기 점검

학생이 '내 결과 확인'으로 스스로 성찰·조정 (→ AS). 잠재능력을 믿는 평가.

🧭 오답의 자원화

오답 분포가 오개념 지도가 되어 다음 수업 설계로 이어져요.

📚 문제 제작 부담 완화

다른 선생님 퀴즈를 복사 후 수정해 바로 활용. 혼자 다 만들 필요 ✕.

📊 '데이터·기록' 자세히 — 연속성·종합성 & 젭퀴즈 학습 통계

시간의 연속성 = 평가가 한 번으로 끝나지 않고 수업 전 과정에 걸쳐 이어지는 것. 종합성 = 지필 하나가 아니라 여러 자료로 학생을 종합적으로 보는 것.

📈 학생별 결과가 누적되면 → 과정중심평가·피드백의 든든한 근거가 돼요. 젭퀴즈는 이걸 학습 통계로 제공해요!

우리 반 학생들의 학습 현황을 확인해 볼까요?

📈 퀴즈 결과 확인 👥 클래스 비교 🧑‍🎓 학생별 통계
  • 퀴즈 결과 확인 — 퀴즈 카드의 '학습 리포트' 클릭 → 클래스 단위 결과. 같은 퀴즈를 여러 반에 공유해도 클래스별 따로 확인.
  • 클래스 비교 — 상단 드롭다운에서 반 전환. '전체 응시자' 선택 시 모든 결과를 한 번에.
  • 학생별 통계 — '학생 탭'에서 학생 클릭 → 퀴즈별 정답률 · 풀이 시간 · 문제별 정답/오답 · 완료 여부.
  • 플랜 — 학생별 통계는 모든 플랜. 학습 리포트 / 문제별 통계 / AI 학습 도우미는 Pro 이상.

📋 Teams 연동 — 단계별 자세히

채팅창에서 @Forms 봇으로 즉석 퀴즈를 보내거나, 채널 탭에 폼을 고정해 함께 분석할 수 있어요.

1. 채팅·채널에서 퀴즈/설문 추가 (폴링)
  1. 대화창 하단 도구에서 Forms 아이콘 클릭 또는 @Forms 입력
  2. '새 설문 조사 만들기' 클릭
  3. 질문·보기 입력, 복수 응답 여부 설정
  4. 저장 후 보내기 → 채팅창에 공유, 바로 참여
2. 팀 채널에 퀴즈 탭 추가
  1. 연동할 채널로 이동 → 상단 탭 우측 +(탭 추가) 클릭
  2. Forms 앱 검색·선택
  3. '기존 양식 추가'로 내 퀴즈 연결 또는 새로 만들기
  4. '공동 작업'·'결과 표시'·'양식 표시' 중 선택 → 저장
📊 응답 → 자동 채점 → Excel·Insights → 피드백·과세특 근거로

Google Forms + Classroom

형성 · 성적 연동

강점

📋 구글 클래스룸 연동 — 단계별 자세히
🛠️ 1. 퀴즈 과제 생성 및 설정
  1. Google Classroom 접속 → 원하는 수업 선택
  2. [수업] 탭 → [만들기] → [퀴즈 과제] 클릭
  3. 생성된 빈 Google 설문지를 클릭해 퀴즈 작성
  4. 설문지 우측 상단 톱니바퀴(설정)에서 '퀴즈 만들기' 활성화
  5. 각 문항 [정답]·[배점] 입력 → 완성
🔗 2. 퀴즈 연동 및 배포
  1. '퀴즈 과제' 창으로 돌아오기
  2. 첨부된 설문지 아래 '성적 가져오기'가 켜져 있는지 확인
  3. [과제 만들기] 클릭 → 학생에게 배포

⚠️ 정확한 성적 연동을 위해 과제엔 퀴즈 설문지 1개만 첨부하세요.

💯 3. 성적 가져오기
  1. 학생 제출 후 → 과제 페이지 [학생 과제] 탭
  2. 우측 상단 [성적 가져오기] 클릭
  3. 학생별 점수가 클래스룸 성적표에 자동 입력

실습 2 · 개인 · 약 32분 · 오늘의 메인 🎯

내 다음 수업의 '평가 한 장면' 설계하기

내 수업의 평가 한 장면을 목적 적합성으로 설계 · 4단계 카드 따라가기

4단계 설계 카드
1

무엇을 위한 평가?

FOR · AS · OF 중 하나 고르기

FOR · 학습을 위한AS · 학습으로서의OF · 결과 확인
예) 형성평가 → FOR
2

순간 고르기

도입 · 전개 · 정리 중

예) 전개 — 굴절 설명 직후
3

알고 싶은 것 한 문장

들여다보고 싶은 것 + 학생이 얻을 것

예) "성취기준 00을 잘 이해하고 적용할 수 있는가?"
4

수업 방식 정하기

전원이 '생각하게' 모형 + 퀴즈 결합 (아래)

예) "STAD·직소(JIGSAW) 등 수업 모형을 활용할지, 개인이 풀도록 할지 등"
수업 모형 — 전원이 '생각하게'
STAD · 모둠성취분담

모둠 학습 → 개별 퀴즈 → 향상 점수 · 개별 책무성

짝 토론 · Think-Pair-Share

혼자 → 짝 → 응답 · 응답 전 짝 토론

직소 · Jigsaw

전문가 그룹 → 원 모둠 전달 → 파트별 퀴즈

🔬 온라인 퀴즈로 수업 모형 적용하기 — STAD · 직소
STAD(모둠성취분담) — 온라인 퀴즈로 이렇게 (수업 사례)

✅ 온라인 퀴즈와 찰떡 — '개별 향상 점수 → 모둠 점수'를 데이터로 쉽게 계산해요.

📚 예시 수업 — 중2 과학 '밀도'

  1. 전체 제시 — 교사가 '밀도 = 질량/부피' 핵심 개념을 전체에게 설명·시연 (약 10분).
  2. 모둠 학습 — 4명 이질 모둠. 연습문제를 함께 풀며 서로 가르쳐 모두가 이해하게 (모둠 전체의 책임). 잘하는 학생은 설명, 막히는 학생은 질문.
  3. 개별 퀴즈 — 퀴즈앤/젭으로 개별 응시 (모둠 도움 ✕). 각자 실력을 측정해요.
  4. 향상 점수 → 모둠 점수 — 지난 퀴즈(기준 점수) 대비 얼마나 올랐는지를 점수화. 모둠원 향상 점수의 합 = 모둠 점수. 못하던 학생도 오르면 크게 기여 → 모두가 동기!
  5. 모둠 보상 — 향상 점수가 높은 모둠을 인정·보상.

💡 젭 학습 통계로 학생별 점수를 추적하면 향상도 계산이 쉬워요. 같은 난이도 퀴즈를 주기적으로 내면 '성장'이 한눈에 보여요.

직소(Jigsaw) — 온라인 퀴즈로 이렇게

✅ 됩니다 — 전문가 그룹용 퀴즈 + 종합 퀴즈로 책무성을 잡아요.

  1. 주제 분담 — 원 모둠에서 학생마다 다른 소주제 배정.
  2. 전문가 그룹 학습 — 같은 주제끼리 모여 학습 → 그 주제 퀴즈로 숙달 확인(통과해야 복귀).
  3. 원 모둠 복귀 — 각자 자기 주제를 모둠원에게 가르침.
  4. 종합 퀴즈로 개별 확인 — 모든 주제를 포함한 퀴즈를 개별로 풀기. 내 주제만 알면 못 풀게 설계.
  5. 젭 클래스로 모둠별 결과를 분리해 보면 누가 어느 주제에서 막혔는지 한눈에.

💡 퀴즈 2종 준비: 주제별(전문가용) + 종합(개별 확인용). 자료실에서 복사해 빠르게!

🧪 평가 문항이 갖춰야 할 요소

'맞히기 게임'을 넘어, 한 문항이 갖춰야 할 기본기를 체크해요.

  • 타당도 — 측정하려는 성취기준·목표를 실제로 측정하는가. (목표 ↔ 문항 일치)
  • 명확한 발문 — 한 가지로만 해석되는 분명한 질문. 애매함·중의성 제거.
  • 적절한 난이도 — 너무 쉽지도 어렵지도 않게, 핵심을 가르는 수준으로.
  • 매력적인 오답 — 오답 보기가 흔한 오개념을 반영해 그럴듯해야. (찍기 방지)
🤖 주의 — 퀴즈 플랫폼 내장 AI 문제 생성은 위 요소를 대부분 충족하지 못해요. 오히려 고치는 데 더 오래 걸립니다. → 다른 선생님이 공유하신 퀴즈를 복사해 쓰거나, 처음부터 직접 만드는 편이 더 빠르고 좋아요. 차라리 성능 좋은 기존 생성형 AI(ChatGPT·Gemini·Claude 등)를 활용해 문제를 생성하시는 것을 추천드려요.

넌센스 퀴즈 (정답 확인하기)

제가 낸 넌센스 문제를 퀴즈 플랫폼에서 학생처럼 풀어보세요! 답이 막히면 — 여기서 정답을 확인하고 플랫폼에 입력하시면 돼요 😄

🧠 퀴즈앤·젭퀴즈를 학생 입장에서 체험하실 때 제가 이 넌센스 문제들을 출제할게요. 고민해 보시고 막히면 여기서 정답을 확인해 플랫폼에 입력하세요! 총 15문제예요.
1. 오이가 무를 치면?
→ 오이무침
2. 오징어가 대출을 못 받는 이유는? (○○○○)
→ 연체동물 (대출 '연체' ↔ 연체동물)
3. 사고 나면 후회하는 의자는? (○○○○○)
→ 팔걸이의자
4. 의자에 앉으면 졸린 이유는? (○○○)
→ 안자서 ('앉아서')
5. 자동차가 화나면 오히려? (○○○)
→ 차분함
6. 호주에서 꽃을 사면 안 되는 이유는? 꽃이 ○○○까.
→ 시드니 ('꽃이 시드니까')
7. 베를린에서 물을 마시면 안 되는 이유는? ○○ ○○ 있으니까.
→ 독일수도 ('독일 수도 있으니까')
8. 그늘에 있으면 행복한 이유는? ○○해서.
→ 해피 ('해 피해서' = happy)
9. 김치가 가위바위보에서 바위를 내면 안 되는 이유는? ○○○니까.
→ 묵은지 (바위='묵' → '묵은지'니까)
10. 사슴을 맨손으로 만지면 안 되는 이유는? ○○○서.
→ 손디어 ('손 대어서')
11. 사슴이 시력이 좋으면? (○○○○○)
→ 굿아이디어 (good + 아이(eye) + deer)
12. 산소를 싫어하는 사람은? ○○기피자.
→ 오뚜기피자 (O₂(오투) 기피자)
13. 아이언맨이 사실 여자인 이유는? (영어 6글자)
→ female (Fe(철) + male)
14. 세상에서 제일 뜨거운 과일은? (○○○○○)
→ 천도복숭아 (1000°)
15. 자동차 키의 색깔은? (○○○)
→ 카키색 (car + 키)

① 거꾸로(백워드) 설계 & 참여의 깊이

도구는 맨 마지막에. '재미있는 도구'에서 시작하지 말고, 끝(무엇을 알고 싶은가)에서 시작해 거꾸로 — ① 목표·증거 → ② 어떻게 드러낼까 → ③ 그래서 어떤 도구.

'참여'에는 깊이가 있어요. 빠른 클릭(표면적) ≠ '왜'를 생각하는 것(인지적). 끌어올리는 장치: 짝 토론 후 응답 · 속도 끄기·익명 · 전원 응답 · 오답의 자원화.

GOOGLE FORMS + APPS SCRIPT

응답을 '자동 피드백'으로 — 손은 덜고, 피드백은 늘리고

Google Forms 자동 채점 + Apps Script → 학생별 맞춤 피드백 자동 발송 · 점수대별 분기 · 대시보드. 응답이 곧바로 피드백으로 돌아옴.

  • 제출 즉시 개인 피드백 메일 자동 발송 (오답 문항·해설 포함)
  • 점수·응답에 따라 맞춤 분기 (예: 60점 미만엔 보충 자료 링크)
  • 응답을 시트에 모아 반별·문항별 대시보드로 한눈에
🪄 스크립트, 직접 짜지 마세요 — AI에게 시키세요!
