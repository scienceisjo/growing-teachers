가장 많이 바뀌는 점

  1. 켜면 10초업데이트 기다림 없이 바로 수업 시작. 업데이트는 뒤에서 되고 재시작 한 번이면 끝
  2. 프로그램 창 → 크롬 탭거의 모든 일이 크롬 안에서. 앱 이동은 Ctrl+Tab, 창 배치는 위쪽 가운데를 끌어내려 선택
  3. 바탕화면 없음파일은 「파일」 앱의 다운로드 · 내 파일 · 구글 드라이브에. 저장은 클라우드가 기본
  4. 로그인은 센스쿨 계정기기 로그인 뒤 설정 → 계정 → 계정 추가로 기존 해누리중 계정을 얹으면 드라이브 · 클래스룸 그대로
  5. 단축키 몇 개새로고침 F3, 캡처 Shift+Ctrl+F5, 한/영 Ctrl+Space, 설정 · 종료는 오른쪽 아래 시계
  6. 앱은 전부 웹으로패들렛 · 띵커벨 · 캔바 · 구글 문서 · M365 웹판 그대로. 설치형만 웹 버전으로 바꿈
  7. 기기 관리가 실제로 됨앱 배포 · 사이트 차단 · 사용 시간 · 원격 잠금을 관리 콘솔에서. 수업 중 화면 집중 · 잠금 · 시험 잠금

포기하게 되는 것

  1. 설치형 프로그램한글(HWP) 설치판, 엔트리 오프라인 · 하드웨어 연결, 곰믹스 같은 exe → 한컴독스 · 엔트리 웹 · 웹 편집기로 대체
  2. 안드로이드 앱플레이스토어가 없어 스마트폰용 앱은 설치 불가 → 사이트로 되는 것만
  3. 카메라 일부전 · 후면 중 한쪽 초점이 흐려질 수 있음. 가까운 QR은 인식되지만 먼 QR · 촬영 과제는 스마트폰 병행
  4. 기기에 저장한 파일전환 때 기기 안 파일은 모두 삭제. 2주 전부터 백업 안내
  5. 윈도우식 조작의 익숙함F키 · 창 배치 · 파일 위치가 달라 적응 기간 필요. 대조표(2쪽) 참고
바뀌지 않는 것 — 기기(Surface Go 3)는 그대로, 인터넷으로 하던 수업은 그대로, 학생 개인 지메일은 여전히 차단. 전환 여부는 추석 연휴 전 쿨메신저 설문(투표)으로 결정합니다.
