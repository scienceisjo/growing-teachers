연수 준비 과정

이 연수, 이렇게 준비했습니다!

수강생 계정으로는 실제 관리 화면을 열 수 없어서, 직접 만져 볼 수 있는 실습 사이트를 만들었습니다.

01

교수요목 → 화면 2개

7항목(계정 생성 · 비번 초기화 · 팀 설정 · 승급 · MFA · 라이선스 · MDM)을 실제 화면 2개로 묶었습니다. 6개는 M365 Admin, 1개는 Argos입니다.

02

실습 사이트 5개 제작

Argos 실제 화면 소스 + 사용자매뉴얼 v4.1(149쪽) + M365 관리 센터 매뉴얼로 M365 · Argos · DBS · 관리대장 생성기 · 인수인계 실습기를 만들었습니다.

03

실제 화면과 대조

실제 Argos · DBS 관리 화면을 옆에 두고 메뉴 · 문구 · 숫자를 맞췄습니다. 261대 중 232대 적용 같은 수치도 실제 그대로입니다.

04

직접 겪은 것만

2학년 343명 승급, 수리 207건, 단말 1008대 — 저희 학교에서 직접 부딪힌 것만 담았습니다.

참고: 강현욱 선생님 M365 가상 실습 사이트(msadmin) · 송세호 선생님 「디벗 업무 도우미」 — 실습 사이트는 연수 후에도 그대로 쓰실 수 있습니다!
먼저 이름부터 정리하겠습니다

M365 Admin VS MDM

Windows ADMIN = Microsoft 365 관리 센터

MS 계정을 관리하는 곳입니다!

  • 학생 계정 만들기 — 개별 · CSV 일괄
  • 암호 초기화 · 라이선스 붙이기
  • 표시 이름 바꾸기 = 승급 · 그룹(팀) · 관리자 역할 위임
  • 학생이 디벗 · 팀즈 · 오피스에 로그인하는 그 계정입니다
admin.cloud.microsoft ↗ 학교 관리자 계정으로 로그인
MDM = Argos Edu Manager

기기를 관리하는 곳입니다!

  • 단말현황 — 어느 기기가 누구 것인지
  • 통합설정 — 카메라 · USB · 사이트 차단
  • 분실 위치 · 잠금 · 대여 · 앱 배포
  • Android · iPad · Windows 모두 같은 화면입니다
mdm.sen.go.kr ↗ 학내망 · eVPN에서만 열립니다
+ 수리는 DBS(dbs.edu-portal.ai) — 업체(케이원) 시스템입니다. 실습 ⑨에서 잠깐 보여드리겠습니다.
라이선스 — 계정에 서비스를 붙이는 열쇠

학생용 A3를 붙이면, 무엇이 열립니까?

2024년부터 학생 라이선스가 A1 → A3(교육청 계약, 무료)입니다. 라이선스가 없으면 로그인은 되어도 Office · OneDrive · Teams가 열리지 않습니다.

01 · Office

정식 설치판이 열립니다

Word · Excel · PowerPoint · OneNote · Outlook 최신 버전을 디벗과 개인 기기에 설치 — PC·Mac 5대 + 태블릿 5대 + 폰 5대. 한컴 없이도 과제 OK.

02 · OneDrive

최대 5TB 저장 공간

기본은 1TB(1024GB)로 맞춰 둡니다(학교 테넌트 100TB 공유). 디벗을 바꿔도, 졸업할 때까지 파일은 그대로.

03 · Teams

가상교실이 완성됩니다

수업 팀 · 과제 · Class Notebook · 화상회의 녹화. 학생이 낸 Word·PPT가 설치판에서 열리고, 실시간 공동 편집까지.

04 · 학습 가속화 도구

AI 학습 도우미

몰입형 리더 · 읽기 진행 · 검색 코치 · 발표자 코치 · 인사이트 — Teams 과제 안에서 바로 씁니다.

05 · Windows

Windows 11 Education 업그레이드

디벗 Windows가 Pro · Education이어야 Argos 기능(사이트 차단 등)이 전부 됩니다. 디벗과 직결되는 혜택!

06 · 그리고

Minecraft Education · Clipchamp

Minecraft Education은 A3만 사용 가능(교육청 건축 프로젝트). Clipchamp 영상 편집도 A3에 포함.

Copilot(데이터 보호)은 A3·A5의 18세 이상 학생과 교직원 — 중학생은 아직 해당 없습니다. 교사용 A3 좌석은 학교별 수량 한정 → 전출 교사 것을 회수해 재할당. 근거: 디벗 플랫폼 매뉴얼(팀즈) 6·12·28쪽 · 2026 교육청 MS오피스 라이선스 Q&A · Minecraft Education 사용 가이드.
