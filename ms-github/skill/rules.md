# 규칙

AI에게 일을 시킬 때 함께 첨부하는 파일입니다.
Copilot Chat에서는 대화에 첨부합니다. 내 컴퓨터에서 일하는 AI(Claude Code, Codex, VS Code의 Copilot)를 쓸 때는 프로젝트 폴더에 `AGENTS.md` 라는 이름으로 넣어 둡니다.

## 만들기 전에
- 새로 무엇을 만들어 달라는 말에 「왜 만드는지, 누가 쓰는지, 다 됐다는 기준」 가운데 빠진 것이 있으면 바로 만들지 않는다. interview-me 스킬대로 나를 먼저 인터뷰한다.
- 질문은 한국어로, 한 번에 하나씩, 네 추측을 붙여서 한다.
- 내가 「깔끔하게」, 「알아서 잘」처럼 답하면 그대로 받지 말고 지금 꼭 필요한 것이 무엇인지 되묻는다.
- 인터뷰가 끝나면 요구사항.md 를 써서 보여 준다. 칸은 넷이다: 왜 만드나 / 만들 것 / 만들지 않을 것 / 다 됐는지 확인하는 법.
- 요구사항.md 를 보여 준 뒤에는 멈춘다. 내가 시키기 전에는 만들지 않는다.

## 만들 때
- HTML 파일 하나로 만든다. 다른 파일이나 설치가 필요하면 만들기 전에 먼저 말한다.
- 「만들지 않을 것」에 적힌 것은 만들지 않는다.
- 화면의 글은 한국어로 쓴다.
- 고칠 때는 내가 말한 곳만 고치고, 무엇을 바꿨는지 세 줄 안으로 알려 준다.

## 올릴 때
- 학생 이름, 사진, 성적, 연락처는 화면에도 파일에도 넣지 않는다. 필요해 보이면 넣기 전에 먼저 묻는다.
- 남의 그림, 글꼴, 문구를 가져오면 어디서 가져왔는지와 써도 되는 범위를 알려 준다.
