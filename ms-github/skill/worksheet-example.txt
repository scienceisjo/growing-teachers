학습지 3 · VI.기체의 성질 · 03.기체의 압력과 부피 사이의 관계 (중1 과학)
빈칸은 ( 번호 정답 ) 으로 적었습니다.

■ 기체의 압력
[복습]
기체의 압력은 기체 입자가 일정한 면적의 벽에 ( ① 충돌 )하면서 가하는 힘이다.
같은 시간 동안 일정한 면적의 벽에 부딪히는 ( ② 횟수 )가 많을수록 압력은 커진다.
기체의 압력은 위, 아래, 옆 등 모든 ( ③ 방향 )으로 작용한다.

■ 입자 모형으로 이해하기
[일정한 수의 기체 입자가 들어 있는 주사기의 피스톤을 누를 때와 당길 때]
[부피가 변해도 변하지 않는 것]
기체 입자의 ( ④ 수 )와 ( ⑤ 크기 )는 변하지 않는다.
입자의 평균 ( ⑥ 빠르기 )도 변하지 않는다. 입자의 빠르기는 ( ⑦ 온도 )가 변할 때 달라진다.
[그림: 피스톤을 누르기 전과 후의 입자 모형]

■ 온도가 일정할 때 기체의 압력과 부피 사이의 관계
[압력과 부피의 관계]
일정한 양의 기체에 가하는 압력을 크게 하면 부피는 ( ⑧ 작아진다 ).
반대로 압력을 작게 하면 부피는 ( ⑨ 커진다 ).
[보일 법칙]
온도가 일정할 때 일정한 양의 기체의 압력과 부피를 ( ⑩ 곱한 ) 값은 ( ⑪ 일정하다 ).
이 관계를 보일 법칙이라고 한다.
압력 × 부피 = 일정

■ 실험으로 확인하기
끝을 막은 주사기에 공기 40 mL를 넣고 피스톤을 누르면서 기체의 압력과 부피를 측정하였다(예시 결과).
표를 보고 압력과 부피를 곱한 값을 구하시오.
압력 (기압) | 1 | 2 | 4 | 5
부피 (mL) | 40 | 20 | 10 | 8
압력 × 부피 | 40 | ( ⑫ 40 ) | ( ⑬ 40 ) | ( ⑭ 40 )
알아낸 것   압력이 2배가 되면 부피는 ( ⑮ 절반 )이 되고, 압력이 4배가 되면 부피는 ( ⑯ 4분의 1 )이 된다.
압력과 부피를 곱한 값은 ( ⑰ 일정 )하다(보일 법칙).
[그래프 그리는 칸: 가로축 압력 (기압), 세로축 부피 (mL)] 가로축은 한 칸에 1기압, 세로축은 한 칸에 5 mL로 눈금을 적고, 표의 값을 점으로 찍어 부드럽게 이으시오.
그래프 모양   그래프는 직선이 아니라 오른쪽 아래로 휘어지는 ( ⑱ 곡선 )이다.
부피는 0이 되지 않으므로 곡선은 가로축에 ( ⑲ 닿지 않는다 ).

■ 생활 속 압력과 부피의 관계
각 상황에서 기체에 작용하는 압력과 기체의 부피가 어떻게 되는지 쓰시오(기체의 온도는 변하지 않는다고 본다).
상황 | 작용하는 압력 | 기체의 부피
높은 산에 올라간 과자 봉지(봉지에 작용하는 압력) | ( ⑳ 낮아진다 ) | ( ㉑ 커진다 )
물속 깊이 내려간 공기 방울 | ( ㉒ 높아진다 ) | ( ㉓ 작아진다 )
끝을 막고 피스톤을 누른 주사기 | ( ㉔ 높아진다 ) | ( ㉕ 작아진다 )
하늘 높이 올라간 풍선 | ( ㉖ 낮아진다 ) | ( ㉗ 커진다 )
