맛집 지도 따라 만들기

연수에서 함께 채운 맛집 지도를, 내 Supabase와 내 GitHub로 직접 만들어보겠습니다!

30분쯤 · GitHub 계정과 Supabase 계정

맛집 지도 파일 내려받기 표 만드는 SQL 내려받기 연수 페이지로

0무엇을 만드나요

지도를 눌러 가게 이름과 한 줄 추천을 올리면, 다른 사람의 화면에도 핀이 나타나는 페이지입니다. 파일은 index.html 하나이고, 올린 자료는 Supabase의 표 하나에 한 줄씩 쌓입니다.

무엇어디에 두나
화면 (index.html)GitHub Pages에 올립니다.
자료 (가게 목록)Supabase의 표 matjip에 쌓입니다.

1Supabase 프로젝트 만들기

  1. Supabase에 로그인하기supabase.com 에서 [Start your project]를 누르고 GitHub 계정으로 로그인합니다.
  2. 새 프로젝트 만들기[New project]를 누르고 이름을 적습니다. 데이터베이스 비밀번호는 따로 적어 두고, Region은 Northeast Asia (Seoul)을 고릅니다.
  3. 만들어질 때까지 기다리기[Create new project]를 누르고 1~2분 기다립니다.

무료 요금제로 충분합니다. 무료 프로젝트는 일주일 동안 쓰지 않으면 멈추고, 대시보드에서 다시 켤 수 있습니다.

2표 만들기

  1. SQL Editor 열기프로젝트 화면 왼쪽의 [SQL Editor]를 누릅니다.
  2. 아래 SQL을 붙여 넣고 실행하기[복사]를 누르고 편집 칸에 붙여 넣은 뒤 [Run]을 누릅니다. 아래에 줄_수 0 이 나오면 된 것입니다.
  3. 표가 생겼는지 보기왼쪽 [Table Editor]에서 matjip 표를 누릅니다. 칸 이름만 있고 줄은 비어 있습니다.
표 만드는 SQL
불러오는 중입니다…

이 SQL은 세 가지 일을 합니다. 가게 이름, 한 줄 추천, 올린 사람, 위도, 경도 칸이 있는 표를 만듭니다. 그 표에 규칙(RLS)을 켭니다. 그리고 앱에서는 읽기와 넣기만 할 수 있게 허락합니다.

주의 규칙을 켜지 않은 표는 주소와 키를 아는 누구나 고치고 지울 수 있습니다. SQL로 표를 만들 때는 규칙을 켜는 줄이 들어 있는지 꼭 봅니다.

3주소와 키 찾기

  1. [Connect] 누르기프로젝트 화면 위쪽에 있습니다. Project URL과 Publishable key가 함께 보입니다. [Settings] → [API Keys]에서도 찾을 수 있습니다.
  2. Project URL 복사해 두기https://영문자.supabase.co 모양입니다.
  3. Publishable key 복사해 두기sb_publishable_ 로 시작합니다. 예전 프로젝트는 anon key라고 적혀 있습니다.
주의 secret key(service_role)는 앱에 넣지 않습니다. 이 키는 규칙을 건너뛰기 때문에, 공개된 파일에 들어가면 누구나 표를 지울 수 있습니다.

4맛집 지도 파일에 두 줄 넣기

  1. 맛집 지도 파일 내려받기맨 위의 [맛집 지도 파일 내려받기]를 누릅니다. 파일 이름은 index.html 입니다.
  2. 메모장으로 열기파일을 오른쪽 단추로 누르고 [연결 프로그램] → [메모장]을 고릅니다.
  3. 주소와 키 바꿔 넣기파일 아래쪽의 여기에_Project_URL 과 여기에_Publishable_key 를 3단계에서 복사한 값으로 바꿉니다. 작은따옴표는 그대로 둡니다.
  4. 제목과 지도 시작 자리 바꾸기같은 자리의 title, place, center 를 우리 학교에 맞게 고칩니다. center 는 위도와 경도입니다.
  5. 저장하기Ctrl+S 로 저장합니다.

고칠 곳은 파일 맨 아래 const CONFIG 로 시작하는 칸 하나에 모아 두었습니다. 그 밖의 줄은 건드리지 않아도 됩니다.

5열어서 핀 찍기

  1. index.html 열기파일을 두 번 눌러 브라우저로 엽니다.
  2. 지도를 누르고 가게 올리기가게 이름과 한 줄 추천을 적고 [올리기]를 누릅니다.
  3. Supabase에서 새 줄 확인하기[Table Editor]의 matjip 표를 새로 고치면 방금 올린 줄이 보입니다.
막혔을 때

「서버에 닿지 않습니다 (401)」이 뜹니다. 키가 잘못 들어간 것입니다. 앞뒤에 빈칸이 붙지 않았는지, 작은따옴표가 남아 있는지 봅니다.

「서버에 닿지 않습니다 (404)」가 뜹니다. 표가 없다는 뜻입니다. 2단계의 SQL을 실행했는지, 표 이름이 matjip 인지 봅니다.

「올리지 못했습니다 (403)」이 뜹니다. 규칙에 걸린 것입니다. 가게 이름이 40자를 넘었거나, 지도에서 우리나라 밖을 눌렀을 때 그렇습니다.

지도가 회색으로만 보입니다. 지도 그림을 인터넷에서 불러옵니다. 연결을 확인하고 새로 고칩니다.

6GitHub Pages로 올리기

  1. 저장소를 만들고 index.html 올리기github.com 에서 [New repository]로 Public 저장소를 만들고, 「uploading an existing file」로 파일을 올립니다.
  2. Pages 켜기[Settings] → [Pages] → Branch 를 [main] 으로 바꾸고 [Save]를 누릅니다.
  3. 주소를 열어 다른 기기에서도 찍어 보기휴대폰으로 같은 주소를 열어 핀을 올리면, 노트북 화면에도 몇 초 뒤에 나타납니다.

단추 위치를 화면 캡처와 함께 보시려면 GitHub Pages 따라하기를 열어 주세요.

주의 공개 저장소에 올리는 파일에는 Publishable key만 들어 있어야 합니다. 학생 이름이나 연락처를 받는 칸은 만들지 않습니다.

7고치고, 지우고, 더 해 보기

기능을 더하고 싶을 때는 index.html 을 Copilot 대화에 올리고 「이 파일에서 가게마다 별점을 줄 수 있게 고쳐 줘. 표에 필요한 칸이 있으면 SQL도 같이 알려 줘」처럼 보냅니다. 연수에서 받은 규칙 파일을 함께 올리면 만들기 전에 먼저 물어봅니다.

줄을 지울 때는 [Table Editor]에서 줄을 고르고 [Delete]를 누릅니다. 앱에서는 지울 수 없게 해 두었습니다.

프로젝트를 더 쓰지 않을 때는 [Settings] → [General] 맨 아래에서 프로젝트를 지웁니다.

학생 답을 모으고 교사만 보는 화면까지 만들고 싶으시면 학생 데이터와 AI 연결 안내에 순서를 적어 두었습니다.
