# c1-5 · 생물은 어떻게 다양해졌을까 (중1 칠판 강의 화면)

- **만든 모델**: Claude Opus 5.5 (`claude-opus-5-5`)
- **걸린 시간**: 약 1시간 10분(대략)
- **도구 호출 수**: 약 65회
- **결과물**: `index.html`(한 파일, 글꼴 불러오기 줄만 바깥 연결) · `sheet.png` · `shots/`(k00~k21, rapid_end, report.json)
- **입력**: 중1 과학(비상교육, 2022 개정) 52~55쪽. 범위와 용어는 학생 본문을 따랐고, 교사용 주석은 오개념 점검에만 참고했습니다.
- **학습지가 없어서** 빈칸 6개와 문장은 교과서 본문 용어로 새로 만들었습니다. 정답 글자는 모두 본문에 있는 낱말이라 «(추측)» 표시는 없습니다.
- **쓰지 않은 낱말·문장**
  - 「자연선택」「진화」는 교사용 보충에만 있어서 쓰지 않았습니다.
  - p.54 「변이는 생물이 … 환경에 적응하면서 점점 차이가 커질 수 있다」는 「필요해서 변한다」로 읽힐 수 있어 옮기지 않았습니다.

## 시뮬레이터 (장면 ③)

**조작** — 조작 칸과 머리띠는 눌러도 장면이 넘어가지 않습니다.
- 「다음 세대 ▶」: 살아남기 뒤 1초 있다가 다음 세대가 쌓입니다.
- 「10세대 더 ▶▶」
- 「처음 무리로」: 지금 먹이와 같은 씨앗값으로 처음부터 시작합니다.
- 섬마다 「먹이 ⇄」
- 자유 조작은 7단계에서 하기를 권합니다. 조작한 뒤 →를 누르면 대본 순서의 모습으로 돌아간 다음 넘어갑니다.

**규칙**
- 부리는 1(길고 뾰족)부터 7(크고 두꺼움)까지 7칸입니다.
- 처음 무리는 [1,3,5,6,5,3,1], 24마리로 일곱 칸이 모두 있습니다.
- 살아남을 확률
  - 선인장 섬: p(k) = 0.85 − 0.10(k−1)
  - 씨앗 섬: p(k) = 0.25 + 0.10(k−1)
- 같은 칸 c마리 가운데 살아남는 수는 floor(c·p + u), u는 0~1 난수입니다.
- 살아남은 S마리가 자손 24마리를 나눠 남깁니다.
- 자손 부리는 80% 부모와 같은 칸, 10% 한 칸 더 뾰족, 10% 한 칸 더 두껍게 나옵니다.
- 개체는 `Object.freeze`로 얼려 둡니다.
- 난수는 mulberry32이고, 씨앗값은 왼쪽 섬 5, 오른쪽 섬 10입니다.
- 한 칸 높이는 자동(최대 20px)이고 두 섬이 같은 눈금을 씁니다.

**값 출처**
- 두 섬과 어느 부리가 유리한지는 교과서 55쪽 「해 보기」를 따랐습니다.
- 24마리, 확률, 변이 비율은 **예시 값**입니다.
- 씨앗값은 3000번 돌린 결과의 가운데쯤이면서 2단계 차이가 잘 보이는 값으로 골랐습니다. 10세대 평균 칸은 중앙값 1.79, 25~75% 구간 1.63~2.00입니다.

**대본대로 넘겼을 때 화면 값**

| 2단계 남은 핀치 | 1,3,3,3,2,1,0 (13마리) | 0,1,2,4,4,2,1 (14마리) |
| 1세대 | 2,4,6,6,4,2,0 (평균 칸 3.50) | 0,2,3,7,8,3,1 (4.42) |

## 점검 결과
- **keyshots**(마지막 실행, 21회): `{"logs":[],"sameStartAfterBack":true,"rapidEqualsSlowEnd":true}`. 1차 실행 뒤 고치고 세 번 더 돌려 모두 같은 결과였습니다.
- **시뮬 코드**: index.html의 SIM 블록을 그대로 node로 돌렸습니다. 모두 통과했습니다.
  - 처음 무리에 일곱 칸이 모두 있음
  - 섬마다 744마리를 30세대 추적: 부리가 바뀐 개체 0, 모두 얼려 있음, 자손은 늘 새 개체, 부모는 늘 살아남은 개체
  - 같은 씨앗값이면 같은 결과, 다른 씨앗값이면 다른 결과
- **브라우저**(헤드리스 크롬, CDP)
  - 시뮬 단추를 눌러도 장면이 넘어가지 않고, 포커스는 BODY에 남음
  - 단추를 누른 뒤에도 →·Space로 넘어가고, ←는 대본 상태로 되돌림
  - 같은 자유 조작을 두 번 하면 같은 결과
  - 막대 칸 480번 관찰, 다른 열로 옮긴 칸 0
  - 머리띠를 누르면 안 넘어가고, 막대 쪽을 누르면 넘어감
  - 판서: 펜슬로는 그려지고, 그 뒤 손가락 탭은 장면을 넘김. 펜이 켜진 채 손가락으로 도구 상자를 닫을 수 있고, Z가 동작함
  - `?s=1`: 안내 줄이 보이고, 소리는 꺼져 있고, T가 막힘
  - 콘솔 오류·경고 0

## 점검하며 고친 것
1. 빈칸 정답이 밑줄 쪽으로 처져 기준선이 어긋남 → 기준선을 맞추고 번호 배지를 3px 올림.
2. 막대가 작아 패널이 비어 보임 → 칸 높이를 자동(최대 20px, 두 섬 같은 눈금)으로.
3. 정리 카드 뒤로 시뮬이 비치고 그림자가 삐져나옴 → 불투명하게, 높이를 늘리고 가운데 정렬.
4. 선인장 아이콘이 트럼프 클로버처럼 보임 → 기둥 선인장으로.
5. 오른쪽 섬 씨앗이 이름표에 가려짐 → 핀치와 씨앗 위치를 옮김.
6. 섬의 초록 조각이 칼자국처럼 보임 → 덤불로.
7. 북극 얼음이 거의 안 보임 → 윤곽선과 갈라진 선을 더함.
8. 나는 핀치 날개가 지느러미처럼 보임 → 뒤로 젖힌 날개로.
9. 1세대 뒤 변화가 덜 보임 → 옅은 「처음 무리」 막대를 깔고 숫자는 그 위로.
10. 「처음 무리로」가 개체 번호를 다시 1부터 써서 칸이 다른 열로 날아가, 한 마리의 부리가 바뀐 것처럼 보일 수 있었음 → 다시 시작할 때 칸을 모두 지우고 새로 쌓음.
11. 교과서 오개념 지도(종이 다른 생물의 차이는 변이가 아님) → ② 7단계로 추가.
12. 보이지 않는 정리 카드가 클릭을 막을 수 있었음 → 안 보일 때는 클릭을 통과시킴.
13. 패널 전체가 클릭 넘기기를 막음 → 머리띠와 조작 칸만 막음.
14. 첫 조작 전에 소리 장치를 만들던 것 → 첫 키·터치 뒤에만 만듦.

## 내가 정한 것

## 남은 걱정
- 10세대 만의 변화는 실제보다 빠르니, 「오랜 세월」은 선생님이 말로 짚어야 합니다. 시뮬은 새 종이 생기는 장면을 직접 보여 주지는 않습니다.
- 부리를 길이·두께 한 줄로 단순화했습니다.
- 씨앗값은 첫 세대 경향이 잘 보이게 골랐습니다(극단값은 아님).
- ② 「종류」는 쉬운 빈칸입니다. 학습지가 따로 있으면 번호와 정답을 그 학습지에 맞춰야 합니다.
- 「이번 세대에 죽음」은 교과서 말투보다 직설적입니다.
- 바지락 색 일부가 실제보다 노란빛입니다(디자인 팔레트 제약).
- 실제 전자칠판·아이패드 터치는 헤드리스 흉내로만 확인했습니다.
- 글꼴은 인터넷이 있어야 보이고, 없으면 맑은 고딕으로 보입니다.
- 저작권 문구를 받지 못해 마지막 줄은 내용 출처로 대신했습니다.
- voice-check·insta-ai-look 검사는 이번 작업 범위 밖이라 돌리지 않았습니다.
