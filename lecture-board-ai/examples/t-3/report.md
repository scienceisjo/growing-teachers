# t-3 생명 시스템에서 일어나는 화학 반응과 효소 (칠판 강의 화면 3장)

- 만든 모델: Sonnet 5.5 · 디자인 서랍 corkboard(코르크 보드)
- 근거: 비상교육 고등 통합과학1(2022 개정) 132~135쪽. 교과서 그림·사진은 쓰지 않고 새로 그림
- 걸린 시간: 약 75분(18개를 한 컴퓨터에서 동시에 돌려 점검이 느렸음)
- 보고서: 만든 에이전트가 보고서를 남기기 전에 멈춰서, 화면을 검토하며 정리함

## 장면 표

| 장면 | 무엇이 움직이나 | 열리는 빈칸 |
|---|---|---|
| ① 표지 「생간이 기포를 만든다고?」 | 과산화 수소수 시험관에 생간 조각을 넣으면 기포가 생기고 불씨가 다시 타오름 → 「간 속에 무엇이 들어 있길래 반응이 빨라졌을까요?」 | — |
| ② 생명체 안의 화학 반응 실험 (시뮬레이터) | 합성(작은 물질 → 큰 물질)과 분해 그림 → 효소가 붙음 → 시험관 A(아무것도 안 넣음)·B(생간)·C(감자) 기포 비교, 불씨, 반응이 끝난 뒤 과산화 수소수 2 mL 더 넣기 | ① 물질대사 ② 효소 ③ 카탈레이스 |
| ③ 효소는 어떻게 반응을 빠르게 할까 | 반응의 진행 에너지 그래프에서 효소가 언덕을 낮춤 → 효소의 입체 구조와 결합·반응·분리, 반응 뒤 다시 사용 → 생활 속 효소(세제·소화제·식품·청바지 가공) | ④ 활성화 에너지 ⑤ 단백질 ⑥ 변하지 |

## 시뮬레이터 (장면 ②)
- 조작: 「2 mL 더 넣기」「비우기」, 시험관마다 넣을 것 고르기(없음·생간·감자)
- 규칙: 효소(카탈레이스)가 있는 시험관만 기포(산소)가 빠르게 생김. 반응이 끝난 시험관에 과산화 수소수를 더 넣으면 다시 기포가 생김(효소는 반응 뒤에도 그대로)

## 학생용 빈칸 학습지 글
- 생명체에서 일어나는 모든 화학 반응을 ( ① )라고 한다.
- 생명체의 물질대사에는 ( ② )가 관여한다.
- 간과 감자에는 과산화 수소를 물과 산소로 분해하는 효소 ( ③ )가 들어 있다.
- 화학 반응을 일으키는 데 필요한 최소한의 에너지를 ( ④ )라고 한다. 효소는 이 언덕을 낮추어 반응이 빠르게 일어나게 한다.
- 효소의 주성분은 ( ⑤ )이며, 효소마다 고유한 입체 구조를 갖는다.
- 효소는 반응이 끝나도 ( ⑥ ) 않아 다시 사용된다.

정답: ① 물질대사 ② 효소 ③ 카탈레이스 ④ 활성화 에너지 ⑤ 단백질 ⑥ 변하지
