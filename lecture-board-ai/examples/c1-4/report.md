# 기체의 온도와 부피 관계 — 칠판 강의 화면 (c1-4)

- 만든 모델: Claude Sonnet 5.5 (claude-sonnet-5-5)
- 걸린 시간: 대략 50분 (캡처 점검이 느린 컴퓨터에서 한 번 멈춰 다시 돌림)
- 도구 호출: 약 40회 (읽기 12, 쓰기·고치기 8, 캡처·검증 실행 약 15, 그림 확인 약 10)
- 파일: `index.html` (한 파일, 바깥 라이브러리·이미지 없음, 글꼴 불러오기 한 줄만), `sheet.png`, `shots/`

## 범위와 정한 것
- 교과서(비상교육 중1 VI. 기체의 성질, 210~213쪽) 학생 본문 범위입니다. 압력이 일정할 때 온도가 높아지면 부피가 늘어나고 낮아지면 줄어듭니다. 입자 수는 변하지 않고, 입자 운동이 활발해지거나 둔해져 부피가 바뀝니다.
- 쓰지 않은 것: 샤를 법칙, 절대 온도, K, 식, 「비례」 낱말. 식과 √ 관계는 코드 주석에만 있습니다. 교과서 그림·사진은 쓰지 않고 SVG로 새로 그렸습니다.
- 예시 값: 부피 50 mL(20 ℃), 슬라이더 0~80 ℃. 화면 숫자에 「(예)」를 붙였습니다.
- 뜻 색 약속: 온도 분홍 `#FF5C8A` · 부피 노랑 `#FFD60A` · 입자 초록 `#30D158` · 힘(추) 보라 `#BF5AF2` · 입자 빠르기 화살표 하늘 `#64D2FF` · 빈칸 정답 파랑 `#0066cc`. 면 색은 검정(표지) → 흰 띠 + 짙은 회색 면(장면 2) → 흰 띠 + 검정 면(장면 3)입니다.
- 소리(WebAudio 합성), 판서 도구, 대본(T), 전체 장면(O), 도움말(H), `?s=1` 복습판은 설계서대로 넣었습니다.

## 시뮬레이터 설명 (장면 2)
- **조작**: 왼쪽 슬라이더(0~80 ℃, 1 ℃ 단위, 끌기)와 「− 10 ℃」 「+ 10 ℃」 단추입니다. 슬라이더·단추를 눌러도 장면이 넘어가지 않고 ← → 키는 그대로 넘기기에 쓰입니다. 단계가 바뀌면 온도는 그 단계의 값으로 돌아갑니다.
- **식(코드 주석에만)**: V = V0·(273 + t)/(273 + t0), V0 = 50 mL, t0 = 20 ℃입니다. 0 ℃ 46.6 · 20 ℃ 50.0 · 40 ℃ 53.4 · 60 ℃ 56.8 · 80 ℃ 60.2 mL입니다. 입자 속력 ∝ √(273 + t), 0 ℃에서 140 px/초, 80 ℃에서 159 px/초(약 1.14배)입니다.
- **그려지는 것**: 피스톤 높이는 부피 × 6 px, 눈금 10~70 mL과 부피 표시 삼각형, 온도계, 가열판, 피스톤 위의 추(크기·무게 고정), 그래프(온도 0~80 ℃, 부피 0~70 mL)입니다.
- **입자**: 18개, 반지름 10 px 고정입니다. 입자끼리·벽·피스톤과 부딪치면 튕기고 겹치지 않습니다. 모두 같은 속력으로 그려 온도에 따른 빠르기를 견주기 쉽게 했습니다.

시뮬레이터 코드 점검(20·40·60·80 ℃, 0 ℃도 같은 방식으로 확인):

- 피스톤 높이는 300.0 / 320.5 / 341.0 / 361.4 px이고, 그래프 점 y는 식 값과 같습니다(585.7 / 567.7 / 549.6 / 531.6).
- 읽기 값은 50.0 / 53.4 / 56.8 / 60.2 mL이고, 입자 평균 속력은 식 값과 같습니다(145.0 / 149.9 / 154.6 / 159.2).
- 장면 3의 두 실린더는 입자 18개씩, 반지름 10으로 같고 높이는 279.5 / 361.4입니다.
- 3000 걸음 뒤 벽 밖 입자는 0개입니다. 슬라이더를 80→0 ℃로 갑자기 옮겨도 입자가 피스톤 밖에 남지 않았습니다.
- 슬라이더를 73 ℃로 끌면 59.0 mL로 식과 일치했습니다.

## 점검하며 고친 것
1. 표지 생수병이 작아 1.35배로 키우고, 병을 가로지르던 선반 선을 뺐습니다.
2. 장면 2의 추 설명 글이 실린더 벽과 겹쳐 실린더 위 가운데 한 줄로 옮겼습니다.
3. 슬라이더 「0」이 손잡이에, 온도계 「0」이 구슬에 가려져 위치를 옮겼습니다.
4. 번호 배지가 윗줄 글자와 겹쳐 빈칸 카드 줄 간격을 넓히고 제목·카드 위치를 올렸습니다.
5. 장면 3 열에서 「입자 크기도 같다」와 화살표 설명이 겹쳐 세로 자리를 다시 나눴습니다.
6. 점선이 오른쪽 열 글자까지 나가 실린더 끝에서 멈추게 했고, 오른쪽 열이 가열판에 붙어 22 px 옮겼습니다.
7. 「부피 차이」가 식 값(13.5)과 화면 숫자(60.2 − 46.6 = 13.6)로 어긋날 수 있어, 화면에 보이는 두 값의 차로 계산했습니다.
8. 입자를 밀어낸 뒤 벽 밖으로 1~2 px 나가는 경우가 있어 충돌 뒤 한 번 더 벽 안으로 되돌렸습니다(3000 걸음 점검에서 6 → 0).
9. 정답 누설: 장면 2의 추 설명은 「압력」 대신 「누르는 힘」으로 썼습니다. 장면 3 열의 설명은 「느리게/빠르게 움직인다」로 써서 ⑤ 「활발」, ⑥ 「멀어져」가 열리기 전에 보이지 않게 했습니다.

## 오개념 목록과 점검
1. 온도가 올라가면 입자가 커진다 → 입자 반지름이 모든 장면에서 같고, 장면 3에 「입자 크기도 같다」가 있습니다.
2. 입자 수가 늘거나 준다 → 18개(표지는 12개)를 실제로 세어 표시합니다.
3. 온도가 낮으면 입자가 멈춘다 → 0 ℃에서도 계속 움직입니다.
4. 바깥 압력도 따라 변한다 → 추를 같은 크기·무게로 고정하고 「누르는 힘은 늘 그대로」를 적었습니다.
5. 0 ℃에서 부피가 0이다 → 그래프 세로 눈금을 0부터 그려 0 ℃에서도 부피가 0이 아님을 보였습니다. 절대 온도는 다루지 않았습니다.

## 남은 걱정
- 입자 속력 차이는 식대로 하면 0 ℃와 80 ℃에서 약 14 %뿐이라 움직임만으로는 작게 보입니다. 장면 3 화살표 비교(140 / 159 px)와 대본으로 보완했고, 과장은 하지 않았습니다.
- 표지 생수병의 찌그러진 정도는 알아보기 쉽게 과장했고, 화면에 한 줄로 알려 두었습니다.
- 판서 도구(레이저·펜·손가락 설정)와 전체 화면 쓸어내림 방지는 코드로 넣었지만 아이패드·전자칠판 실기기에서는 확인하지 못했습니다. 마우스 클릭·키·슬라이더 끌기만 자동 점검했습니다.
- Pretendard 글꼴은 인터넷이 있어야 내려받고, 없으면 시스템 글꼴로 바뀌어 글자 폭이 조금 달라질 수 있습니다.
- 저작권 한 줄(1016 px 줄)은 받은 문구가 없어 넣지 않았습니다. 전체 장면(O)은 썸네일 대신 장면 목록 카드로 만들었습니다.
