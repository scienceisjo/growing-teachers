## 시뮬레이터 (장면 3)

- 조작: 물질 단추 3개(철 · 알루미늄 · 나무(예)), 부피 막대(10~100 cm³, 10씩), 질량 막대(1~800 g).
  - 물질 단추를 고른 동안 부피 막대를 움직이면 질량이 함께 바뀌고 밀도는 그대로입니다(같은 물질).
  - 질량 막대를 직접 움직이면 「이 물질」로 바뀌어 질량과 부피를 따로 정할 수 있습니다. 밀도가 1.0을 넘는 순간 가라앉는 것을 보여 줄 수 있습니다.
  - 조작 칸 안을 눌러도 장면이 넘어가지 않고, 막대나 단추에 초점이 있어도 → 키는 다음 단계로 갑니다(초점을 바로 풉니다).
  - → 로 넘기는 단계 1·2·5·7은 정해 둔 값으로 맞춰지고, ← 로 돌아가면 그 단계의 정해진 모습으로 돌아갑니다.
- 쓰는 식(코드 주석에도 적음)
  - 밀도(g/cm³) = 질량(g) ÷ 부피(cm³) — 화면의 계산 줄이 이 식 그대로 다시 계산됩니다.
  - 물질을 고른 동안: 질량 = 그 물질의 밀도 × 부피.
  - 밀도 &gt; 물 1.0 → 바닥까지 가라앉음 / 밀도 &lt; 1.0 → 뜸 / 같으면 물속에 머묾.
  - 그림만(글로는 안 씀): 뜬 물체가 잠긴 비율 = 물체 밀도 ÷ 물 밀도, 물 높이는 밀어낸 물의 부피 ÷ 수조 바닥 넓이만큼 올라감. 물체는 정육면체(1 cm = 40 px).
- 값 출처
  - 철 7.9 g/cm³, 물 1.0 g/cm³: 교과서 15쪽 표.
  - 알루미늄 2.7 g/cm³: 교과서 표에 없는 값(일반 자료값). 교과서 「스스로 확인하기」에 알루미늄이 나와서 골랐습니다.
  - 나무 0.5 g/cm³: 예시 값. 화면 단추에 「(예)」를 붙였습니다.
  - 장면 2의 79 g·10 cm³, 158 g·20 cm³: 교과서 밀도 7.9로 계산한 예시 측정값. 그림에 「측정값은 (예)」를 적었습니다.

## 학생용 빈칸 학습지 글

**물질이 뜨고 가라앉는 성질 — 밀도**

1. 같은 철, 크기가 다른 두 조각

| 구분 | 질량(g) | 부피(cm³) | 단위 부피당 질량(g/cm³) |
|---|---|---|---|
| 작은 철 조각 | | | |
| 큰 철 조각 | | | |

- 같은 물질은 양이 달라도 질량을 부피로 나눈 값이 항상 ( ① )하다.
- 물질의 단위 부피당 질량을 ( ② )(이)라고 한다.
- 밀도 = 질량 / 부피 (단위: g/cm³, g/mL)
- 이 값은 물질의 양에 따라 달라지지 않으므로 물질의 ( ③ )이다.

2. 물에 넣으면 뜰까, 가라앉을까?

- 밀도는 물질의 ( ④ )에 따라 다르다. 그래서 밀도로 물질을 구분할 수 있다.
- 물보다 밀도가 ( ⑤ ) 물질은 물에 가라앉는다.
- 물보다 밀도가 ( ⑥ ) 물질은 물 위에 뜬다.

생각해 보기: 크기가 다른 나무 도막이 모두 물에 뜨는 까닭을 「밀도」라는 낱말을 넣어 한 문장으로 써 보자.
