# c2-3 소리의 특성 (손글씨 노트형 3장)

- 만든 모델: Sonnet 5.5 · 손글씨 노트 스킬(hn/engine, 덱 x1)
- 입력: 비상교육 중2 과학 116~119쪽
- 걸린 시간: 약 18분 54초(에이전트 실행 시간), 도구 호출 75번
- 장면 3장, 단계 13개

## 장면

| 장면 | 단계 | 써지고 움직이는 것 |
|---|---|---|
| ① 표지 | 3 | 단원·제목 「소리의 특성」이 써짐. 오른쪽 화면 두 칸이 계속 움직임(위: 진폭이 커졌다 작아짐, 아래: 진동수가 빨라졌다 느려짐). 1단계 질문(크고 작은 소리, 높고 낮은 소리는 파동에서 무엇이 다를까), 2단계 ① 크기 ② 높낮이, 3단계 ③ 크기와 높낮이가 같아도 다른 소리 |
| ② 소리의 크기와 높낮이 | 5 | 1: 2 Hz 위치-시간 그래프와 진폭 화살표, 진폭 정의 · 2: 진폭이 작은 파동을 겹치고 「큰 소리 → 진폭이 크다」, 크기 핵심 문장 · 3: 1초 괄호, 「1초 동안 2번 진동 → 2 Hz」, 진동수 정의와 Hz · 4: 4 Hz 파동을 겹치고 높낮이 핵심 문장 · 5: 「진동수가 클수록 파장이 짧다」 |
| ③ 소리를 파동으로 나타내면 | 5 | 1: 짝 셋(크다·작다→진폭, 높다·낮다→진동수, 악기마다 다르다→파형) · 2: 시뮬레이터 등장 · 3: 파형 핵심 문장 · 4: 악기와 목소리는 파형이 다름 · 5: 「파형 : 파동의 모양(형태)」 |

## 형광펜 핵심 문장
1. 진폭 : 진동의 중심에서 가장 많이 움직인 거리
2. 소리의 크기는 진폭에 따라 달라진다
3. 진동수 : 1초 동안 진동하는 횟수
4. 소리의 높낮이는 진동수에 따라 달라진다
5. 진폭 · 진동수가 같아도 파형이 다르면 다른 소리가 난다
- 그 밖에 「진동수가 클수록 파장이 짧다」(교과서 119쪽). 장면 제목 셋은 초록 형광펜.

## 시뮬레이터 (장면 ③, 2단계에 나타남)
- 조작: 진폭 슬라이더(1~5칸), 진동수 슬라이더(200~1000 Hz), 파형 고르기(① 둥근 곡선 ② 사각에 가까운 모양 ③ 톱니 모양), 「소리 듣기」 단추(Web Audio, 첫 클릭 뒤에만 소리).
- 식: y = A·Σ b_k sin(2πk·f·t). 파형마다 가장 높은 값으로 나눠, 꼭대기가 늘 A가 되게 함.
- 그래프 창: 0.01초로 고정해서, 그려지는 주기 수 = f × 0.01.
- ←로 갔다 돌아오면 3칸 · 400 Hz · ①로 돌아감.
- 소리는 귀로 듣고 확인하지 못함(헤드리스 실행). 단추가 오류 없이 켜지고 꺼지는 것만 확인.

## 학생용 빈칸 학습지 글
1. ( ① ) : 진동의 중심에서 가장 많이 움직인 거리
2. 큰 소리는 작은 소리보다 ( ① )이 크다. 소리의 크기는 ( ① )에 따라 달라진다.
3. ( ② ) : 1초 동안 진동하는 횟수. 단위는 ( ③ )(헤르츠).
4. 1초 동안 2번 진동하는 파동의 진동수는 ( ④ ) Hz 이다.
5. 높은 소리는 낮은 소리보다 ( ② )가 크다. 소리의 높낮이는 ( ② )에 따라 달라진다.
6. ( ② )가 클수록 파장이 ( ⑤ ).
7. 크기와 높낮이가 같아도 ( ⑥ )가 다르면 다른 소리가 난다. ( ⑥ ) : 파동의 모양(형태)

정답: ① 진폭 ② 진동수 ③ Hz ④ 2 ⑤ 짧다 ⑥ 파형

## 점검하며 고친 것
1. 표지와 장면 ②의 범례 두 줄이 동시에 써짐(note_seq 2) → 차례로 나오게(최대 1).
2. 마지막 장면에 app-credit 이 없다는 빌드 경고 → 장면 ③ 왼쪽 아래에 「최종 업데이트」 줄.
3. 시뮬 「시간 (화면 전체 0.01초)」 설명이 파형과 겹침 → 칸을 40 → 36 px로 줄이고 설명을 맨 아래 줄로, 진폭 이름표를 오른쪽 끝으로.
4. 사각·톱니 파형이 들쭉날쭉 → 표본 1600점, 배음 15·12개.
5. 첫 캡처의 써지는 중간 장면은 1.6초 간격 탓 → 5초 간격으로 다시 찍어 최종 모습 확인.

## 남은 걱정
- ②·③ 파형은 사각·톱니로 단순화한 모양이라 실제 피아노·바이올린 파형이 아님(말로 덧붙일 것).
- 2 Hz·4 Hz 그래프는 설명용이며 실제 소리는 훨씬 빠르게 진동함.
- ①②③과 「·」는 손글씨 글꼴에 없어 시스템 글꼴로 보임(g1 예시와 같음).
