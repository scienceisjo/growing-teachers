## 시뮬레이터

**① 주변 밝기 (장면 3 왼쪽)**
- 조작: 「어두움 ↔ 밝음」 슬라이더
- 규칙: 동공 반지름 r = 110 − 80·b (b = 0 어두움, 1 밝음). 밝으면 r = 30, 어두우면 r = 110. 들어오는 빛의 양 막대 = (r/110)².

**② 물체 거리 (장면 3 오른쪽)**
- 조작: 「가까움 ↔ 멀음」 슬라이더
- 규칙: 물체 거리 d = 150 + 210·v. 망막까지 거리 D = 240을 고정하고 1/f = 1/d + 1/D을 써서, 상이 항상 망막의 한 점에 모이게 했습니다.
  - 수정체 두께 rx = 12 + 34p (p는 렌즈 세기를 0~1로 정규화한 값). 가까우면 두꺼움, 멀면 얇음.
  - 섬모체 고리 반지름 Rc = 118 + 14(1 − p). 가까우면 수축(118), 멀면 이완(132).
  - 상 높이 = 56·D/d. 가까우면 크고, 축 아래로 그려져 거꾸로입니다.

## 남은 걱정

- 「거꾸로 맺힌 상」은 과학적으로 맞지만 p.130~133 본문에 그 문장이 없습니다. 교과 범위에 넣을지 선생님이 확인해 주세요.
- 맹점·황반·시각 신경의 위치와 눈 크기는 개념도입니다. 교과서 그림 4-1·4-2와 같은 해부도가 아닙니다.
- 교사용 보충 칸의 「환상근」「종주근」은 쓰지 않았습니다.
- 오개념 점검: 「눈 겉의 홍채·동공이 눈 전체」「수정체와 망막 사이가 비었다」는 장면 2에서 다뤘습니다. 「빛이 많을수록 더 또렷이 보인다」는 장면 3 대본에서 직접 다루지 않았습니다.
- 저작권 한 줄: 교사가 준 문구가 없어 넣지 않았습니다(하단 1016px 줄 비움).
- 글꼴: 설계서(Pretendard) 대신 DESIGN.md의 Hahmlet·Gowun Dodum을 썼습니다. 인터넷 없이 열면 시스템 글꼴이라 줄바꿈이 달라질 수 있습니다.
- O 키 장면 고르기는 썸네일 대신 제목 카드로 만들었습니다.
- 학생 복습판(`?s=1`)은 구현만 했고 실제 학생 기기에서는 시험하지 않았습니다.
