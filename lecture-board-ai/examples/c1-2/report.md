# c1-2 물질을 가열할 때의 온도 변화 (손글씨 노트형 3장)

- 만든 모델: Sonnet 5.5 · 손글씨 노트 스킬(hn/engine)
- 근거: 비상교육 중1 과학(2022 개정) 140~143쪽. 교과서 그림·사진은 쓰지 않고 새로 그림
- 걸린 시간: 약 19분(에이전트 실행 시간), 도구 호출 45번
- 결과: index.html(덱 x1, 장면 3 · 단계 합 12)
- 보고서: 에이전트가 파일 쓰기가 막혀 마지막 답에 붙인 전문을 옮김

## 장면 표
| 장면 | 단계 | 무엇이 써지고 움직이나 |
|---|---|---|
| ① 표지 | 3 | 제목 두 줄이 써지고 끓는 비커(거품·김·불꽃)가 계속 움직임. 질문 「끓는 물의 온도는 계속 높아질까?」, 예상 가·나, 「가열하면서 그래프로 확인해 보자」 |
| ② 1. 물을 가열하면 (시뮬레이터) | 5 | 비커·온도계·그래프·단추·슬라이더 → 오르다가 끓으면 일정 → 끓는 동안 물의 양은 줄고 기체는 늘어남 → 끓는점 → 불을 세게 해도 끓는점은 그대로 |
| ③ 2. 온도가 일정한 까닭 | 4 | 얼음부터 시작하는 가열 곡선(모양만) → 고체·액체·기체 입자 모형 → 녹는 중·끓는 중 구간이 빨갛게 → 열에너지는 입자 배열을 바꾸는 데 쓰임 → 운동 활발 · 거리 멂 · 배열 불규칙 |

## 형광펜 핵심 문장
1. 끓기 시작하면 일정해진다
2. 끓는점(끓는 동안 일정한 온도, 물은 약 100 ℃)
3. 불을 세게 해도 끓는점은 그대로
4. 상태가 변하는 동안 온도는 일정하다
5. 가해 준 열에너지는 입자 배열을 바꾸는 데 쓰인다

## 시뮬레이터 (장면 ②)
- 조작: 「가열」「멈춤」「처음으로」, 불 세기 슬라이더(5단계, 가열 중에도 바꿈), 처음 상태 「25 ℃ 물」(기본, 교과서 탐구와 같음) / 「얼음」(−20 ℃에서 시작, 녹는 구간까지)
- 규칙: 가한 열로 온도를 구함. 오르는 구간은 열에 비례, 녹는 구간(0 ℃)·끓는 구간(100 ℃)은 정확히 일정. 불 세기는 시간당 열만 바꾸므로 빨리 도달하지만 끓는점은 같음. 끓는 구간은 녹는 구간의 약 6.8배(값은 코드 주석에만)
- 입자 모형 32개(수·크기 불변): 고체는 제자리 떨림, 액체는 아래층에서 미끄러짐, 기체는 칸 전체를 빠르게. 녹는 동안 고체 → 액체, 끓는 동안 액체 → 기체로 하나씩 옮겨 가며 물의 양이 줄어듦
- 확인 값: 물·얼음 두 시작 × 불 세기 5단계 모두 끓는 구간 100 ℃ 그대로, 녹는 구간 0 ℃. 끓기 시작 시각 약한 불 1.51분 → 센 불 0.38분. 입자 수 고체/액체/기체 합 늘 32

3. 끓는 동안 일정하게 유지되는 온도를 (　　　)이라고 하며, 물은 약 (　　　) ℃이다.
4. 불을 세게 해도 더 (　　　) 끓을 뿐, (　　　)은 그대로이다.
5. 물질의 상태가 변하는 동안 온도는 (　　　).
6. 이는 가해 준 (　　　)가 입자 (　　　)을 바꾸는 데 쓰이기 때문이다.
7. 고체 → 액체 → 기체로 갈수록 입자 운동은 (　　　), 입자 사이 거리는 (　　　), 입자 배열은 (　　　).

## 점검하며 고친 것
「열에너지 흡수」 글자와 화살촉 겹침, 첫 캡처가 쓰는 도중이라 누름 간격 늘림, 녹기 시작할 때 액체 입자가 칸 밖으로 나가던 것, 불 세기·시간축 범위(그래프가 한쪽에 몰리지 않게), 액체 층 높이, 빌드 경고(app-credit)

## 남은 걱정
- 액체 입자가 가끔 한쪽으로 몰려 보이고, 기체 입자끼리는 부딪히지 않고 겹쳐 지나감
- ③ 장면 곡선은 모양만 간단히 그려 구간 길이가 시뮬레이터와 다름(안내 문구 있음)
- 정지 캡처에는 그래프가 없음. 선생님이 직접 가열해야 그려짐(의도)
- 「℃」「→」는 손글씨 글꼴에 없어 대체 글꼴로 보임. 교과서에 없는 「1기압」은 화면에서 뺌
- 터치 기기는 실기기로 확인하지 못함
