VI. 동물과 에너지 · 기체를 교환하는 호흡계
호흡 운동
중2 과학 · 개념 노트
근육이 없는 폐는 어떻게 공기를 들이마실까?
숨 쉴 때 함께 움직이는 것 → 갈비뼈와 가로막
1. 호흡 운동
흉강 : 갈비뼈와 가로막으로 둘러싸인 가슴 안쪽 공간
폐는 근육이 없어 스스로 커지거나 작아지지 못한다
→ 갈비뼈와 가로막이 움직여 흉강의 부피를 바꾼다
숨을 들이쉴 때
가로막 내려감
갈비뼈 올라감
→ 흉강 · 폐의 부피 커짐
→ 폐의 압력 낮아짐
→ 공기 : 몸 밖 → 폐
숨을 내쉴 때
가로막 올라감
갈비뼈 내려감
→ 흉강 · 폐의 부피 작아짐
→ 폐의 압력 높아짐
→ 공기 : 폐 → 몸 밖
공기는 폐의 압력이 대기압보다 낮으면 들어오고, 높으면 나간다
숨을 다 들이쉬거나 다 내쉬면 폐의 압력은 다시 대기압과 같아진다
2. 허파꽈리에서의 기체 교환
공기의 길
코 → 숨관 → 숨관가지 → 허파꽈리
허파꽈리는 얇은 세포층으로 되어 있고
겉은 모세혈관이 둘러싸고 있다
산소 : 허파꽈리 → 모세혈관
이산화 탄소 : 모세혈관 → 허파꽈리
허파꽈리와 모세혈관 사이에서 산소와 이산화 탄소가 교환된다
폐는 수많은 허파꽈리로 되어 있어
→ 공기와 닿는 표면적이 매우 넓다
→ 기체 교환이 효율적으로 일어난다
