## 형광펜 핵심 문장
- 18족 원소는 홀로 안정하다 / 대부분의 원소는 결합해서 존재한다
- 전자는 원자핵 둘레의 전자 껍질에 있다 / 원자핵에 가까운 껍질부터 차례로 채운다
- 바깥 껍질의 전자 = 원자가 전자
- 같은 족 → 원자가 전자 수가 같다 / 18족은 바깥 껍질에 전자 8개
- 다른 원소는 18족처럼 안정해지려 한다 / 정전기적 인력으로 결합 / 전자쌍을 공유하여 결합

## 시뮬레이터 (장면 ③)
- 조작: 「원소 1」「원소 2」에서 H, He, Li, O, F, Ne, Na, Mg, Cl, Ar 중 하나씩 → 전자 껍질 그림과 배치(예: 2·8·1) → 「결합하기」(약 7.6초 움직임, 끝에 결과 글) · 「처음으로」. 단추를 누른 뒤에도 → 키로 넘어감
- 금속(Li, Na, Mg) + 비금속(O, F, Cl): 이온 결합. 금속은 바깥 전자를 모두 잃어 양이온, 비금속은 8개가 되도록 얻어 음이온. 필요한 원자 수가 자동으로 늘어남(NaCl, MgO, MgCl₂, Na₂O, Li₂O, LiF, MgF₂ 등). 전자 이동 → 이온 이름표 → 「정전기적 인력」 화살표 → 바깥 껍질 초록 테두리
- 비금속 + 비금속(H, O, F, Cl): 공유 결합. 껍질이 겹친 자리에 전자쌍이 모임(H₂, Cl₂, F₂, O₂ 두 쌍, HF, HCl, ClF, H₂O, OF₂, Cl₂O). 결합 뒤 바깥 껍질 8개(수소 2개)
- 18족이 들어가면 「결합하지 않는다」. 금속끼리, 수소 + 금속은 배우지 않은 결합이라 「이번에는 다루지 않는 짝」으로 막음
- 원소 1의 전자는 파랑, 원소 2는 주황이라 옮겨 간 전자를 눈으로 따라갈 수 있음
- 확인 값: 10 × 10 = 100쌍 모두 코드로 돌림. 결합하는 34쌍 문제 0건(껍질별 전자 수, 잃는 수 = 바깥 전자 수, 얻는 수 = 8 − 바깥 전자 수, 전하 합 0, 결합 뒤 바깥 껍질 8개·H 2개). 나머지 66쌍은 안내 글만

## 학생용 빈칸 학습지 글
1. 전자는 원자핵 둘레의 ( ① )에 있으며, 원자핵에 가까운 껍질부터 차례로 채운다. 최대 전자 수는 K 껍질 ( ② )개, L 껍질 ( ③ )개이다.
2. 가장 바깥 전자 껍질에 들어 있는 전자를 ( ④ )라고 한다.
3. 같은 족 원소는 ( ⑤ ) 수가 같아서 화학적 성질이 ( ⑥ ).
4. 18족 원소는 가장 바깥 껍질에 전자가 ( ⑦ )개(헬륨은 ( ⑧ )개) 채워져 ( ⑨ )해서 다른 원소와 거의 반응하지 않는다.
5. 18족이 아닌 원소는 전자를 잃거나 얻거나 ( ⑩ )해서 18족과 같은 전자 배치가 된다.
6. 금속 원소와 비금속 원소 사이에서 전자가 이동해 양이온과 음이온이 생기고, 두 이온 사이의 ( ⑪ )으로 결합하는 것을 ( ⑫ )이라고 한다. 예) Na → Na⁺, Cl → Cl⁻ → NaCl
7. 비금속 원소끼리 ( ⑬ )을 공유하여 결합하는 것을 ( ⑭ )이라고 한다. 예) H₂O

정답: ① 전자 껍질 ② 2 ③ 8 ④ 원자가 전자 ⑤ 원자가 전자 ⑥ 비슷하다 ⑦ 8 ⑧ 2 ⑨ 안정 ⑩ 공유 ⑪ 정전기적 인력 ⑫ 이온 결합 ⑬ 전자쌍 ⑭ 공유 결합
