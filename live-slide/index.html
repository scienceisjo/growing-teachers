수업 화면 열어 보기

중1 기체의 압력 화면이 열립니다. 노트북에서는 → 키로, 태블릿과 휴대폰에서는 화면을 눌러 넘깁니다.

AI움직이는 장면과 시뮬레이터는 어떻게 할까요? 메모의 60 → 30 → 20 mL는 추가 몇 개일 때인지도 알려 주세요.

AI번호별로 짧게 답해 주시거나 「추천대로」라고 보내 주세요.

선생님5번만요. 추가 없을 때 60 mL, 1개 올리면 30, 2개면 20이에요. 나머지는 추천대로.

멈춤

누르면 다음 장으로 넘어가고, 꾹 누르면 멈춥니다.

라이브 슬라이드의 특징

살아 있는 수업 자료
그림이 단계마다 움직이고, 값을 바꾸면 결과가 달라지는 시뮬레이터가 들어 있습니다. 학습지 빈칸은 같은 번호로 열립니다.
학생과 바로 주고받기
학생이 휴대폰으로 답을 보내면 칠판에 바로 모입니다. 고르기, 빈칸, 예측, 서술, 그래프 그리기 다섯 가지 질문을 넣을 수 있습니다.
여러 가지 디자인
기본판, 손글씨 노트판, 디자인 서랍판 가운데 고를 수 있습니다. 같은 내용에 겉모습만 바꿔 다시 만들 수도 있습니다.
쓰던 수업 자료에서 시작
교과서 쪽, 쓰시던 학습지, 설명 순서를 적은 메모를 AI에 주면 그 내용으로 만들어집니다. 선생님이 가르쳐 온 순서와 강조하는 점이 화면에 들어갑니다.

수업에서 쓰는 법

넘기기
화면을 한 번 누른 뒤 → 키를 누르면 한 단계 나아가고, ← 키를 누르면 돌아갑니다. 전자칠판과 태블릿에서는 화면을 눌러 넘깁니다.
빈칸
빈칸에는 학습지와 같은 번호가 붙어 있습니다. 학생이 그림을 먼저 관찰하고, 그다음 단계에서 정답이 열립니다.
시뮬레이터
단추나 슬라이더로 값을 바꾸면 그림과 숫자가 따라 바뀝니다. 전자칠판에서는 손가락으로 조작합니다.
판서
오른쪽 아래 펜 단추를 누르면 화면 위에 글씨를 쓸 수 있습니다. 판서 화면 열어 보기
학생 답
「학생 답」 단추를 누르면 코드와 QR이 뜹니다. 학생은 휴대폰으로 들어와 답을 보내고, 선생님은 모인 답을 칠판에서 봅니다. 학생 이름은 받지 않습니다. 시연 화면 열어 보기
파일
화면 하나가 HTML 파일 하나입니다. 내려받은 파일을 더블클릭하면 크롬에서 열립니다.

만드는 법

AI 채팅(Claude, ChatGPT, Gemini)에 프롬프트를 붙여 넣고 제 수업 자료를 첨부합니다. 처음에는 장면 3장짜리로 만들어 봅니다.

  1. 프롬프트를 복사합니다. 아래 단추를 누르면 3장 프롬프트가 통째로 복사됩니다.

  2. 자료를 첨부해 보냅니다. AI 채팅 입력칸에 붙여 넣고, 교과서에서 이번 차시 쪽을 찍은 사진이나 쓰시던 학습지를 첨부합니다. 둘 중 하나만 있어도 됩니다.
  3. 계획을 보고 「좋아」라고 답합니다. AI가 장면 계획과 빈칸을 먼저 보여 줍니다. 빈칸 번호와 정답이 학습지와 같은지 여기서 확인합니다.
  4. 끝까지 넘겨 봅니다. 결과 창(Claude 아티팩트, Gemini 캔버스, ChatGPT 미리 보기)에서 화면을 한 번 누르고 → 키로 끝까지 넘깁니다. 고칠 곳은 한 문장으로 보냅니다.

막힐 때

코드가 끊김
같은 대화에 「이어서 써 줘」라고 보냅니다.
→ 키가 안 됨
커서가 채팅 입력칸에 있을 때 그렇습니다. 화면을 한 번 누른 뒤 → 키를 누릅니다.
결과 창이 없음
코드를 복사해 메모장에 붙이고, 파일 형식을 「모든 파일」로 바꿔 「강의.html」로 저장한 뒤 더블클릭합니다.

한 차시 전체를 만들 때

한 차시 프롬프트에는 채울 칸이 없습니다. 교과서 쪽, 학습지, 설명 메모 가운데 있는 것을 첨부하면 AI가 모자란 것만 묻습니다. 질문마다 추천 답이 붙어 있어서 「추천대로」라고 보내도 됩니다. 추천 답에 든 숫자와 과학 내용은 읽어 보고 보냅니다. 장면 목록에 「좋아」라고 답하면 한 차시 화면이 파일 하나로 나옵니다.

  • 한 차시로 만드는 순서(매뉴얼 6절)
  • 매뉴얼 전체

이 방법으로 만든 예시

교과서 2~5쪽을 그림으로 주고 3장으로 만들게 한 화면입니다. 화면마다 선생님이 조작하는 시뮬레이터가 한 장면 이상 들어 있습니다.

  • 온도가 같아지는 열평형중1 · 교과서 86~88쪽 · Fable
  • 물질을 가열할 때의 온도 변화중1 · 교과서 140~143쪽 · Sonnet · 손글씨
  • 전하를 띠는 이온중2 · 교과서 152~156쪽 · Haiku
  • 광합성에 영향을 미치는 환경요인중2 · 교과서 170~174쪽 · Sonnet
  • 역학적 에너지의 전환과 보존중3 · 교과서 198~202쪽 · Opus
  • 전자기 유도와 발전기통합과학 · 교과서 89~93쪽 · Opus · 손글씨
  • 예시 모음 24개 모두 보기

한 차시 프롬프트로 만든 것

중1 「기체의 압력과 부피 사이의 관계」 16장입니다. 교과서 206~209쪽 그림, 학습지(빈칸 27개), 설명 순서를 적은 메모 일곱 줄을 첨부했고, Claude Sonnet이 질문 6개를 물은 뒤 파일 3개로 만들었습니다. 제가 보낸 말은 「5번만요 … 나머지는 추천대로」, 「좋아」, 「다음」, 고칠 점 한 번, 「다음」입니다. 고치지 않은 AI 결과 그대로 올렸습니다.

  • 한 차시 결과 열어 보기(강의_1.html부터)
