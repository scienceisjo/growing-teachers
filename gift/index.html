ZoomIt

무료설치 없음Microsoft 공식

화면 어디든 확대하고, 그 위에 펜으로 쓰고, 활동 시간을 재는 발표 도구입니다. 트레이에 조용히 있다가 단축키로 나타납니다.

수업에서 이렇게

  • 교과서 그림 확대. PDF를 띄우고 Ctrl+1을 누르면 마우스 위치가 확대됩니다. 휠로 더 키우고, 그대로 클릭하면 펜이 됩니다.
  • 확대 없이 바로 필기. Ctrl+2. 시뮬레이션 위에 화살표를 그리거나 답을 동그라미 칠 때.
  • 모둠 활동 타이머. Ctrl+3을 누르고 화살표 키로 분을 맞춥니다. 화면 전체에 크게 뜹니다.
  • 빈 칠판이 필요할 때. 그리기 중에 W는 흰 판, K는 검은 판이 됩니다.
ZoomIt.zip 내려받기 공식 페이지 · 압축을 풀고 ZoomIt.exe 실행

Snipaste

개인 무료설치 없음

캡처한 그림을 화면 위에 붙여 두는 도구입니다. 다른 창을 열어도 붙인 그림은 그 자리에 남아 있습니다.

수업에서 이렇게

  • 문제 하나를 옆에 띄워 두고 풀이. F1로 문제를 캡처하고 F3으로 화면 한쪽에 붙입니다. 그 상태로 시뮬레이션이나 풀이 창을 엽니다.
  • 두 장을 나란히 비교. 실험 전·후 사진, 두 학생의 답을 각각 붙여 놓고 같이 봅니다.
  • 붙인 그림은 휠로 크기. 마우스 휠로 키우고 줄이고, Ctrl+휠로 투명하게 해서 뒤가 비치게 합니다.

PowerToys

무료사용자 설치Microsoft 공식

Microsoft가 만드는 작은 도구 모음입니다. 스무 가지가 넘지만, 수업에서 실제로 손이 가는 것은 다섯 개입니다.

수업에서 이렇게

  • 마우스가 어디 있죠? Ctrl을 두 번 누르면 마우스 자리에 스포트라이트가 켜집니다. 큰 화면에서 학생 시선을 모을 때.
  • 클릭 자국 남기기. 마우스 강조를 켜면 클릭할 때마다 동그라미가 남아, 뒤에 앉은 학생도 어디를 눌렀는지 봅니다.
  • 타이머 창을 맨 위에. 창을 고른 뒤 Win+Ctrl+T. 다른 창을 열어도 가려지지 않습니다.
  • 화면 속 글자를 텍스트로. Win+Shift+T 뒤 영역을 드래그하면 그 안의 글자가 복사됩니다. 사진 속 문제를 학습지로 옮길 때.
  • 수업 중 화면이 꺼지지 않게. Awake를 켜 두면 절전 설정을 건드리지 않고도 화면이 유지됩니다.
GitHub에서 내려받기 Microsoft Store · 공식 설명서

주의. 설치가 필요합니다. 내려받을 때 UserSetup이 붙은 파일을 고르면 관리자 권한 없이 내 계정에만 설치됩니다. 안 쓰는 도구는 설정에서 꺼 두면 가볍습니다.

Microsoft Reflect

무료팀즈 안에 있음Microsoft 공식

학생이 오늘 기분을 하나 고르면 교사에게만 모이는 감정 체크인입니다. 이모티콘과 「감정 괴물(Feelings Monster)」로 60가지 감정 낱말 가운데 고르고, 팀즈 학급 팀에 처음부터 들어 있어 따로 깔 것이 없습니다.

우리 반에서 이렇게

  • 아침 조회를 체크인으로. 저는 아침에 학급 팀 게시물에 그날 힘이 되는 한마디를 올리고, 그 밑에 체크인을 붙입니다. 아이들은 등교하면서 휴대폰이나 디벗으로 이모티콘 하나, 감정 낱말 하나를 고릅니다.
  • 학부모 상담 자료로. 몇 주가 쌓이면 「인사이트」에서 학생 한 명의 기분이 날짜별로 어떻게 움직였는지 그래프로 보입니다. 상담 때 느낌 대신 그 화면을 놓고 이야기합니다.
  • 위험군 학생을 먼저 알기. 지친·불안한 쪽 응답이 며칠째 이어지는 아이가 학생별 응답 분포에서 눈에 띕니다. 말로 안 하는 아이를 먼저 부를 수 있습니다.
  • 이름은 교사에게만. 아이들은 친구가 무엇을 골랐는지 이름으로는 볼 수 없습니다. 만들 때 「응답자 이름 기록」을 켜야 학생별로 쌓이고, 전자칠판에 띄울 때는 「이름 숨기기」를 누릅니다.
reflect.microsoft.com ↗ 학교 Microsoft 365 계정으로 로그인 · 팀즈에서 시작하기(Microsoft 안내)

주의. 학교 Microsoft 365 계정(무료 A1 포함)이 있어야 하고, 학교 관리자가 앱을 막아 두면 탭이 안 보입니다. 응답은 학교 소유 데이터로 Microsoft 365 안에 저장되고, 게스트 계정 학생의 응답은 저장되지 않습니다.

CLASS GAME WORLD

무료웹 · 설치 없음직접 만듦

전자칠판에서 손가락으로 바로 하는 교실 미니게임 27개입니다. 한 화면에서 1~6명이 동시에 터치하고, 준비물이 없습니다. 반응·순발력 / 두뇌·집중 / 아케이드 / 단합대회 네 갈래로 나뉩니다.

우리 반에서 이렇게

  • 남는 5분. 타이머가 있는 게임은 한 판을 20초~3분으로 고릅니다. 「고슴+더지 잡기」「반응 줄다리기」처럼 나와서 두드리면 되는 게임은 규칙 설명이 거의 없습니다.
  • 수업 전환. 쉬는 시간이 끝나고 한 판. 많이 한 게임이 앞으로 오게(👑 인기순) 정렬되어 아이들이 고른 것이 늘 맨 앞에 있습니다.
  • 학급 행사·단합대회. 「라이어 게임」「텔레파시」「이구동성」「스피드 퀴즈」「그림 이어그리기」처럼 반 전체가 하는 게임은 단합대회 탭에 모여 있고, 「모둠 대전」으로 점수를 모아 겨룹니다.
  • 기록이 쌓입니다. 명예의 전당에 그 컴퓨터의 최고 기록이 쌓여, 다음 반이 이어서 도전합니다.

주의. 게임을 열기 전에 안전 서약 화면이 뜹니다. 전자칠판을 세게 치지 않기 · 손가락으로만 · 친구를 밀지 않기 다섯 가지에 「동의하고 시작」을 눌러야 열립니다. 기록은 그 컴퓨터의 브라우저에만 쌓입니다.

손뼉을 두 번 치면 화면이 켜지며 "Welcome home, sir." 하고 인사하는 아이언맨의 인공지능 비서입니다. 말로 부르면 날씨·시간·타이머·음악을 띄우고, 「오늘 학습목표」라고 하면 그날의 목표가 빈칸 퀴즈로 열립니다. 영어로 말하고 한글 자막이 같이 뜹니다.

수업에서 이렇게

  • 수업 시작 3분. 아이들이 들어오면 아무 말 없이 손뼉을 두 번 칩니다. 부팅 로그가 흐르는 4초 동안 화면 대신 아이들을 봅니다.
  • 학습목표를 읽어 주는 대신 맞히게. 목표 문장의 핵심 낱말을 [대괄호]로 감싸면 금색 빈칸이 됩니다. 아이들에게 물어본 뒤 Space를 누르면 글자가 톡 튀어나와 채워집니다.
  • 발표자 뽑기. "발표할 사람 뽑아줘" 하면 명단이 드르륵 돌다 멈추고 자비스가 이름을 읽습니다. 도는 3초 동안 숫자키를 누르면 그 모둠에서 뽑힙니다 — 아이들은 모릅니다.
  • 말이 안 먹혀도 됩니다. 교실이 시끄러워 못 알아들으면 숫자키로 똑같이 움직입니다. 음성만 믿지 않는 구조라 아이들은 눈치채지 못합니다.

병합·분할·압축·쪽번호·워터마크·모아찍기·텍스트 추출·OCR까지 열한 가지를 브라우저 안에서 합니다. 파일이 컴퓨터 밖으로 나가지 않습니다.

업무에서 이렇게

  • 학습지 여러 장을 한 파일로. 파일을 끌어다 놓고 순서를 바꾼 뒤 병합합니다.
  • 2쪽을 한 면에. 모아찍기로 종이를 반으로 줄입니다.
  • 스캔한 PDF에서 글자 뽑기. OCR을 돌리면 글자를 긁을 수 있는 PDF가 됩니다. 한글도 됩니다.
  • 인터넷 없이도. 브라우저 주소창의 「앱 설치」를 누르면 오프라인에서도 열립니다.
열어보기 ↗ 주소를 즐겨찾기에 넣어 두세요

주의. 큰 파일의 OCR은 시간이 걸립니다. 처리 중에는 탭을 닫지 마세요.

윈도우에 이미 있는 것

설치 권한이 없어도 됩니다

학교 컴퓨터에 아무것도 깔 수 없을 때. 윈도우 10·11에 이미 들어 있는데 잘 안 쓰는 기능들입니다.

Win+Shift+S

화면 일부 캡처

영역을 드래그하면 클립보드에 들어갑니다. 그대로 한글이나 메신저에 붙여 넣습니다.

Win+V

클립보드 기록

복사한 것 여러 개가 쌓입니다. 처음 한 번 「켜기」를 누르면 됩니다. 세특 문장 여러 개를 옮길 때.

Win+H

받아쓰기

말하면 글자가 됩니다. 긴 관찰 기록을 타자 대신 말로 남깁니다.

Win++

돋보기

ZoomIt이 없을 때의 확대. Win+-로 줄이고 Win+Esc로 끕니다.

Win+Ctrl+L

라이브 캡션

컴퓨터에서 나는 모든 소리에 자막이 붙습니다. 영상에 자막이 없을 때. 윈도우 11.

Win+P

전자칠판 연결

복제와 확장을 고릅니다. 확장으로 두면 노트북에는 교사용 화면, 칠판에는 학생용 화면.

Win+← →

창 반씩 나누기

왼쪽에 시뮬레이션, 오른쪽에 학습지. 창을 잡고 끌지 않아도 됩니다.

Win+.

이모지 · 기호

℃, →, ≠ 같은 기호를 찾을 때. 「기호」 탭에 수학 기호가 모여 있습니다.
