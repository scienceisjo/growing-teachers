이름과 전화번호를 쓰지 말라는 조건은 예제 공문에서는 필요 없어 보입니다. 그래도 처음부터 넣은 이유는, 5단계에서 실제 공문을 올릴 때 같은 프롬프트를 그대로 쓰기 위해서입니다.

안내문에 장학사 이름·전화가 들어감 — 「이름·전화 빼고 담당은 부서까지만」 한 줄로 고칩니다. 5단계에서 실제 공문을 올릴 때는 이 한 줄을 먼저 붙입니다.

너무 공손하고 길어짐 — 「5줄, 개조식, 인사말 없이」.

안내문에 빈칸을 남기게 하는 이유는 하나입니다. 교내 회신 기한은 공문에 없고 학교마다 달라서 AI가 알 수 없습니다. 이 칸을 AI가 채우면 그럴듯한 날짜가 들어가고, 그 날짜가 메신저로 한 번 나가면 되돌리기 어렵습니다.

체크리스트에서 D-day를 계산시키지 않는 것도 같은 이유입니다. AI는 오늘이 며칠인지 모를 때가 있고, 알아도 셈을 틀립니다. 기한만 받아 두고 남은 날은 캘린더가 세게 둡니다.

3

일정 — 계획표를 보고, 내 캘린더에 넣기

10분

계획표를 먼저 받아 종류와 시간을 확인해보겠습니다! 캘린더에 넣는 건 4단계에서 비서에 Google 캘린더를 연결한 뒤 「등록」 한마디로 합니다. 지금 당장 넣고 싶으면 계획표를 보고 직접 넣어도 3건이면 2분입니다.

🌱 가볍게 코스는 P5로 계획표를 받아 보는 데까지입니다.

일정 계획표 먼저 — 등록은 아직

P5로 계획표만 받아보겠습니다! 종류(제출 마감·행사·교내 마감)와 시간이 맞는지 확인하고, 넣는 건 그다음입니다.

  1. P5로 계획표 받기같은 대화에서 이어서.
  2. 종류와 시간 확인하기11/5 마감은 종일 + 「시간 원문 미기재」 · 제목 앞에 [마감] [안내] [연수] · 교내 마감은 날짜를 직접 준 경우에만.
  3. 넣는 길 고르기기본은 4단계에서 비서에 Google 캘린더를 연결해 「등록」. 지금 직접 넣으려면 calendar.google.com → 만들기 → 제목·날짜(마감은 종일) → 저장, 3건이면 2분.
P5 · 일정 계획표
위 표의 날짜를 일정 계획표로만 보여 줘(등록은 아직). 열은 제목 | 날짜 | 시간 | 종류(제출 마감 / 행사·연수 / 안내 / 교내 마감) | 설명 | 알림 제안. 제목 앞에 [마감] [연수] [안내] [교내] 중 하나. 시간이 원문에 없으면 종일로 두고 「시간 원문 미기재」라고 써.

저는 AI가 바로 등록하게 두지 않고 계획표를 먼저 받습니다. 웍스AI(SenGPT의 바탕) 문서 기준으로 캘린더 도구는 일정을 만들고 고칠 수는 있지만 지우지는 못합니다. 잘못 들어간 일정은 캘린더에서 손으로 지워야 해서, 들어가기 전에 한 번 보는 편이 빠릅니다.

선택CSV로 가져오기 — 계정 연결이 안 될 때만

학교 Google 계정이 연결을 막거나 일정이 열 건을 넘을 때 쓰는 길입니다. P5-b로 CSV를 받아 파일로 저장한 뒤 Google 캘린더 설정의 가져오기로 넣습니다. 오늘 실습에서는 건너뜁니다.

  1. P5-b로 CSV 받기코드 블록으로 옵니다. 블록 오른쪽 위 복사.
  2. 메모장에 붙여 넣고 .csv로 저장하기파일 이름 일정.csv · 저장 창의 인코딩 「UTF-8」 · 파일 형식 「모든 파일」.
  3. Google 캘린더에서 가져오기calendar.google.com → ⚙ → 설정 → 가져오기/내보내기 → 파일 선택 → 넣을 캘린더 고르기 → 가져오기.
  4. 11월로 넘겨 네 건 확인하기[마감] 11/5 종일, [안내] 11/11, [연수] 11/18·11/25 15:00.
P5-b · 캘린더 CSV
위 계획표를 Google 캘린더 가져오기용 CSV로 출력해 줘. 첫 줄은 정확히 Subject,Start Date,Start Time,End Date,End Time,All Day Event,Description,Location. 날짜는 MM/DD/YYYY, 시간은 3:00 PM 형식, 종일 일정은 All Day Event 를 True. 코드 블록으로.
막혔을 때

가져오기에서 오류 — 첫 줄 머리글이 정확히 Subject,Start Date,… 인지, 날짜가 11/05/2026 꼴인지 봅니다. 하나라도 다르면 통째로 거부합니다. 제가 만들어 둔 예시 CSV로 먼저 넣어 보면 형식 문제인지 바로 압니다.

제목 한글이 깨짐 — 메모장 저장 창에서 인코딩이 ANSI 로 되어 있는 경우입니다. UTF-8 로 다시 저장합니다.

저는 이 길을 연결이 막힐 때만 씁니다. 학교 Google 계정은 관리자가 외부 앱을 막아 둔 경우가 있고, 그때는 CSV가 유일한 자동 입력입니다. 일정이 열 건을 넘는 학사일정 공문에도 CSV가 손으로 넣는 것보다 빠릅니다.

서너 건이면 직접 넣는 편이 빠르고, 다음 공문부터는 4단계에서 연결한 비서에게 「등록」이라고 하면 됩니다. 그래서 이 블록은 선택으로 두었습니다.

4

나만의 비서 — 빈칸을 채워 지침문을 받고, 2·3단계를 한 번에

15분

프리셋을 누르고 빈칸을 채워 지침문을 받은 뒤, 에이전트로 만들어 예제 공문으로 시험해보겠습니다! 「등록해」라고 했을 때 계획표를 보여 주고 묻고 멈추는지까지 보겠습니다.

🌱 가볍게 코스는 빌더 대신 아래 완성본 지침문을 그대로 붙여 비서를 하나 만들어봅니다.

내 업무에 맞춘 비서 — 프리셋을 누르고 빈칸을 채우면, 지침문을 받는 프롬프트가 나옵니다

프리셋 하나를 누르고 빈칸을 고친 뒤 「프롬프트 만들기」를 눌러보겠습니다! 그걸 SenGPT 새 대화에 붙여 넣으면 지침문과 대화 스타터 여섯 개가 옵니다. 빌더는 📖 상세 모드에서 채웁니다.

프리셋 — 내 업무에 가까운 것 하나(담임·교무·교과). 누르면 ②③⑥⑦⑧이 채워지고, 그다음 고치면 됩니다
② AI에게 분석시킬 것 — 비서에게 넣을 재료
③ 비서가 만들어 줄 것 — 결과물(표는 엑셀·구글 시트에 붙여 넣는 열·수식으로 옵니다)
④ 연결할 도구
⑤ 항상 들어가는 규칙(빼지 않습니다)
원문에 없으면 「원문에 없음」이름·연락처 옮기지 않기등록·저장은 내가 「등록」이라고 말한 뒤학생 이름·민감 정보면 멈추기일정 삭제는 안 함보내는 건 내 손으로
채운 내용은 이 기기에 저장됩니다. 빈 칸은 기본값으로 채워집니다.
SenGPT(또는 Gemini·ChatGPT·Copilot)에 넣을 프롬프트 — 이걸로 지침문을 받습니다
메모장·한글·구글 문서 어디에 열어도 됩니다.
  1. 프리셋 하나 누르고 빈칸 채우기공문 담당자 / 담임·학부모 안내 / 부서 쪽지 많은 분. 부서·담당 업무는 구체적으로(「과학정보부, 디벗·정보화」). 모르는 칸은 비워 두어도 됩니다.
  2. 「프롬프트 만들기」 → 「복사」아래에 프롬프트가 나타납니다. 칸을 고치고 다시 누르면 다시 만들어집니다.
  3. SenGPT 새 대화에 붙여넣고 지침문 받기코드 블록 하나(지침문) + 스타터 6개가 오면 성공. 블록이 둘로 나뉘면 「한 블록으로 다시」.
  4. 받은 지침문을 보관함에 붙여 넣고 ⬇️ TXT로 저장하기아래 「내 지침문 보관함」. 이 파일 하나로 SenGPT·Gemini·ChatGPT·Copilot 어디서든 같은 비서를 만듭니다.
  5. 에이전트 만들기 → 이름·설명 → 지침 칸에 붙여넣기[내가 만든 비서] 또는 [에이전트] → 만들기. 코드 블록 안만 복사. 요술봉(프롬프트 고도화)은 누르지 않기 — 규칙이 바뀝니다.
  6. 대화 스타터 여섯 개 넣기SenGPT가 준 것 그대로. 6개까지 됩니다.
  7. 저장하고 새 대화에 예제 공문 올리기다른 말 없이 추출표가 먼저 나오면 성공.
  8. 「일정 등록해」라고 말해 보기계획표를 보여 주고 「이대로 등록할까요?」라고 묻고 멈추면 성공. 도구를 붙이면 「등록」에 실제로 들어갑니다.
막혔을 때

지침문이 길어 지침 칸에 안 들어감 — 「2,000자 이내로 줄여. 절대 규칙 여섯 개는 그대로」 한 줄.

규칙 여섯 개 중 하나가 빠져서 옴 — 프롬프트의 [절대 규칙] 부분을 다시 붙이고 「빠진 규칙을 넣어 전체를 다시 출력해」.

메뉴에 「비서」와 「에이전트」가 둘 다 있음 — 같은 기능입니다. 웍스AI가 2026년 8월에 이름을 에이전트로 바꿨고, 외부 도구 연결은 에이전트 쪽에 있습니다.

「등록해」에 묻지 않고 바로 하려 함 — 도구가 없는 비서는 등록할 수 없어서 계획표만 나옵니다. 아래 심화에서 도구를 붙인 뒤에도 그러면, 「등록」이라는 말 없이 계획표만 시키고 확인한 뒤 「등록」이라고 따로 말합니다.

제 지침문을 그대로 드리지 않고 빌더를 두는 이유는, 제 지침문이 제 업무(과학정보부, 공문 위주) 기준이기 때문입니다. 교무기획부는 쪽지가 더 많고, 담임은 가정통신문이 더 급합니다. 빈칸 여덟 개를 채우면 그 차이가 지침문에 들어갑니다.

대신 빼면 안 되는 규칙 여섯 개(원문에 없으면 없다고 쓰기, 요일 계산 금지, 근거 인용, 이름·연락처 금지, 「등록」 전 실행 금지, 삭제 금지)는 프롬프트에 그대로 박아 두어서, SenGPT가 어떤 지침문을 써 주더라도 빠지지 않습니다. 저는 수업 도입 영상을 만들 때도 에이전트 지침에 규칙 일곱 개를 넣어 썼는데, 이번엔 그 규칙을 프롬프트 쪽에 옮겨 둔 셈입니다.

# 공문 업무비서 ## 역할 당신은 학교 교사의 「공문 업무비서」입니다. 교사가 올린 공문 1건을 읽고 교사가 해야 할 일을 정리하며, 요청이 있을 때만 안내문·체크리스트·일정 계획·관리표를 만듭니다. 최종 판단과 실행 여부는 항상 교사가 결정합니다. ## 입력 - 공문 본문(PDF, HWP, HWPX, 이미지, 붙여넣은 글). 붙임 파일은 함께 올라온 경우에만 참고합니다. - 교사가 알려 주는 조건(담당 부서, 내가 담당자인지, 교내 회신 기한 등). ## 절대 규칙 1. 원문에 없는 내용을 만들지 않습니다. 날짜·시간·장소·인원·제출 방법이 원문에 없으면 그 칸에 「원문에 없음」이라고 쓰고, 필요하면 교사에게 묻습니다. 2. 날짜는 원문 표기를 그대로 옮깁니다(예: 2026. 11. 5.(목)). 요일을 고치거나 계산해 넣지 않습니다. 연도가 없으면 「연도 미기재」라고 씁니다. 3. 추출한 항목마다 근거가 된 원문 문장을 짧게 인용합니다. 4. 사람 이름·전화번호·이메일은 결과물에 옮기지 않습니다. 담당자는 「담당: 부서명」까지만 씁니다. 학생 이름·성적·건강·상담·징계 등 민감한 정보가 보이면 작업을 멈추고 「이 공문은 AI에 올리지 않는 것이 좋습니다」라고 알립니다. 5. 캘린더·드라이브 같은 외부 도구는 교사가 「등록해」「저장해」라고 분명히 말하기 전에는 절대 실행하지 않습니다. 실행 전에는 반드시 계획표를 보여 주고 확인을 받습니다. ## 1단계 — 공문 읽기(공문이 올라오면 다른 말 없이 이 표부터) 표 열: 항목 | 내용 | 근거 문장 행: 문서 제목 / 발신 기관 / 시행일 / 목적(한 줄) / 대상 / 내가 해야 할 일(번호 목록) / 각 일의 기한 / 제출 방법(공문·메일·시스템·서식) / 붙임 자료(첨부 여부 표시) / 행사·연수 일시와 장소 / 주의사항 / 예산·출장 관련 / 원문에 없어서 확인이 필요한 것 표 아래에 「한 줄 요약」과 「지금 당장 할 일 1개」를 씁니다. ## 2단계 — 요청이 있을 때만 - 「안내문」: 교직원 메신저용 5~7줄. 첫 줄에 무엇을·언제까지·어떻게. 교내 회신 기한은 교사가 정하므로 「(교내 회신 기한: ____ )」 빈칸으로 둡니다. 이름·전화는 넣지 않습니다. - 「체크리스트」: 담당자가 할 일을 순서대로, 항목마다 기한과 산출물. D-day 계산은 하지 않습니다(교사가 확인). - 「관리표」: 열 이름과 예시 1행만 있는 표. 세는 열이 있으면 COUNTIF 같은 수식을 한 줄로 제안합니다. - 「신청 조사 문항」: 5문항 이내, 문항마다 응답 형식(객관식·체크박스·단답)을 적습니다. 이름·연락처 같은 개인정보 문항은 꼭 필요한 최소만. - 「쪽지 정리」: 쿨메신저 쪽지가 여러 개 붙여 넣어지면 표로 정리합니다. 열: 출처(부서·직책·받은 때) | 할 일 | 기한(원문 표기 그대로, 없으면 「원문에 없음」) | 회신 방법 | 근거 문장. 「이번 주까지」처럼 날짜가 아닌 기한은 그대로 옮기고 「확인 필요」라고 표시합니다. 「회신 초안」 요청이 있으면 항목마다 3줄(무엇을·언제까지·어떻게), 이름 없이 씁니다. - 「일정」: 아래 3단계. ## 3단계 — 일정 1. 먼저 「일정 계획표」만 보여 줍니다. 열: 제목 | 날짜 | 시간 | 종류(제출 마감 / 행사·연수 / 안내 / 교내 마감) | 설명(공문 제목·제출 방법) | 알림 제안. - 제목 규칙: 「[마감] …」「[연수] …」「[안내] …」「[교내] …」. - 시간이 원문에 없으면 종일 일정으로 두고 설명에 「시간 원문 미기재」라고 씁니다. - 교내 마감은 교사가 날짜를 준 경우에만 넣습니다. 2. 「이대로 등록할까요? 고칠 것이 있으면 말씀해 주세요.」라고 묻고 멈춥니다. 3. 교사가 「등록」이라고 하면 그때 캘린더 도구로 한 건씩 등록하고, 건별 결과(성공/실패, 제목)를 표로 보고합니다. 4. 캘린더 도구가 연결되어 있지 않거나 실패하면 같은 내용을 Google 캘린더 가져오기용 CSV로 출력합니다. 첫 줄은 정확히 Subject,Start Date,Start Time,End Date,End Time,All Day Event,Description,Location 이고 날짜는 MM/DD/YYYY, 시간은 3:00 PM 형식, 종일 일정은 All Day Event를 True로 씁니다. 가져오기 방법을 한 줄로 덧붙입니다(캘린더 › 설정 › 가져오기/내보내기). 5. 일정 삭제는 하지 않습니다(도구가 지원하지 않음). 삭제는 교사가 캘린더에서 직접 합니다. ## 4단계 — 저장(요청 시) - Google Drive 도구가 연결되어 있으면 「공문 요약본」 문서를 새로 만들어 저장하고 링크를 보고합니다. 기존 파일을 열거나 고치려 하지 않습니다. - 연결되어 있지 않으면 요약본을 마크다운으로 출력하고 「대화 내보내기(DOCX)」로 저장하도록 안내합니다. ## 예외 - 파일을 읽지 못하면 본문 텍스트를 붙여 넣어 달라고 요청합니다. - 공문이 2건 이상이면 1건씩 처리하겠다고 알리고 첫 번째부터 합니다. - 스캔 이미지라 글자가 흐리면 읽은 부분과 못 읽은 부분을 구분해 알립니다. - 도구 오류는 오류 내용을 그대로 알리고 CSV 대안을 줍니다. ## 말투 짧고 개조식, 표 우선, 존댓말. 서론·격려 문구 없음.

연결Google 캘린더 연결 — 「등록」 한마디로 넣기

에이전트 편집 화면의 도구에서 Google 캘린더 카드를 눌러 로그인하면 「연결됨」이 뜹니다. 그다음 새 대화에서 「일정 등록해」라고 하면 계획표가 오고, 「등록」이라고 해야 들어갑니다. 3단계 계획표를 여기서 넣어보겠습니다!

  1. 에이전트를 복사해 두 번째 판 만들기에이전트 목록 → 복사. 첫 판은 도구 없이 그대로 둡니다. 시간이 없으면 복사 없이 첫 판에 바로 연결해도 됩니다.
  2. 도구에서 Google 캘린더 카드 연결하기카드 클릭 → Google 로그인(개인 계정) → 권한 허용 → 「연결됨」.
  3. 새 대화에 공문 → 「일정 등록해」 → 계획표 → 「등록」3단계에서 확인한 계획표 그대로. 건별 성공/실패 표가 오면 성공.
  4. Google 캘린더 새 탭에서 확인하기11월로 넘겨 [마감]·[연수]가 보이는지.
  5. 수정 한 번 시켜 보기「[마감] 일정에 하루 전 알림 넣어 줘」. 삭제는 안 되니 캘린더에서 직접.
막혔을 때

학교 Google 계정으로 권한 창이 안 뜸 — 관리자가 외부 앱 접근을 막아 둔 것입니다. 개인 Google 계정으로 연결합니다.

「Gmail · Google Drive」 카드가 보임 — 이 카드는 메일 읽기·보내기 권한을 같이 요구합니다. 오늘은 연결하지 않고, 요약본은 대화 내보내기(DOCX)로 받습니다.

저는 이 연결을 개인 Google 계정으로 합니다. 학교 계정은 관리자가 외부 앱 접근을 막아 둔 경우가 있어서입니다. 연결 설정은 에이전트에 저장되지만 데이터는 각자 로그인으로 오가기 때문에, 비서를 다른 선생님과 공유해도 제 캘린더에 남이 쓰지 못합니다.

Gmail과 Google Drive는 웍스AI에서 한 카드로 묶여 있어서, 드라이브 저장을 켜면 메일 권한이 같이 넘어갑니다. 요약본은 대화 내보내기로 DOCX를 받아 직접 올리는 편이 빠르고, 넘기는 권한도 없습니다.

SenGPT는 서울교육청 전용이고 API 방식이라 데이터가 모델 학습에 쓰이지 않는다고 운영 계획에 적혀 있습니다. 그런데 같은 기관의 이용 매뉴얼은 개인정보와 내부 데이터를 넣지 말라고 합니다. 저는 그래서 본문만 올리고 붙임은 서식만 올립니다. 명단은 붙임에 있을 때가 많습니다.

지우는 방법은 간단합니다. 저는 에듀파인에서 본문 글을 긁어 메모장에 붙이고 이름과 번호를 지운 뒤, 그 글을 그대로 입력창에 넣습니다. PDF를 가릴 필요가 없고, 이 과정에서 공문을 한 번 더 읽게 됩니다.

연수 전에 저장해 오신 공문(초록 또는 노랑)을 비서 새 대화에 올려보겠습니다! 대조는 기한·제출 방법·붙임 세 가지만 봅니다.

  1. 내 공문을 색으로 나누기빨강이면 예제 공문으로 대신하고 같은 순서로.
  2. 노랑이면 본문 글을 복사해 이름·전화 지우기메모장에 붙여넣기 → 지우기 → 전체 복사.

막혔을 때

시리얼이 한두 글자 바뀌어 옴 — 0과 O, 1과 l을 AI가 바꾸는 경우입니다. P19의 「한 글자도 바꾸지 말고」 조건이 있어도 생기니, COUNTIF로 원본과 개수를 맞춰 보고 다르면 그 행만 원본에서 다시 붙입니다.

드롭다운이 안 뜸 — 데이터 확인의 범위가 다른 시트를 가리킬 때는 기기!A2:A200처럼 시트 이름을 붙여야 합니다.

기기가 학생보다 많거나 적음 — AI가 억지로 채우지 않게 「남는 것은 따로」 조건이 있습니다. 남는 쪽은 대장에 「예비」로 둡니다.
