🪄 수업앱 기획 스튜디오

계획만 적으면 → 만들기 프롬프트가 자동 완성 → 승재쌤이 대신 배포

진행 방법
① 아래에 내 수업앱 계획을 적습니다 → ② [프롬프트 생성]을 누르면 2개의 프롬프트(앱 만들기 → Supabase SQL)가 자동으로 완성됩니다 → ③ 제출하면 승재쌤에게 공유되어, 승재쌤이 Claude로 돌려 대신 만들어·배포해 드립니다.
❓ URL·anon key 어디서 찾나요? (펼치기)
Supabase 접속 → 왼쪽 아래 ⚙️ Project Settings → Data API의 Project URL 복사 → API Keys의 anon(또는 publishable) 키 복사. service_role(비밀) 키는 절대 넣지 마세요! anon 키만.
📌 순서: ① 먼저 프롬프트 1로 앱을 만들고 → ② 프롬프트 2로 Supabase 표를 만드세요. (앱을 만든 뒤 DB를 붙이는 순서!)
STEP 1

🖥️ 앱(웹앱) 만들기 프롬프트

AI(클로드·GPT)에 붙여넣으면 내 계획대로 웹앱 코드를 만들어 줍니다.

    


    

      STEP 2
      
🗄️ Supabase SQL 프롬프트 

      
위 앱이 쓸 표를 만드는 SQL을 생성합니다. 공개 anon 키를 쓰므로 RLS(보안) 요청이 필수로 들어가 있습니다.

      

    

  


  
  

    🧑‍🏫 관리자(승재쌤)용 — 처음 1회 설정
    
이 페이지가 기획을 저장할 표입니다. Supabase(A) SQL Editor에 붙여넣고 Run. 읽기(select)는 anon에게 막아 다른 사람이 남의 기획·키를 못 읽습니다(승재쌤은 Table Editor로 열람).

create table if not exists teacher_plans (
  id uuid primary key default gen_random_uuid(),
  created_at timestamptz not null default now(),
  teacher text, plan text, data_types text, purpose text,
  app_plan text, supa_url text, supa_key text,
  prompt_app text, prompt_sql text
);
alter table teacher_plans enable row level security;
drop policy if exists "anon insert plans" on teacher_plans;
create policy "anon insert plans" on teacher_plans for insert to anon
  with check ( char_length(coalesce(plan,'')) <= 5000 );
-- 읽기 정책 없음 = anon 읽기 불가(의도적)
